# TDD & Implementation (Native)

## 1. RED (Failing Test)
Reproduce the issue or cover the requirement first.

## 2. GREEN (Minimal Fix)
Pass the test with the simplest possible code.

## 3. READ-AFTER-EDIT
Mandatory: `read_file` in the same turn as a write to verify the final state.
