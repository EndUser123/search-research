# Architectural Review (Native)

Follow these high-rigor design patterns:

## 1. Adversarial Review
Identify 3 ways the design could fail:
- Performance bottlenecks
- Security gaps
- Complexity bloat

## 2. Alternatives Analysis
Always present Approach A (Recommended) and Approach B (Alternative).

## 3. Contract Audit
Ensure return schemas and security gates are preserved.
