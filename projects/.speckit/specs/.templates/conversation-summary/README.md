# Conversation Summary Template

This directory contains templates for creating conversation summary task specifications (TSK).

## Directory Structure

- `README.md` - This file
- `PLAN.md` - Task planning template
- `SPECIFY.md` - Requirements specification template
- `TASKS.md` - Task breakdown template
- `DATA_MODEL.md` - Data structure definition template
- `IMPLEMENT.md` - Implementation guide template
- `clone_template.sh` - Script to clone templates
- `TEMPLATE_README.md` - Template for creating new template READMEs

## Usage

Refer to the individual template files for their specific purposes and usage instructions.
