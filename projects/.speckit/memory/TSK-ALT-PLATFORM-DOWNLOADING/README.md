# Alt-Platform Video Downloading

## Project Description
Development of multi-platform video downloading support for Odysee, Rumble, BitChute, and other alternative platforms beyond YouTube.

## Goals
- Extend yt-fts to support alternative video platforms
- Integrate yt-dlp with Odysee, Rumble, BitChute
- Implement platform-specific error handling
- Create unified interface for multi-platform downloads

## Current Status
Project initialized - planning phase

## Next Steps
1. Set up git worktree for isolated development
2. Research platform-specific API limitations
3. Design extensible platform architecture
4. Implement core platform detection
5. Add support for first alt-platform (Odysee)
