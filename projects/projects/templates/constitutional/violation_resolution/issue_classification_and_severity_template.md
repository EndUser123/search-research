# Issue Classification and Severity Assessment Template

**Template Version:** 1.0
**Last Updated:** 2025-11-20
**Framework:** CSF NIP Constitutional Compliance

## Template Overview
This template provides a systematic framework for classifying constitutional compliance violations and assessing their severity, enabling consistent evaluation and appropriate response prioritization.
