# dualllm-v2 Development Intelligence Integration

## 🧠 **Unified Intelligence System**

This project uses the Development Intelligence system that combines memory bank, issue tracking, and development workflows for AI-assisted development.

### **Before Starting Any Task:**
```bash
# Search all intelligence systems
python ..\.brain/tools/intelligence_search.py --project dualllm-v2 --query "your-topic"

# Search memory bank specifically
python ..\.brain/memory_bank/tools/search_engine.py "your-topic" --projects dualllm-v2

# Check for related issues
grep -r "your-topic" docs/issues/
```

### **During Work:**
- **Reference intelligence** - Link to related memory entries and issues
- **Document insights** - Note significant discoveries for later intelligence updates
- **Follow workflows** - Use development guides from intelligence system
- **Cross-reference** - Connect current work to existing knowledge

### **After Completing Work:**
```bash
# Check if work should create memory entry
python ..\.brain/integration/memory_issue_bridge.py suggest --project dualllm-v2 --issue-id your-issue-id

# Create memory entry for significant insights
python ..\.brain/memory_bank/tools/memory_manager.py create \
  --type lesson_learned \
  --title "Your Insight Title" \
  --projects dualllm-v2 \
  --tags relevant,domain,tags \
  --llm-id your-identifier \
  --confidence high

# Link issue and memory entry
python ..\.brain/integration/memory_issue_bridge.py link --project dualllm-v2 --issue-id issue-id --memory-id memory-id
```
