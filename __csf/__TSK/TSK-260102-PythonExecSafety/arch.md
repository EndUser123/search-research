# Architecture Design: PreToolUse Python Execution Safety Hook

**Date:** 2026-01-02
**Status:** Design Complete

## Overview

Automatic conversion of unsafe `python -c` commands to safe temp file execution via PreToolUse hook.

## Problem Architecture

### Current Flow (Unsafe)
```
User Request
    ↓
Claude Code generates: python -c "from pathlib import Path; print('complex')"
    ↓
Bash Tool (Git Bash)
    ↓
MINGW64 Translation Layer ← ESCAPING HAPPENS HERE
    ↓
Windows Python
    ↓
SIGKILL (exit 137) ← FAILS HERE
```

### Root Cause Analysis

| Layer | What Happens | Why It Fails |
|-------|--------------|--------------|
| User Intent | `python -c "complex code"` | User expects Python to receive code |
| Bash Tool | Passes command string | Standard shell invocation |
| MINGW64 | Translates paths/quotes | **BREAKING POINT** - mangles complex strings |
| Windows | Receives mangled string | Python cannot parse |
| Result | Exit code 137 | SIGKILL forced termination |

**Key Issue:** The MINGW64 translation layer handles:
- Backslashes (`\` → escape character or path separator)
- Quotes (`"` nested in `"`)
- Windows paths (`P:\` → ambiguous)
- Special characters (`&`, `|`, `>`, `<`)

## Solution Architecture

### New Flow (Safe)
```
User Request
    ↓
Claude Code generates: python -c "complex code"
    ↓
PreToolUse_python_exec.py HOOK ← INTERCEPTS HERE
    ↓
Detects: python -c pattern
    ↓
Extracts: Code from -c argument
    ↓
Generates: Deterministic temp file path
    ↓
Writes: Code to temp file
    ↓
Returns: updatedInput with safe command
    ↓
Bash Tool executes: python P:/__csf.nip/temp/exec_<hash>.py
    ↓
MINGW64 Translation Layer ← SINGLE PATH, NO ESCAPING
    ↓
Windows Python
    ↓
SUCCESS
```

## Component Design

### 1. PreToolUse_python_exec.py Hook

**Location:** `P:/.claude/hooks/PreToolUse_python_exec.py`

**Trigger Conditions:**
- Tool: `Bash`
- Command matches: `python -c` or `python3 -c`
- Command complexity: > 100 chars OR contains backslashes/quotes

**Input Environment Variables:**
- `CLAUDE_TOOL_NAME`: "Bash"
- `CLAUDE_TOOL_INPUT`: JSON with `{"command": "..."}`
- `CLAUDE_HOOK_CONTEXT`: Session context

**Output JSON:**
```json
{
  "decision": "approve",
  "updatedInput": {
    "command": "python P:/__csf.nip/temp/exec_<hash>.py"
  }
}
```

### 2. Detection Logic

```python
import re
import hashlib
import json
from pathlib import Path

def should_intercept(tool_input: dict) -> bool:
    """Check if command should be converted to temp file."""
    command = tool_input.get("command", "")

    # Must be python -c
    if not re.match(r'^\s*python(?:3)?\s+-c\s+', command):
        return False

    # Complexity indicators
    complexity_markers = [
        len(command) > 100,           # Long command
        '\\' in command,              # Backslashes
        '"' in command.count('"') > 2,  # Multiple quotes
        "'" in command.count("'") > 2,  # Multiple quotes
        'Path(' in command,           # Windows paths
        'P:/' in command,             # Windows paths
    ]

    return any(complexity_markers)
```

### 3. Extraction Logic

```python
def extract_python_code(command: str) -> str | None:
    """Extract code from python -c argument."""

    # Match: python -c "CODE" or python -c 'CODE'
    match = re.match(r'^\s*python(?:3)?\s+-c\s+(["\'])(.+?)\1\s*$', command, re.DOTALL)

    if match:
        return match.group(2)

    # Try parsing with shlex for more complex cases
    import shlex
    try:
        parts = shlex.split(command)
        if len(parts) >= 3 and parts[1] == '-c':
            # Remaining parts form the code
            return ' '.join(parts[2:])
    except:
        pass

    return None
```

### 4. Deterministic File Naming

```python
def get_temp_file_path(code: str) -> Path:
    """Generate deterministic temp file path from code hash."""

    # Hash the code for consistent naming
    code_hash = hashlib.sha256(code.encode()).hexdigest()[:16]

    # Use consistent temp directory
    temp_dir = Path("P:/__csf.nip/temp")
    temp_dir.mkdir(exist_ok=True)

    return temp_dir / f"exec_{code_hash}.py"
```

### 5. Temp File Writing

```python
def write_temp_file(file_path: Path, code: str) -> None:
    """Write code to temp file."""

    # Add header for debugging
    header = f'''# Auto-generated by PreToolUse_python_exec hook
# Source: python -c command
# DO NOT EDIT - This file will be reused if same command is issued

'''

    file_path.write_text(header + code)
```

### 6. updatedInput Generation

```python
def build_updated_input(file_path: Path, original_input: dict) -> dict:
    """Build updatedInput for PreToolUse response."""

    new_command = f'python "{file_path}"'

    return {
        "decision": "approve",
        "updatedInput": {
            "command": new_command
        }
    }
```

## Complete Hook Flow

```python
#!/usr/bin/env python3
"""
PreToolUse Hook: Python Execution Safety

Automatically converts unsafe python -c commands to safe temp file execution.
"""

import os
import re
import json
import hashlib
import shlex
from pathlib import Path

def main():
    # Read tool input from environment
    tool_input_json = os.environ.get("CLAUDE_TOOL_INPUT", "{}")

    try:
        tool_input = json.loads(tool_input_json)
        command = tool_input.get("command", "")

        # Check if should intercept
        if not should_intercept(tool_input):
            print(json.dumps({"decision": "approve"}))
            return

        # Extract Python code
        code = extract_python_code(command)
        if not code:
            print(json.dumps({"decision": "approve"}))
            return

        # Generate temp file path
        temp_file = get_temp_file_path(code)

        # Write temp file (only if doesn't exist)
        if not temp_file.exists():
            write_temp_file(temp_file, code)

        # Return updated input
        result = build_updated_input(temp_file, tool_input)
        print(json.dumps(result))

    except Exception as e:
        # On error, let command proceed unchanged
        print(json.dumps({"decision": "approve"}))

if __name__ == "__main__":
    main()
```

## Fallback Behavior

If hook fails:
1. Exception caught → returns `{"decision": "approve"}` without modification
2. Original command executes (may fail with exit 137)
3. No harm done, just doesn't solve the problem

## Advantages

| Aspect | Benefit |
|--------|---------|
| **Automatic** | No user action required |
| **Transparent** | Works without changing workflow |
| **Safe** | Deterministic file naming prevents conflicts |
| **No cleanup** | temp/ already in .gitignore |
| **Reusable** | Same command reuses same temp file |
| **Fallback** | Graceful degradation if hook fails |

## Limitations

| Limitation | Impact | Mitigation |
|------------|--------|------------|
| Hook reliability issues | May not always fire | Monitor and report issues |
| Undocumented edge cases | Unknown behaviors | Test thoroughly |
| File I/O overhead | Small performance cost | Negligible for background tasks |
| Temp file accumulation | Disk usage | .gitignore prevents commit |

## Testing Strategy

1. **Unit Tests:**
   - `should_intercept()` with various command patterns
   - `extract_python_code()` with quote variations
   - `get_temp_file_path()` determinism

2. **Integration Tests:**
   - Hook doesn't fire for simple commands
   - Hook fires and converts complex commands
   - Temp file is created correctly
   - Modified command executes successfully

3. **Edge Cases:**
   - Empty python -c
   - Nested quotes
   - Windows paths with backslashes
   - Multi-line code
   - Unicode characters
