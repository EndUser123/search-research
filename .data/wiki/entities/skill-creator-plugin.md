# Skill-Creator Plugin

## What It Is

A meta-skill for Claude Code that automates the creation, testing, evaluation, and optimization of custom skills.

## Core Workflow

1. **Capture skill intent** — what the skill should do
2. **Draft SKILL.md** with YAML frontmatter and instructions
3. **Generate test cases** for the skill
4. **Run benchmarks** with and without the skill
5. **Review quantitatively** — measure improvement

## Key Features

- Structured workflow for skill development
- Quantitative evaluation (benchmarks)
- Test generation
- Skill optimization loop
