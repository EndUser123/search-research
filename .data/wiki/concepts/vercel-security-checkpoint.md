# Vercel Security Checkpoint

## Decision context

**Definition:** A browser verification layer implemented by Vercel that blocks automated content retrieval and requires JavaScript execution to proceed. The transcripts in this collection were captured during automated video processing attempts that triggered this verification mechanism, resulting in the security checkpoint page being recorded instead of the intended video content.

## Operational details

- The security checkpoint displays 'We're verifying your browser' as a prerequisite for accessing the requested content
- JavaScript must be enabled for the verification process to complete successfully
- The checkpoint generates unique verification tokens embedded in the URL path, structured as datacenter identifier, timestamp, and a hash component
- Verification tokens follow the pattern: datacenter::timestamp-hash (e.g., pdx1::1774886060-XGKEXZMcusVFs2nQdfHYRq4wqQAAedFP)
- Different datacenter identifiers appear across sources including 'pdx1' and 'cpt1'
- The checkpoint is accessible via the URL path /security-checkpoint at vercel.link domain
- CloudFront CDN also blocks access with 403 errors when security checks are triggered
- The checkpoint appears to be part of Vercel's bot detection and mitigation infrastructure
