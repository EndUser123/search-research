# Claude Code Skill Failure Patterns

## Top 10 Failure Patterns (Ranked by Frequency/Impact)

| # | Pattern | Symptom | Root Cause | Fix |
|---|---------|---------|------------|-----|
| 1 | **Skill Substitution** | Loads skill but analyzes vs executes | Ignores EXECUTION protocol | SKILL.md: "IMMEDIATELY Bash(...) NO analysis" + `allowed-tools: Bash` |
| 2 | **Enum Guessing** | Hallucinates file/tool names | No ls/dir first | Prefix: "Bash(ls .claude/skills) before invoke" |
| 3 | **Step Skipping** | Jumps to output, misses validation | Weak sequencing | Number steps 1-N; "Complete 1 before 2" + PreResponse hook |
| 4 | **Output Format Drift** | Wrong line breaks/omits verbatim | Summarizes | "PASTE VERBATIM in ``` block. NO edits" + template |
| 5 | **Error Swallowing** | Ignores failures, improvises | No recovery path | "If error: Output [ERROR:<exact>]. STOP" |
| 6 | **Mega-Skill Syndrome** | Works simple, fails complex (60%→90% post-split) | Overloaded context | Partition into 7 micro-skills (scope/execute/validate) |
| 7 | **Activation Misses** | No trigger despite /skill | Weak desc/keywords | YAML: `triggers: ["/yt-channel", "channel stats"]`; <100 token desc |
| 8 | **Over-Spec CLAUDE.md** | Ignores rules in noise | >15k chars | Prune to <2k chars; use hooks for enforcement |
| 9 | **Patch Spiral** | Contradictory rules accumulate | No re-test | Post-edit: baseline re-run + /clear |
| 10 | **Context Pollution** | Failed attempts bias future | No reset | After 2 fails: `/clear` + learned prompt |

## Key Frameworks

### PVE (Plan-Validate-Execute)

For batch/exec operations:

```
1. PLAN: dry-run → create manifest
2. VALIDATE: check readiness before execute
3. EXECUTE: run for real
4. VERIFY: compare vs plan
```

**Example for yt-channel**:
```bash
# PLAN
Bash(csf-source check-all --dry) → channels.json

# VALIDATE
Bash(validate-channels.py channels.json) → [OK/ERROR:<msg>]

# EXECUTE
Bash(csf-source check-all) → verbatim output

# VERIFY
Compare output vs plan; flag deltas
```

### SALT Framework

For reliable agent/skill design:

- **Specific**: <100 token description; exact triggers
- **Actionable**: Numbered 1-N steps; allowed-tools list
- **Layered**: Micro-skills over monoliths
- **Tested**: Baseline 10 runs; log failures

## Context Degradation Over Sessions

### Causes

1. **Context Inflation**: Failed attempts bloat window → signal/noise drops
2. **Attention Decay**: Long sessions → ignores CLAUDE.md rules
3. **Accumulated Bias**: Uncorrected hallucinations persist

### Reset Workflows

- `/clear + learned prompt` — beats long sessions 2x
- **Checkpoint + Resume**: decisions.log/SESSION.md
- **Git Atomic**: Commit per phase; `/clear` safe
- **Parallel Sessions**: Multi-terminals; merge via worktrees

### Decisions Log Pattern

Add to CLAUDE.md:

```markdown
## DECISIONS LOG
# | Decision | Alts | Rationale | Status
1 | yt-channel: Bash(csf-source) verbatim | Summarize | Substitution fails 95% | ACTIVE
2 | Format: Single line {url} {stats} | Multi-line | csf-source fix | ACTIVE
```

## Recovery Path Best Practices

- **Explicit**: "If Bash fails: [RECOVERY: ls; retry]"
- **Scripted**: Dedicated recovery.py/recover.sh
- **Guarded**: Max retries (3); fallback to human (/escalate)
- **Observable**: Log to recovery.log
- **Edge cases**: Network fail → offline cache; DB stale → timestamp check
