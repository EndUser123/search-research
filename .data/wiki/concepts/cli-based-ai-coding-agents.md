# CLI-Based AI Coding Agents

## Decision context

**Definition:** Command-line interface tools that leverage large language models to provide conversational code editing, exploration, and modification capabilities directly within developer terminals, representing a category of open-source AI coding assistants that operate independently of integrated development environments.

## Operational details

- These agents operate as terminal-based applications that accept natural language instructions to perform code tasks such as file manipulation, searching, and version control operations.
- The tools function as open-source projects available on GitHub under various licenses, including Apache 2.0 for Mistral Vibe.
- Many implementations utilize the Model Context Protocol (MCP) for extensibility and integration with external tools, as evidenced by code-health analysis tools and agent frameworks.
- The agents provide interactive chat interfaces for conversational interaction with the codebase, breaking down complex tasks into manageable steps.
- Tool availability varies across implementations, with some offering comprehensive suites including file manipulation, code searching, and version control capabilities.
- Agent frameworks like Qwen-Agent support function calling, code interpretation, and retrieval-augmented generation (RAG) patterns.
