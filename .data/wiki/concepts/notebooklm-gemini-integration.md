## Operational details

- NotebookLM has been rebranded as Gemini Notebook, fully integrated into the Gemini ecosystem with access to faster models, smarter reasoning, and larger context windows
- The system acts as a synchronized ecosystem where NotebookLM's document handling and Gemini's chat capabilities exist in one unified interface, eliminating the need for manual context re-entry
- A single prompt can trigger a multi-step automated research workflow that searches the web, analyzes documents, writes code, builds spreadsheets, creates presentations, and generates explanatory audio
- NotebookLM 2.0 introduced code execution capabilities, allowing the system to run code directly rather than just suggesting it
- The system transforms static sources (PDFs, notes, research documents) into multiple output formats including summaries, study guides, and short vertical videos
- Context persistence means the AI retains memory of all previously uploaded documents without requiring users to re-explain background information
- The platform functions as an AI operating system for entire knowledge bases, moving beyond basic document summarization
