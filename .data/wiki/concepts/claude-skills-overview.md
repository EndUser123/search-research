# Claude Skills Overview

## Decision context

**Definition:** Claude Skills are reusable instruction packages that users create once and Claude retains across conversations, enabling repeatable task execution without repetitive prompting. They represent a core capability within the Claude Code ecosystem for extending AI functionality.

## Operational details

- A skill functions as a repeatable task triggered on demand, packaged once and executed repeatedly without requiring the user to re-enter instructions each session
- Skills differ from CLAUDE.md files (which provide persistent memory and context), MCPs (which connect Claude to external applications), and subagents (which handle tasks requiring conversation splitting for large workloads)
- Skills can be enhanced by incorporating 'ask user question' prompts, which format interactions into structured, sequential questions rather than presenting questions as a single text block
- The approach of adding deterministic algorithms to skills has been reported to reduce AI drift and hallucination in workflows by approximately 95-98%
- Anthropic's own Claude Code implementation utilizes nine distinct skills, while community-built systems have expanded to include 181 skills with 47 subagents and 79 readymade commands
- Skills operate alongside preset packs (plugins combining multiple configurations) and connectors (integrations with external services like Gmail, Slack, Google Calendar)
- Skills can be created from scratch using custom instructions and can be shared publicly or kept private depending on security considerations
