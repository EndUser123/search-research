# Free Open Source Self Hosted Tools

## Decision context

**Definition:** A category of software projects that are freely available with source code, designed to run on user-controlled infrastructure without recurring subscription costs. These tools span AI assistance, API development, automation, security testing, and identity management domains, offering privacy-preserving alternatives to cloud-hosted services.

## Operational details

- Self-hosted AI workspaces enable local execution of chat, agents, research, documents, email, notes, and calendar functionality on user hardware without transmitting data externally (Source 2, 10, 15)
- Open-source API clients keep collections as plain files in user git repositories rather than vendor clouds, supporting REST, GraphQL, gRPC, WebSockets, and server-sent events (Source 11)
- Free AI coding assistants connect to multiple model providers including OpenAI-compatible APIs, Gemini, GitHub models, Codex, and others through unified interfaces (Source 4, 13)
- Relay tools expose LLM subscriptions as API services, making paid provider access available to tools that typically require per-token payment (Source 9)
- Open-source automation platforms connect to over 400 applications while keeping data on user-controlled servers (Source 17)
- Free security testing platforms provide offensive security capabilities including visual fuzzing, passive scanning, and reverse connections (Source 12)
- Identity management solutions provide Single Sign-On (SSO), OAuth, and full authentication stacks previously available only through expensive enterprise licensing (Source 17)
- One-click deployment systems allow installation of multiple AI and development applications on a single server through graphical interfaces (Source 6)
- Open-source networking tools combine secure mesh networks with reverse proxy and DNS server capabilities under unified management (Source 16)
- Wealth tracking applications provide multi-account portfolio management for stocks, ETFs, and cryptocurrencies with full transaction management (Source 1)
