# Adaptive Teaching Skills

## Decision context

**Definition:** Adaptive teaching skills are AI-powered methods that personalize instruction based on individual learner preferences and maintain session continuity. These approaches distinguish between stateful and stateless execution models, enabling persistent learning experiences that align with a learner's specific mission and learning style.

## Operational details

- The teach skill operates as a stateful system that retains memory across runs, unlike stateless skills which do not preserve any information from previous executions
- Four foundational learning skills structure effective learning: retrieval, encoding, mind mapping, and skill acquisition, with the first two focusing on memory retention and deep comprehension
- The Rikai technique emphasizes deep compression of information, encouraging learners to read with precision rather than passively collecting facts
- Study notebook tools function as personal tutors, customizing lessons and assessments based on the learner's specific objectives such as certification exam preparation
- Effective note-taking leverages core learning skills to accelerate comprehension and retention
