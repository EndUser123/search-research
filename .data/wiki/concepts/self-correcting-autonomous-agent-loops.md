# Self-Correcting Autonomous Agent Loops

## Decision context

**Definition:** An iterative execution paradigm where AI agents continuously generate, assess, and correct outputs using internal or external feedback loops to achieve verifiable goals without manual intervention.

## Operational details

- Behavior Trees (BTs) are used for orchestration, allowing for local correction where only a failing sub-branch is modified while the rest of the hierarchy remains intact (Source 1).
- The 'Ralph Loop' (or Persistence Loop) pattern uses an external script-based hook to intercept premature exits, ensuring the agent continues until a specific 'COMPLETE' string marker is detected in the output (Source 11).
- Hierarchical Error-Corrective Graphs (HECG) utilize a threshold-based transition policy to switch between main execution, optional alternative actions, and fallback recovery based on measured local execution errors (Source 13).
- Pydantic V2 models are employed for recursive schemas (UniversalNode) to provide strictly typed, serializable representations of complex tree-based agent logic (Source 1, Source 14).
