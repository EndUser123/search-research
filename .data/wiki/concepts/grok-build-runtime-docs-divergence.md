# Grok Build runtime/docs divergence

## The gap

The workspace's documentation describes a runtime that isn't running:

- `P:/.claude/CLAUDE.md` describes a constitution with 38 in-process Stop gates
- `P:/.claude/hooks/HOOKS_CATALOG_v3.md` enumerates them
- `/check` skill references `preprocessor.py` and evidence packets
- `/review` skill references specialist dispatch and verify passes
- Multiple SKILL.md files reference cc-aca-* routers

**None of these fire under Grok Build.** `~/.grok/config.toml` has
`compat.claude.hooks=false`. The cc-aca-* plugin suite (28 plugins) is
disabled. The runtime has permission rules and skill dispatch — but none
of the verification/enforcement hooks the docs describe.

## How this causes failures

New sessions read the docs → internalize the described enforcement → propose
changes assuming enforcement exists → discover it doesn't. This happened
repeatedly in the 2026-07-20 session:
- Model assumed `PreToolUse_bulk_delete_gate.py` was firing (it wasn't)
- Model assumed `Stop_verification_gate.py` was checking claims (it wasn't)
- Model proposed adding to `Stop.py` (which isn't invoked by Grok)

## What IS active under Grok Build

| Layer | Active? |
|-------|---------|
| Permission rules (via `compat.claude.rules=true`) | ✅ Yes |
| Catastrophic-deny patterns in `.claude/settings.json` | ✅ Yes |
| Grok-native hooks (`~/.grok/hooks/*.json`) | ✅ Yes |
| Grok-native plugins (superpowers, exec-gate, etc.) | ✅ Yes |
| Claude-side hook dispatch (`Stop.py`, PreToolUse routers) | ❌ No |
| cc-aca-* enforcement suite (28 plugins) | ❌ No (disabled) |
| `~/.grok/active-surface.last.md` snapshot | ✅ Yes (read this first) |

## The active-surface snapshot

A Grok-native SessionStart hook writes `~/.grok/active-surface.last.md`
enumerating what's actually firing. **Read this before trusting any
documented enforcement.** The snapshot includes dynamically enumerated
Claude-side hook files (from `P:/.claude/hooks/*.py`) all marked "NOT firing."

## Resolution options (not yet decided)

1. **Mark docs as historical** — add banners to CLAUDE.md, HOOKS_CATALOG_v3.md
2. **Port enforcement to Grok-native hooks** — selective, one gate at a time
3. **Accept divergence** — rely on the active-surface snapshot to bridge

Option 3 is the current state (as of 2026-07-20). The snapshot exists but
hasn't been validated across multiple sessions yet.
