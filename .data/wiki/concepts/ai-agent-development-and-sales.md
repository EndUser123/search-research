# AI Agent Development and Sales

## Decision context

**Definition:** AI agents are software entities that understand instructions and take action to automate tasks, often built using no-code platforms and sold as business solutions. ## Operational details

- AI agents can be built using no-code platforms like n8n, allowing users to create workflows without programming experience
- Multi-agent architectures involve parent agents delegating tasks to child agents, enabling distributed task processing
- Agents can be connected to external services through tools such as Gmail, Google Calendar, Slack, and Google Sheets
- Voice-enabled agents can be created using services like ElevenLabs for speech synthesis and real-time conversation
- AI agents can be sold as standalone products or integrated into existing business workflows
- Common use cases include personalized outreach, client onboarding, travel planning, and newsletter creation
- The parent-child agent pattern allows agents to coordinate and communicate results back to a central system
- Agents can be triggered via various channels including Telegram, WhatsApp, webhooks, and forms
- Building agents for specific business problems (lead qualification, CRM updates, email notifications) addresses actual market demand
- Agents can be designed to generate and coordinate sub-agents for complex task completion
