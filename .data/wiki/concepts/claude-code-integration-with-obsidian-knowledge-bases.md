# Claude Code Integration with Obsidian Knowledge Bases

## Decision context

**Definition:** Claude Code can integrate with Obsidian as a personal knowledge management system, enabling AI-assisted organization of notes, documents, and research materials. This approach leverages Obsidian's markdown-based structure and bidirectional linking capabilities alongside Claude Code's ability to perform actions and answer questions about the note collection.

## Operational details

- The integration uses Claude Code CLI skills to create and manage Obsidian notes from various data sources including emails and local files
- Claude Code can act as an AI assistant to perform actions on notes and answer questions about the knowledge base
- The Obsidian vault serves as the canvas for building a second brain system that Claude Code can query and maintain
- Multiple plugins and MCP servers exist to enhance the Obsidian-Claude Code integration, including hybrid search capabilities combining BM25 and semantic search
- The approach supports organizing projects, research topics, and various content types within a linked note structure
