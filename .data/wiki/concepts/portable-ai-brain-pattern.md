# Portable AI Brain Pattern

## Decision context

**Definition:** A method for providing AI systems with persistent, transportable context that transcends individual conversation sessions and tool boundaries. The approach involves creating structured knowledge files that define a user's world—business context, preferred writing style, and operational parameters—which any AI can read and apply consistently.

## Operational details

- The pattern addresses the fundamental limitation that AI conversations reset when closed, requiring users to re-explain context repeatedly across sessions and tools.
- Implementation typically uses a folder structure of markdown files that describe the user's business, customers, metrics, and preferences in plain language readable by any AI system.
- Google Drive is identified as a common base storage option for the knowledge files, though with limitations in sophistication.
- The approach differs from native tool memory features by providing a permanent, user-controlled knowledge base rather than relying on proprietary AI memory systems.
- Key technical requirements include maintaining the folder structure so that any AI can parse and apply the context across different platforms (Claude, ChatGPT, Gemini).
- The method enables a user to build context once and have it instantly available to every AI tool they use, addressing the fragmentation of context across different AI platforms.
- One source ties this pattern to the OODA loop decision framework, integrating it into a broader 'infinite brain' system for AI-augmented decision making.
- Complementary open standards like OKF (Open Knowledge Format) provide standardized structures for agent durable knowledge alongside the portable brain concept.
