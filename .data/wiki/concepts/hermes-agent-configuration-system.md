## Operational details

- The mixture-of-agents approach consults multiple different AI models from various providers and sends their outputs to a single aggregator model for synthesis before producing a final response.
- Each profile can have its own soul.md file containing unique skills, personality traits, and behavioral instructions that shape how the agent responds to queries.
- The portable version can run directly from a USB flash drive or external storage device across Windows, Linux, and Mac platforms, maintaining consistent chats, memory, and API key configurations between machines.
- The agent platform supports web search capabilities, code writing, and Python script execution as core functional features.
- The agent learns and improves over time based on usage patterns, becoming increasingly personalized to the user's preferences.
- Real-time X (formerly Twitter) search integration is available through Grok or Super Grok subscription tiers on premium-plus plans.
- Profile creation enables users to train agents on specific voice and writing style preferences for targeted content generation tasks.
