# Codebase Knowledge Graph Mapping

## Decision context

**Definition:** A technique where AI coding assistants build a persistent map of a codebase's symbols, functions, and their interconnections by parsing the source code, enabling the agent to query the graph instead of repeatedly reading files during tasks.

## Operational details

- The graph construction scans the entire repository once, extracting every file, function, class, and dependency into an interactive knowledge graph representation
- TreeSitter is commonly used as the parsing engine to analyze code structure and relationships between symbols
- This approach reduces agent tool calls by approximately 70% compared to file-by-file reading, as the agent queries the map rather than opening multiple files to search for specific functions
- Each node in the resulting graph represents a real piece of code (function, class, or file) with plain-English explanations of its purpose and relationships
- The graph enables dependency-ordered traversal and allows developers to click nodes to understand the codebase without reading raw files
- For large repositories (e.g., 100,000+ files), this eliminates the inefficient fan-out pattern where agents open multiple wrong files searching for a single function
- Some implementations support mapping additional content beyond code, including documentation, PDFs, images, and videos into the knowledge graph
