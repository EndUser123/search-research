# Local LLM Inference Engines

## Decision context

**Definition:** Local LLM inference engines are software frameworks that enable running large language models on personal hardware, offering alternatives to cloud-based API services by providing local model management, optimization techniques, and OpenAI-compatible endpoints.

## Operational details

- Ollama serves as a model management layer that downloads, organizes, and serves GGUF-formatted model files through a REST API, abstracting away quantization complexity
- llama.cpp functions as the underlying compute engine that performs matrix multiplications on CPU/GPU using quantized weights stored in GGUF format, with llama-server.exe providing an OpenAI-compatible API
- vLLM, Ollama, LM Studio, and llama.cpp represent distinct design philosophies for local inference, each with different optimization approaches and hardware utilization patterns
- Inference engines use KV cache quantization, flash attention, and Mixture of Experts (MoE) architectures to reduce VRAM requirements, enabling larger models on limited hardware
- Local inference engines achieve zero API costs by running models entirely on-user owned hardware, eliminating per-token charges associated with cloud services
- The Haven VLM Connector plugin enables local multimodal inference by routing base64-encoded video frames through a local llama-server.exe process via OpenAI-compatible API endpoints
- Flash attention optimization is cited as a key technique that makes running large models on limited VRAM not just possible but fast
