# Claude Code launches proxy tool to run models for free #claudecode #aiproxy #openaialternatives
someone just built a GitHub repo that lets you run Claude code for free and it already has over 16,000 stars here's how it works normally Claude Code sends requests directly to Anthropics models this tool drops a lightweight proxy in between and reroutes those requests to a completely different model that could be DeepSeek Ky Open Router or even a local model on your own machine and here's the wild part claude code doesn't really know the difference same interface same workflow but the model doing the actual work is completely different you can even route different model types to different providers depending on the task setup is simple just a couple of environment variables and you're ready to go
