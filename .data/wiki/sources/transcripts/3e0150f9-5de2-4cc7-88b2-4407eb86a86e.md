5. DESIGN INTENT AND NON-NEGOTIABLES
Architectural Pillars
4-tier evidence hierarchy
 — Tier 0 < Tier 1 < Tier 2 < Tier 3
Fast-fail Tier 0
 — Catch configuration issues before expensive tests
Evidence-based
 — Every tier shows actual test/execution output
Multi-agent strategy
 — Different agents for each tier to reduce bias
Prohibited Claims
Claim "verified" without running all 4 tiers (real-time mode)
Claim "verified" without TSR >= 95% threshold (post-hoc mode)
Skip Tier 0 (checklist) or Tier 3 (e2e) execution evidence
Generate report without evidence from each tier
Use post-hoc mode without plan artifact
Constitution Alignment
PART T (Truthfulness)
: Report all failures, don't hide tier mismatches
PART P (Testing Workflow)
: Systematic validation with evidence required
PART L (Success Protocol)
: Do not claim "verified" without all 4 tiers passing
