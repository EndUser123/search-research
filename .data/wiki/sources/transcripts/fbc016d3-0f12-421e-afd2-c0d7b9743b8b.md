What is Shipyard?  
 Shipyard is an ephemeral environment platform. It automatically spins up a full-stack, isolated copy of your app for every pull request. Each environment is hydrated with a fresh copy of your data. Developers and agents use these environments to test high-impact code changes without the risk of taking down staging or production. 
What are ephemeral environments?  
 Ephemeral environments (also called preview environments or PR environments) are short-lived, isolated replicas of your application spun up per branch or pull request. These prevent infra-related bottlenecks, since multiple developers and/or agents can test in parallel without waiting for a shared staging or test environment. Ephemeral environments spin down when idle, and are deleted when a PR is merged. 
How does Shipyard integrate with AI coding agents?  
 Shipyard’s ephemeral environments are 100% agent-accessible. Agents can manage them via the Shipyard MCP and CLI, and use the Playwright MCP and CLI for visual testing and debugging. Some users define workflows that let agents autonomously spin up Shipyard environments, grab logs, run tests, and iterate until a PR is ready for merge. 
How does Shipyard reduce cloud costs?  
 Environments scale to zero when idle and are deleted automatically when a PR closes. Teams typically see 30–62% savings on pre-production cloud spend. 
Is Shipyard secure?  
 Yes. Every environment runs in a single-tenant, fully sandboxed Kubernetes cluster, and your code and data never reside on Shipyard’s internal infra. All data is transmitted over SSL/TLS and encrypted end-to-end. Environment variables are treated as secrets by default, encrypted at rest and in transit. Our infrastructure is hosted in ISO 27001, FedRAMP, SOC 1, and HIPAA-compliant data centers.
