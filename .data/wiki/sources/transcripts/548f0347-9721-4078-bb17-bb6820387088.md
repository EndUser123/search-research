--

The year 2025 has seen an explosion of open-source projects aimed at building and enhancing AI agents. GitHub’s latest Octoverse report highlights that over 4.3 million AI-related repositories now exist 

(a 178% YoY jump in LLM-focused projects)

https://ragflow.io/blog/ragflow-named-among-github-fastest-growing-open-source-projects#:~:text=As%20the%20Octoverse%20report%20highlights%2C,grade%20AI%20workflows

. In this environment, certain new repos skyrocketed in popularity — garnering tens of thousands of stars — by empowering developers to create autonomous workflows, integrate advanced models locally, and streamline AI development.

In the blog below, let’s take a look at the ten most-starred 

GitHub agentic AI repositories

https://opendatascience.com/top-10-trending-open-source-ai-repositories-starting-off-2025/

 in 2025 and explore why they’ve earned such acclaim.

n8n (160k+ ★)

n8n

https://opendatascience.com/top-10-trending-open-source-ai-repositories-starting-off-2025/

 is an open-source workflow automation platform that combines a visual no-code interface with code flexibility, now supercharged with native AI capabilities. With 400+ integrations, n8n enables technical teams to build powerful automation pipelines while maintaining full control. Notably, n8n introduced an “AI-native” approach, letting users incorporate large language models (e.g. via LangChain) into their workflows to create custom AI agent automations. This ability to build AI-driven agents and multi-system flows — all self-hosted under a fair-code license — has made n8n immensely popular. It surpassed 150,000 GitHub stars in 2025.

This reflects its status as a go-to platform for bridging traditional automation with cutting-edge AI, hence seeing more GitHub agentic AI repositories.

Langflow (140k+ ★)

Langflow

https://opendatascience.com/top-10-trending-open-source-ai-repositories-starting-off-2025/

 is a powerful low-code platform for designing and deploying AI-powered agents and retrieval-augmented workflows. Think of it as a visual builder for LLM applications: Langflow provides a drag-and-drop interface to construct chains of prompts, tools, and data sources (built on the LangChain framework). It comes with support for all major large language models, vector databases, and a growing library of AI tools.

Developers can visually orchestrate multi-agent conversations, manage memory and retrieval, and then deploy those flows as APIs or stand-alone apps. This ease of use and versatility propelled Langflow to around 140k stars on GitHub. By democratizing the creation of complex AI agent pipelines (no extensive coding required), Langflow has attracted a thriving community of data scientists and engineers looking to prototype and share LLM-driven applications.

DeepSeek-V3 (100k+ ★)

DeepSeek-V3

https://opendatascience.com/top-10-trending-open-source-ai-repositories-starting-off-2025/

 gained attention as “the best-performing open-source model” of its time, with benchmark results rivalling those of frontier closed models. It’s essentially an open, large language model (with a massive MoE architecture) optimized for 

general-purpose 

https://aiagentindex.mit.edu/deepseek-v3/#:~:text=Website%3A%20https%3A%2F%2Fweb

reasoning and agent use-cases. In practice, DeepSeek-V3 enables developers to run a GPT-4-class model under an open license, powering chatbots and autonomous agents without reliance on proprietary APIs. The project’s team introduced novel training techniques (like distilled reasoning chains and ultra-long 128K context support) that set new standards in the open model community.

By late 2025, DeepSeek-V3 had well over 100k stars on GitHub, as practitioners flocked to this open alternative to GPT-4. Its popularity underscores the demand for top-tier AI models that the community can freely use, fine-tune, and integrate into custom agent systems.

Google Gemini CLI (87k ★)

Gemini CLI

https://aiagentindex.mit.edu/deepseek-v3/#:~:text=Website%3A%20https%3A%2F%2Fweb

 is an open-source AI agent released by Google that brings the power of the Gemini multimodal model directly to developers’ terminals. With a simple CLI tool (npx installable), developers can chat with or instruct the Gemini model from the command line, integrate it into scripts, or use it in IDEs. This tool effectively democratized access to Google’s cutting-edge model (a competitor to GPT-4) by abstracting away the complexity of API calls. Gemini CLI supports code assistance, natural language queries, and integration with Google Cloud services — all through text commands.

It quickly amassed 80k+ stars by the 

fall of 2025 

https://buttondown.com/agent-k/archive/llm-daily-october-11-2025/#:~:text=%E2%80%A2%20Open,Gemini%20CLI%20surpassing%2078K%2B%20stars

and has since grown further. The appeal lies in its plug-and-play simplicity: AI engineers can leverage a state-of-the-art model in workflows and applications without needing a separate UI, making Gemini’s capabilities readily accessible for both experimentation and production.

Dify (120k+ ★)

Dify

https://buttondown.com/agent-k/archive/llm-daily-october-11-2025/#:~:text=%E2%80%A2%20Open,Gemini%20CLI%20surpassing%2078K%2B%20stars

 is a “production-ready platform for agentic workflows,” providing an all-in-one toolchain to build, deploy, and manage AI applications. Written in TypeScript, Dify acts as a comprehensive backend for creating anything from enterprise QA bots to AI-driven forms and custom assistants. It supports local or cloud deployment and integration with multiple AI models (OpenAI, open-source LLMs, etc.). Dify’s workflow builder allows developers to define tool-using agents, set up retrieval augmented generation (RAG) pipelines, and monitor usage — all with relatively minimal coding. The project gained 114K+ stars by late 2025, indicative of its strong adoption.

Developers praise Dify for streamlining the path from prototype to production: it abstracts away boilerplate infrastructure and lets teams focus on crafting the logic of their AI agents. In short, Dify fills a crucial gap for those who want to stand up ChatGPT-like services or agent-based products quickly, under an open-source and self-hostable framework.

GitHub Spec Kit (55k ★)

Spec Kit

https://buttondown.com/agent-k/archive/llm-daily-october-11-2025/#:~:text=%E2%80%A2%20Open,Gemini%20CLI%20surpassing%2078K%2B%20stars

 by GitHub is a toolkit that introduces a new paradigm called Spec-Driven Development (SDD) — essentially using AI to generate and maintain code from structured specifications. This open-source project provides a CLI (specify) and workflow that works with tools like GitHub Copilot, Anthropic Claude, and even Gemini CLI. Developers write a plain-language or formal spec for a feature, and the AI agents (via Spec Kit) help generate implementation code, test plans, and more following that spec. The Spec Kit repository, launched in 2025, quickly accumulated 50k+ stars as it resonated with software engineers seeking more structure in AI-assisted coding.

By treating specs as executable artifacts rather than throwaway docs, Spec Kit allows teams to leverage AI coding assistants in a controllable way. Its popularity stems from addressing a real pain point: it brings order to 

AI-assisted coding

https://blog.logrocket.com/github-spec-kit/#:~:text=Exploring%20spec,using%20Copilot%2C%20Claude%2C%20or%20Cursor

, helping developers avoid the chaos of “prompt-and-pray” by embedding agents in a predictable development process. This makes AI coding assistants far more practical for large projects.

Ollama (160k+ ★)

Ollama

https://blog.logrocket.com/github-spec-kit/#:~:text=Exploring%20spec,using%20Copilot%2C%20Claude%2C%20or%20Cursor

 is a lightweight, extensible framework for running and managing large language models locally on your own hardware. In an era of massive cloud APIs, Ollama went against the grain by enabling offline and private LLM deployment with ease. It works as a one-stop solution to download and serve models (like Llama 2, GPT-OSS, etc.), providing simple commands to run chat or completion sessions on a PC or server. In 2025, OpenAI’s open-weight model GPT-OSS (their partially open-source GPT) was made available, and Ollama partnered to make running GPT-OSS-20B and larger variants trivially easy.

This caused a surge of interest — developers could now experiment with advanced LLMs without sending data to third parties. Ollama’s focus on user-friendly local inference (including a desktop app for Mac/Windows) propelled it to 150k+ stars. The project is celebrated for empowering developers to build AI agents with local models, which is vital for use cases requiring data privacy, customization, or working within air-gapped environments.

Claude Code (46k ★)

Claude Code

https://blog.logrocket.com/github-spec-kit/#:~:text=Exploring%20spec,using%20Copilot%2C%20Claude%2C%20or%20Cursor

 is an “agentic coding tool that lives in your terminal” — essentially, Anthropic’s answer to GitHub Copilot CLI. It integrates Anthropic’s Claude AI assistant with your local development workflow. Once installed, Claude Code can understand your entire codebase context and execute developer commands via natural language (e.g. “refactor this function,” “explain this file,” or even “generate a unit test here”). It automates routine programming tasks and can handle git operations, all guided by conversation. Launched in mid-2025, Claude Code quickly gained traction as an open-source project (with a permissive license) complementary to closed offerings. It reached tens of thousands of stars on GitHub within months.

The enthusiasm is due to its promise of a fully on-device AI coding assistant: developers get the experience of an AI pair programmer that is deeply aware of their project and can act autonomously on code, without sending data to external services. Claude Code epitomizes the trend of agentic AI moving into core developer tooling — boosting productivity while keeping the human in control.

RAGFlow (70k ★)

RAGFlow

https://blog.logrocket.com/github-spec-kit/#:~:text=Exploring%20spec,using%20Copilot%2C%20Claude%2C%20or%20Cursor

 is an open-source engine for Retrieval-Augmented Generation that “fuses cutting-edge RAG with agent capabilities to create a superior context layer for LLMs. In simpler terms, RAGFlow helps developers build AI applications that can search and reason over external knowledge (documents, databases, APIs) before generating answers — a critical feature for enterprise chatbots, assistants, and data analysis agents. It provides an end-to-end framework: from document ingestion and vector indexing to query planning and tool-using agents that fetch information as needed.

RAGFlow’s built-in agentic toolkit allows it to not only retrieve text but also invoke other tools or APIs, making it a robust platform for building knowledge-grounded AI agents. The project saw rapid community adoption (around 70k stars) as companies looked to move beyond toy examples and prototype real production systems. In fact, GitHub’s Octoverse 2025 report noted RAGFlow as one of the fastest-growing projects, reflecting surging demand for production-ready AI workflows. By enabling reliable retrieval, citation tracking, and multi-step reasoning, RAGFlow has become a backbone for many advanced QA systems and agent-driven apps.

Pathway (50k ★)

Pathway 

https://blog.logrocket.com/github-spec-kit/#:~:text=Exploring%20spec,using%20Copilot%2C%20Claude%2C%20or%20Cursor

is a Python ETL framework for streaming data that bridges real-time analytics with LLM pipelines and RAG (Retrieval-Augmented Generation). While not an “agent” in the classic sense, Pathway addresses a key need in the AI agent ecosystem: feeding live data to and from AI models in production. It lets developers build pipelines that continuously process events (from databases, message queues, etc.), transform data, and pass context into LLM-based components (like a summarization or question-answering step) on the fly. Under the hood, Pathway uses a Rust-powered engine for high-performance incremental computation, meaning it can handle both batch and streaming workloads efficiently.

In 2025, as enterprises started deploying AI agents that must react to real-time data (think monitoring systems, live customer support bots, dynamic dashboards, etc.), Pathway’s approach gained significant traction. It accumulated 50k+ stars, indicating broad interest from data engineers and ML engineers alike. By providing a unified framework for live data and AI, Pathway makes it easier to build AI systems that are continuously updated and responsive — an essential capability for the next generation of smart applications.

Conclusion on the Top GitHub Agentic AI Repositories

The rise of these open-source repositories in 2025 sends a clear message: AI agents are no longer just experimental — they’re becoming essential. Whether it’s n8n streamlining automation, Langflow simplifying orchestration, or platforms like DeepSeek and Ollama enabling local, high-performance model deployment, each project reflects the community’s growing demand for transparency, flexibility, and production-ready tools. From developer-first workflows to cutting-edge code copilots, what unites them is a commitment to making AI agents easier to build — and more powerful to scale.
