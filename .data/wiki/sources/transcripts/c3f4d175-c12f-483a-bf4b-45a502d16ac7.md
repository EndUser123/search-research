hi welcome to another video so hermes agent 0.14 is out and this one is called the foundation release and honestly the name makes sense this update is not really about one shiny feature it is about installation hermes agent is now available as a proper pippi package so instead of cloning the repo and running a custom setup you can install it with pip install hermes- agent and then run hermes that is a very important change because if an agent tool is hard to install many people will never even reach the good part this makes hermes feel much more approachable the second big change is debloating hermes used to pull in a lot of extra dependencies for things you might not even use messaging adapters browser pieces voice tools image tools and all that sort of stuff could make the install heavier than necessary now many of those heavier parts are lazy installed when you actually need them so the basic setup should be lighter and hermes should feel cleaner on normal machines small vps setups and local laptops they also worked on cold start performance in normal terms hermes should open faster load less unnecessary stuff at startup and feel less annoying when you just want to start a session quickly this is not the flashiest feature but it matters a lot in daily use now the most interesting feature for coding agent users is probably the new openai compatible local proxy or super grock so tools like codeex cli ader klein continue or your own scripts can point at hermes as the endpoint this is pretty cool because instead of setting up a separate api key for every tool
