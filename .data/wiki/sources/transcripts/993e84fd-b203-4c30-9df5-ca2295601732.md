Which version of LM Studio?

LM Studio 0.4.5 (Build 1)

Which operating system?

Windows

What is the bug?

When running Qwen3.5-35B-A3B, the llama.cpp backend silently disables KV cache reuse for this model, forcing a full cold prompt recompute on every single request. This results in significantly slower prompt processing (prefill). Multi-turn conversations are especially affected since the shared system prompt and conversation history must be recomputed on every turn.
