Behavior on Detection:

Load prior turn context from transcript file

Set flag for follow-up mode

Prevent standalone interpretation of fragment queries

Multi-terminal Safety: Session-isolated via session_id in state file path.

Component 2: Tool Availability Checker (PreToolUse)

Purpose: Verify tool/skill works before calling it — prevents calling /research when HyDE imports fail.

Check Sequence:

For skill invocations: Verify skill file exists and imports are valid (try import)

For bash commands: Command is already parsed by PreToolUse — no additional check

For MCP tools: Verify server is connected (via mcp__* tool availability)

Behavior on Failure: Fall back to alternative immediately, report unavailable tool.

Multi-terminal Safety: Stateless — each invocation is independent.
