# Google Antigravity 2.0: New Desktop App, CLI, and Gemini 3.5 Flash
google just did a full reset on how they packaged developer tools At Google IO 2026 they rolled out anti-gravity 2.0 a new CLI a fresh SDK and a faster model called Gemini 3.5 Flash The naming gets confusing fast so let me explain what actually changed before we get into the demo Anti-gravity started as a VS Code fork It was Google's answer to cursor and windsurf an IDE with aentic coding baked in Some of my friends use it daily but it never really sat at the top of the food chain Cursor and Claude Code were where most serious developers ended up So Google watched what happened with Codeex and Claude's desktop app and they pivoted The old IDE is still around and it's now called Anti-gravity IDE The new thing Antiggravity 2.0 is a standalone desktop app that has nothing to do with that VS Code fork It looks and behaves a lot more like codecs or the clawed desktop client That's the part most people are going to interact with going forward Around that desktop app Google built a whole family of products There's the anti-gravity CLI for terminal work the anti-gravity SDK for developers who want to build their own agents on top and the old anti-gravity IDE sitting off to the side for people who still want that integrated editor experience All four share the same agent harness underneath That's the part I find genuinely interesting When Google improves the core agent loop every surface benefits at the same time You're not stuck waiting on the CLI team to catch up to the desktop team The model running all of this is Gemini 3.5 Flash Google says it beats Gemini 3.1 Pro on almost every benchmark and runs about four times faster than other Frontier models Big claim The chart they showed on stage put it next to Claude Opus and GPT 5.5 on intelligence but way ahead on speed The catch is that this is the flash model not the Pro one Gemini 3.5 Pro isn't out yet Google said it's coming next month which makes me think they intentionally split the announcement so they get a second news cycle in June That's a fair business call but it means today we're testing the lighter model not the heavyweight Looking at the actual benchmark numbers Google published the picture is more interesting than the stage chart made it look On terminal bench 2.1 the agentic terminal coding test flash hits 76.2% which puts it above Gemini 3.1 Pro at 70.3 and just under GPT 5.5 at 78.2 On MCP Atlas the multi-step workflow benchmark using MCP Flash actually tops the chart at 83.6% 6% beating Claude Opus 4.7 GPT 5.5 and Pro Same story on Tulathlon and on the Finance Agent V2 benchmark where Flash leads at 57.9% over Opus and GPT The multimodal numbers are strong too On Charxive Reasoning and MMU Pro Flash is at the top of the table Where it falls behind is on the harder reasoning tests On humanity's last exam Flash scores 40.2% 2% versus Opus at 46.9 and Pro at 44.4 On Air Ragi2 Flash is at 72.1 which trails GPT 5.5 at 84.6 and even Gemini 3.1 Pro at 77.1 On S Bench Pro the diverse coding task set flash sits at 55.1 behind both Opus and GPT So the headline of beating pro on almost every benchmark is roughly accurate but the more honest read is that flash trades blows with the frontier on agent and coding tasks and falls a step behind on deep reasoning That's a real win for a speed tier model but it's not a clean sweep The desktop app itself is built around running multiple agents in parallel You can spin up sub agents schedule tasks to run in the background and the agents will keep working while you go do something else They added native voice commands too which I haven't tried in any serious way yet There's also tight integration with Google AI Studio Firebase and Android tooling If you live inside Google Stack this is going to feel pretty seamless If you don't it might feel like extra friction The CLI is where Google made the biggest mechanical change Anti-gravity CLI is a complete rewrite of the old Gemini CLI in Go The original Gemini CLI had over 100K stars on GitHub and a lot of community contributions but it had been built for a different era of agentic coding The Go Rewrite makes it noticeably snappier It also keeps the features people actually used Things like agent skills hooks sub aents and what used to be called extensions are now called anti-gravity plugins Same idea new label Google is pushing all existing Gemini CLI users to migrate There's a deadline floating around mid June where the old CLI stops getting updates The SDK is the piece I think most developers are sleeping on It gives you programmatic access to the same agent harness Google uses internally You can define your own agents host them wherever you want and ship them in your own products That's a pretty big move because it means Google is essentially saying "Here's the same runtime we use Build with it." There's also a managed agent feature in the Gemini API where you can spin up an isolated Linux environment with a single API call The state persists across multiple turns so you can run a long task walk away and come back to query it later Pricing is where things get interesting and a little bit ugly Google launched a new $100 a month AI ultra plan aimed at developers You get five times the usage limits of the pro plan priority access to anti-gravity 20 terabytes of cloud storage and a YouTube premium subscription thrown in The original Ultra plan dropped from $250 to $200 a month which now gives you 20 times the pro limits They also moved away from daily prompt limits and switched to a compute used model that resets every 5 hours until you hit a weekly cap Developers on Reddit and the Google AI forums have been pretty vocal about this Some people tracking their token usage say they're hitting weekly limits at way less than what they used to get Google is selling pay as you go credit topups at $25 for 2500 credits but they haven't been super clear about what a single credit actually buys you inside anti-gravity That lack of transparency is a real frustration point in the community right now To install the desktop app you just go to the anti-gravity site and download the build for your OS The CLI is a oneline curl command from their GitHub I ran it in my terminal typed a to launch and it dropped me into something that looks remarkably like clawed code Same kind of slash command menu same conversation flow similar agent skill structure The desktop app when you open it is basically the codeex layout You have a sidebar with your project history a model selector and a chat area You can pick between Gemini Claude and GPT models inside the app which is a nice touch and something the IDE version also supports I gave it a real test I asked Antiggravity 2.0 to build me a project management dashboard in React.js something with tasks team members project status and a basic conbon board I told it to mock the database and be creative with the design I just wanted something I could click through end to end and the agent worked in the background for about 22 minutes When it finished I ran npm rundev in a split terminal and open the local host to see what it actually built The app loaded standard dark mode aesthetic that same kind of indigo and slate gradient combination you see on a lot of AI generated dashboards lately dashboard have a sidebar with projects a top bar with notifications and a profile menu and a main grid showing active projects recent tasks and a small team activity feed None of which I specifically asked for The agent had clearly inferred a lot of features from the broad prompt which is either a good thing or annoying depending on how prescriptive you want to be That's the honest read on what Flash gave me a working app a reasonable feature set but the kind of output you'd want to iterate on for another hour or two before showing it to anyone It's a clear improvement over what the original Gemini CLI produced when we tested it almost a year ago but it's not at the level of the top tier coding setups developers are using today Gemini 3.5 Pro should change that math when it ships next month and I'll run the same test the day it lands So the bigger picture is what Google is actually betting on here They're not trying to win the IDE race anymore They're trying to own the agent orchestration layer The desktop app the CLI the SDK and the managed API all point in the same direction Multi-agent workflows as the default not a feature That's a sensible long-term bet because the kind of work people do with these tools is shifting from oneshot prompts to chains of agents handling background tasks Whether Google can pull engineers away from cloud code and cursor is a different question Most developers I talked to don't want to redo their workflow every time a new tool drops with better benchmark numbers
