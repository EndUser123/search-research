I have been investigating this. There are two APIs: the Transcript API (the searcheable transcript in the sidebar), and the TimedText API (closed captions). The Transcript API currently requires attestation, while the TimedText API does not.

Now, there's two ways Invidious can get captions. One is without Companion. Indeed, when it does so without use_innertube_for_captions, it uses the TimedText API which shouldn't be an issue. Alas, Invidious without Companion gets detected by Google, and blocked, for reasons I'm not sure about.

The other way is to use Companion. Companion uses YouTube.js, which uses Transcript API. Alas, it has no attestation, so it gets blocked.

My current 

working

 workaround is to edit Companion and YouTube.js to use the TimedText API. Since Companion (and YouTube.js) can access YouTube without getting blocked, 

and

 TimedText does not yet require attestation, it works!

Well, for now, at least. YouTube.js developers mentioned that they would want to add attestation support to the Transcript API instead, which will be a more long-term solution.

I'll post my patches soon, if anyone wants them.

Note: I haven't tested Invidious without Companion with use_innertube_for_captions, but I doubt it'll work since it just uses YouTube.js, which as mentioned is using the Transcript API without attestation (for now).
