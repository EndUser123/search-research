# Desktop-TU: Terminal-First Desktop Environment Written in Rust
imagine having a full desktop environment without graphics Meet Desktop TY a Rust power project that turns your terminal into a tiling desktop inspired by tools like T-Mox With desktop 2e you can launch apps or commands straight from shortcut files view anything that outputs to and manage your workspace by moving resizing or tiling windows all inside the terminal It even handles crashes gracefully lets you select files or folders as arguments and is working toward cross- term support for better color handling If you love minimal setups or want to explore what a textonly desktop could look like desktop TUI is an open- source experiment worth checking out licensed under MIT and written in Rust
