The importance of developer first security

When developers think about when & how to detect application security issues; more often than not, it will be “after I've pushed the code”. This is only natural as the ethos for most developers is to build and ship code as fast as possible; anything which slows down the development cycle is a problem.

However, in a time where over 50% of application code is now being written by AI, software supply chain attacks are becoming more prevalent, combined with an ever increasing number of cyber attacks and CVEs reported; it is safe to say times have changed since The Phoenix Project was written. It is finally time that we, both developers and security engineers change with them, embracing AI as a engine of change for Application Security.

⚠️ IMPORTANT - Scan Scope Configuration:

 

When scanning with Gitleaks, it's critical to limit the scan scope to only the application directory to avoid:

Including unrelated secrets from other projects

Generating false findings from external codebases

2.2 Multi-Stage Build Pattern

Multi-stage builds separate build-time dependencies from runtime, reducing image size and attack surface.

# ============================================
# Stage 1: Builder (use -dev variant with npm)
# ============================================
FROM cgr.dev/chainguard/node:latest-dev AS builder
WORKDIR /app
# Copy package files first (better caching)
COPY --chown=65532 package*.json ./
# Install dependencies (production only)
RUN npm ci --omit=dev
# Copy application code
COPY --chown=65532 . .
# ============================================
# Stage 2: Runtime (use minimal variant)
# ============================================
FROM cgr.dev/chainguard/node:latest
WORKDIR /app
# Copy node_modules and application from builder
COPY --from=builder --chown=65532 /app/node_modules ./node_modules
COPY --chown=65532 package*.json ./
COPY --chown=65532 server.js ./
COPY --chown=65532 *.html ./
COPY --chown=65532 images/ ./images/
# Set environment variables
ENV NODE_ENV=production \
    PORT=8080
# Expose non-privileged port
EXPOSE 8080
# Health check
HEALTHCHECK --interval=30s --timeout=3s --start-period=5s --retries=3 \
  CMD node -e "require('http').get('http://localhost:8080/health', (res) => process.exit(res.statusCode === 200 ? 0 : 1))" || exit 1
# Run as non-root user (Chainguard images default to nonroot)
USER 65532
# Start application
CMD ["node", "server.js"]
