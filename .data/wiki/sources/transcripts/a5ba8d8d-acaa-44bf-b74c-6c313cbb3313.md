The frontend-design skill from Anthropic's official claude-plugins-official plugin auto-activates in Claude Code for UI/UX tasks, guiding Claude to produce distinctive, production-grade frontend code that avoids generic "AI slop" aesthetics like default fonts or purple gradients. It emphasizes bold choices in typography, color, motion, spatial layouts, and visual details tailored to your project's purpose and audience.
