# Missing ComfyUI Manager? Install it in 2 Minutes!
If your ComfyUI doesn't have the manager 
button, don't worry. In this video,  

I'll show you how to install Comfy 
UI Manager in under 2 minutes.

First, open the Comfy UI Manager GitHub page. I 
will include the link in the description. Scroll  

down until you find the installation 
instructions. We only need the GitHub  

repository link. Copy it. Now, open your Comfy 
UI installation folder. Go inside the custom  

nodes folder. Click on the address bar. Type 
cmd and press enter. This opens command prompt  

directly in this folder. Now paste the GitHub 
repository link you copied earlier and press  

enter. Wait a few seconds until the download 
finishes. Once the installation is complete,  

simply restart ComfyUI. After ComfyUI opens 
again, you'll see the manager button at the  

top. Click it and that's it. ComfyUI manager is 
successfully installed. If this tutorial helped,  

don't forget to like the video and 
subscribe for more ComfyUI tutorials.
