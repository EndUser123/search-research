As of 2026, Gemini CLI supports 

Gemini 3

 Pro and Gemini Flash models. By default, the CLI uses an automatic routing strategy that selects the best model per request. You can switch manually with 

/model

 or use a flag like 

--model gemini-3-pro-preview

 when launching.

What Is Gemini CLI?

Gemini CLI is a tool that runs directly in your terminal, understands your codebase, and helps you fix bugs using natural language prompts. It's Google's response to Anthropic's 

Claude Code

https://www.datacamp.com/tutorial/claude-code

.

Here are some key capabilities of Gemini CLI:

Editing and refactoring: It can automatically improve and simplify your code with AI guidance.

Bug detection and fixing: It identifies the bugs and proposes fixes for errors.

Code understanding: Gemini CLI asks Gemini to summarize architecture, explain module roles, or map flows.

Test generation: Gemini auto-generates pytest test cases to improve reliability and CI confidence.

Documentation support: You can create structured markdown docs, changelogs, and GitHub issue replies within the terminal using this tool.

Search grounding: The 

@search

 tool can be used for real-time information retrieval to validate best practices.

Source: Google

Generating a flowchart using MCP

This section extends the previous experiments, where I explore how Gemini CLI uses 

Model Context Protocol (MCP)

https://www.datacamp.com/tutorial/mcp-model-context-protocol

Here is the prompt I used:

Prompt: Generate a flowchart that shows how agents communicate via A2A and how the main.py orchestrates the system. Highlight where the issue occurred and how it was fixed.

 

This visualization is powered by Gemini's persistent memory, which retained the full context of our earlier bug fix and agent structure without needing any re-upload or file hints.

Although image generation tools were not directly available within the CLI (they may be accessible via API), this visualization proved helpful in understanding agent routing.

Gemini CLI FAQs

What is the Gemini CLI and what can it do?

The Gemini CLI is Google's open-source AI terminal assistant that allows developers to integrate Gemini models directly into their command-line workflow. It is designed to understand your codebase, allowing you to automate debugging, refactor complex functions, generate unit tests, and write documentation without leaving your terminal.

How do I install the Gemini CLI?

To install the Gemini CLI, you need Node.js version 18 or higher installed on your system. You can then run the following command in your terminal: 

npm install -g @google/gemini-cli

 . Alternatively, you can run it without installation using 

npx google-gemini/gemini-cli

 .

Is the Gemini CLI free to use?

Yes, the Gemini CLI is generally free to use with generous usage limits. By authenticating with your Google account, you typically get access to a free tier (e.g., up to 

60 requests per minute

 and 

1,000 requests per day

) using models like Gemini 3 Pro or Flash. For higher limits, you can connect a Google Cloud API key.

How do I use Gemini CLI with an existing project?

To use the Gemini CLI with an existing codebase, simply navigate to your project directory in the terminal ( 

cd my-project

 ) and type 

gemini

 . The tool will read the context of your current folder, allowing you to ask questions like "Explain the architecture of this app" or "Fix the bug in main.py" using the files immediately around you.

What are the prerequisites for running Gemini CLI?

The main prerequisite for setting up the Google Gemini CLI is having Node.js (v18+) and 

npm

 installed. You also need a valid Google account for authentication. It works across major operating systems, including macOS, Windows, and Linux.
