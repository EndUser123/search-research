# Meet Termix: The Open-Source Control Center for Your Servers
meet Termix the open-source forever free platform that brings all your server management needs together in one clean intuitive dashboard with Termix you can securely manage your infrastructure from anywhere all through a web browser at its core Termix offers a fullfeatured SSH terminal complete with split screen support up to four panels and a tab navigation system so multitasking across servers has never been easier need a tunnel traffic no problem termix makes SSH tunnel management simple with automatic reconnection and real-time health monitoring working directly with files on remote servers is seamless with the built-in remote file editor you can open edit upload or delete files all with syntax highlighting and familiar controls organizing your connections is effortless thanks to the integrated SSH host manager add tags group servers into folders and streamline your workflows meanwhile the server stats view gives you instant insight into CPU memory and storage usage so you always know what's happening under the hood security is at the core of Termix with a user authentication system that already supports OIDC plus admin controls built-in you can manage access safely and reliably and it's not just about functionality it's about experience termix sports a modern interface built with React Tailwind CSS and Shad Cen designed to keep your focus where it matters one platform full control your servers your rules
