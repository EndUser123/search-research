Which version of LM Studio?

LM Studio 0.3.31

Which operating system?

Windows 10 Pro

What is the bug?

Sliding Window Attention (SWA) does not work properly, causing excessive memory usage despite llama.cpp 1.52.1 supporting this feature. Using CUDA llama.cpp (windows) 1.52.1.

Expected Behavior:

Gemma 3 27B Q5_K_S with 128K context and Q4_0 KV cache quantization should fit within ~24GB VRAM using SWA, as it does in Oobabooga and KoboldCPP.

Actual Behavior:

Model VRAM: 18.1 GB

Context VRAM: 4.5 GB + 13.4 GB = 17.9 GB total context

Total VRAM: 36 GB allocated (exceeds physical 24GB, spills to shared memory)

This causes significant system RAM usage that should not occur with proper SWA implementation

Root Cause:

LM Studio appears to have a context shifting feature (similar to KoboldCPP's "ContextShift" or Oobabooga's "Streaming LLM") that conflicts with SWA and cannot be disabled.

Requirements for SWA to work properly:

Flash Attention must be enabled ✓ (appears to be enabled)

Context shifting must be disabled ✗ (no option available in LM Studio)

Terminology reference:

KoboldCPP: "Use ContextShift" checkbox (must be unchecked for SWA)

Oobabooga: "Streaming LLM" setting (must be disabled for SWA)

LM Studio: No equivalent toggle exists

Current LM Studio context options:

Context length slider

"Stop at limit" option (enabled, but does not resolve the issue)

No toggle for context shifting behavior

To Reproduce:

Load Gemma 3 27B Q5_K_S model

Set context length to 128K

Set KV cache quantization to Q4_0

Enable "GPU offload" to load model entirely to GPU

Set context overflow handling to "Stop at limit"

Observe memory usage: 18.1GB model + 17.9GB context = 36GB total (should be ~24GB with proper SWA)

Comparison with working implementations:

In both Oobabooga (with "Streaming LLM" disabled) and KoboldCPP (with "Use ContextShift" unchecked), the same model configuration with SWA enabled stays within 24GB VRAM.

Suggested Fix:

Add a toggle to disable context shifting behavior (equivalent to KoboldCPP's "Use ContextShift" or Oobabooga's "Streaming LLM"), allowing proper SWA functionality for models that support it.
