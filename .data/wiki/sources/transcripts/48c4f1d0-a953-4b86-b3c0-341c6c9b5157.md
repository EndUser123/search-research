60 Selected Skills, Workflows, and Open Source Projects, the Ultimate Claude Advancement Checklist

Developers, Content Creators, Product Builders, and Beginners can all use this

Original Article Title: Top 60 Claude Skills, Workflows, and GitHub Repos for AI—The Complete List.

Original Article Author: Khairallah AL-Awady

Translation: Peggy, BlockBeats

Editor's Note: If you've been following AI lately, you may easily get the impression that the number of tools is increasing, but the ones that are truly usable are decreasing.

For most people, the challenge lies not in the lack of tools, but in which tools are worth using and where to start.

This list is based on practical testing, systematically reviewing the current AI tool ecosystem, selecting 60 tools, and categorizing them according to different levels and use cases: from coding and development tools, to agent frameworks and tool integration, then to workflow automation, data processing and infrastructure, and finally extending to learning resources and continuous update paths.

Overall, it outlines a clear path from "using AI" to "building AI systems," providing different entry paths for developers, content creators, product builders, and beginners, helping readers find their own entry points in a complex tool ecosystem.

In the ever-evolving landscape of tools, such a structured review may be more meaningful than isolated recommendations. It provides not answers, but a more efficient way to understand and use AI.

Below is the original text:

I've spent over 100 hours testing various AI tools so you don't have to stumble on your own.

Bookmark this first :)

The AI tool ecosystem in 2026 has reached a point of "information overload": new frameworks every week, new agents every day, new projects hitting the GitHub trending list every morning.

Most of them are just hype. Some are indeed useful. A very few will truly change the way you work.

I've filtered out the noise for you.

These 60 tools below are ones I personally tested, selected as truly worth paying attention to—organized by category, along with the scenarios each excels in.

It's recommended to bookmark this, as you are likely to come back to use them repeatedly.

Part 1: AI Programming Agent & IDE

This category of tools can allow AI to help you write code, review code, and even manage the entire development process.

The key is: these are truly capable of running in a real-world workflow, not just staying at the demo stage.

1. Claude Code

A command-line programming agent introduced by Anthropic. It can read files, write code, run tests, all directly in your local environment.

If you want to maintain full control in AI-assisted development, this is the current "gold standard."

https://docs.anthropic.com/en/docs/claude-code

https://docs.anthropic.com/en/docs/claude-code

2. Cursor

An AI-first code editor built on VS Code. It supports in-line completion, interaction with code repositories, and multi-file editing.

Suitable for developers looking to seamlessly integrate AI into their existing development flow.

https://www.cursor.com

https://www.cursor.com/

3. Codex CLI

A terminal-based programming agent introduced by OpenAI. Given natural language instructions, it reads code repositories, generates, and executes code.

Performs well on tasks involving multiple steps.

https://github.com/openai/codex

https://github.com/openai/codex

4. Windsurf

An AI programming IDE launched by Codeium. Its Cascade agent supports multi-file editing, deep understanding of codebases, and an "immersive coding flow."

Growing rapidly.

https://codeium.com/windsurf

https://codeium.com/windsurf

5. Superpowers

A collection of 20+ practical skills built for Claude Code, including TDD, debugging, end-to-end pipeline planning, and more.

Over 96,000 stars on GitHub. If you use Claude Code, it is recommended to install this promptly.

https://github.com/obra/superpowers

https://github.com/obra/superpowers

6.Spec Kit (GitHub)

「Specification-Driven Development」 tool: Write the specification first, then let AI generate the code. Forces you to think before you start coding. Over 50k stars on GitHub.

https://github.com/github/spec-kit

https://github.com/github/spec-kit

7.Aider

AI pair programming tool in the terminal, supports any LLM. Particularly strong in working with existing codebases. Over 30k stars on GitHub.

https://github.com/paul-gauthier/aider

https://github.com/paul-gauthier/aider

Part 2: Agent Framework

Used to build automation systems that can "Think-Act-Iterate".

8.OpenClaw

Phenomenal open-source AI agent. Supports long-running processes, multi-channels (WhatsApp/Telegram/Discord), and can even write its own skills. Over 210k stars on GitHub, one of the most beginner-friendly personal AI agent frameworks available.

https://github.com/openclaw/openclaw

https://github.com/openclaw/openclaw

9.LangGraph

Orchestrates multiple agents using a "graph structure": supports branching logic, human-in-the-loop, and persistent state.

https://github.com/langchain-ai/langgraph

https://github.com/langchain-ai/langgraph

10.CrewAI

Multi-agent collaboration framework, where each agent has a role, objectives, and a "persona". Ideal for simulating team collaboration processes.

https://github.com/crewAIInc/crewAI

https://github.com/crewAIInc/crewAI

11.AutoGPT

A mature auto agent framework designed for long-running tasks.

Has come a long way since its early versions.

https://github.com/Significant-Gravitas/AutoGPT

https://github.com/Significant-Gravitas/AutoGPT

An open-source LLM application development platform that integrates workflow, RAG, agent, and model management.

Relatively user-friendly even for non-developers.

https://github.com/langgenius/dify

https://github.com/langgenius/dify

13.OWL

A multi-agent collaboration framework that excels in GAIA benchmark tests.

Represents the trend of turning cutting-edge research into practical use.

https://github.com/camel-ai/owl

https://github.com/camel-ai/owl

14.CopilotKit

Allows embedding an AI copilot directly into a React application.

Goes beyond just improving development efficiency to making AI an integral part of the product.

https://github.com/CopilotKit/CopilotKit

https://github.com/CopilotKit/CopilotKit

A type-safe agent framework based on Pydantic.

Ideal for Python developers looking to produce structured, verifiable results.

https://github.com/pydantic/pydantic-ai

Part 3: MCP Service and Tool Integration

MCP (Model Context Protocol) enables AI to truly "plug into the world." If Skills teach it how to do things, MCP gives it "permission to act."

16. Tavily

A search engine designed specifically for AI agents, providing structured data that can be directly consumed by LLM instead of blue links.

Offers search, extraction, crawling, and mapping tools, with easy MCP integration in one minute.

https://github.com/tavily-ai/tavily-mcp

https://github.com/tavily-ai/tavily-mcp

17. Context7

Injects the latest library documentation into the context of LLM.

No more "API illusion" or deprecated methods.

Simply add "use context7" in your prompt to automatically fetch the latest documentation.

https://github.com/upstash/context7

https://github.com/upstash/context7

Your AI project manager. Input a PRD, and it will break it down into tasks with dependencies.

Then, Claude will execute them step by step, transforming a chaotic development process into an orderly pipeline.

https://github.com/eyaltoledano/claude-task-master

https://github.com/eyaltoledano/claude-task-master

https://github.com/executeautomation/mcp-playwright

https://github.com/executeautomation/mcp-playwright

One of the fastest paths to creating custom tool integrations for models like Claude.

How to Truly Use This List

Do not try to install all 60 tools at once. It will only lead to information overload and waste of time.

Here is a better approach:

If you are a developer:

 Start with Claude Code (01) + Superpowers (05) + Context7 (17) + Tavily (16).

This combination can help you set up a powerful AI programming environment with search capabilities and document support.

If you are a creator / knowledge worker:

 Start with OpenClaw (08) + Obsidian Skills (28) + PDF Processing (23) + Frontend Design (24). This combination can provide you with an AI assistant capable of file management, document processing, and content creation.

If you are working on a product:

 Start with FastAPI (48) + Instructor (44) + Chroma (45) + LangGraph (09).

This combination covers backend framework, structured output, memory system, and agent orchestration capabilities, enough to support a production-grade AI application.

If you just want to learn:

 Start with the Anthropic Tutorial (57) + PromptingGuide (56) + Anthropic Official Documentation (60).

Build a solid foundation first, then start adding tools.

Choose a path and dive deep into it first.

Expand your tools slowly as needs arise.

TL;DR

Skills = Teaching AI to "do better"

MCP = Giving AI the "ability to access external tools and data"

Repos = Providing all the open-source infrastructure

Combining these three, what you get is no longer just a "cool-looking demo," but a truly productive AI workflow.

That's it. 60 tools. Now, go build something.
