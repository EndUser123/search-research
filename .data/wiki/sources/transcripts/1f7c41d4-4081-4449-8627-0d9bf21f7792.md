Description

7 meta-cognitive thinking skills for Claude Code that upgrade how your AI thinks, not just codes. Includes cross-verified research (multi-source verification with source tier labeling), creativity sampler (5 probability-weighted options forcing unconventional alternatives), adversarial review (3-vector Devil's Advocate stress testing), and 4 more skills. Converted from 30+ Korean AI prompt engineering patterns. MIT licensed, 12+ GitHub stars.

Validate Claims

Install the plugin and run any of the three prompts below. You'll immediately see structured, multi-step thinking output that's fundamentally different from default Claude responses — probability-weighted options, source-tier-labeled research, or forced adversarial critique.

Specific Task(s)

Creativity test: Ask Claude to evaluate a technology choice — you'll get 5 probability-weighted options instead of one default answer, with at least 1 unconventional alternative.

Research test: Ask Claude to research a technical topic — you'll get cross-verified findings with source tier labels (S/A/B/C) and a confidence score.

Adversarial test: Ask Claude to review a decision you've already made — it will attack it from 3 vectors and surface blind spots.

Specific Prompt(s)

Test 1 — Creativity Sampler:

/creativity-sampler Which database should I use for a real-time analytics dashboard?


Test 2 — Cross-Verified Research:

/cross-verified-research What are the current best practices for WebSocket authentication in 2026?


Test 3 — Adversarial Review:

/adversarial-review I decided to use a monorepo with Turborepo for our 3-person team's microservices


Additional Comments

Stack Skills originated from analyzing a popular Korean AI prompt engineering archive (30+ patterns, 12 GitHub repositories) and converting the most effective meta-cognitive patterns into reusable Claude Code skills. Full credits to the original creator (fewweekslater/lemos999) are in CREDITS.md. Each skill is designed to chain with others — e.g., creativity-sampler → cross-verified-research → adversarial-review for a complete decision-making pipeline.
