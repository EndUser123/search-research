How to Install Claude Code: Complete Setup Guide (2026)

Claude Code is Anthropic's AI coding assistant that runs directly in your terminal. It reads your codebase, writes code, runs commands, and handles complex multi-file edits -- all from a single command-line interface.

Unlike browser-based AI chat tools, Claude Code operates inside your actual development environment. It sees your file structure, understands your project context, and makes changes to real files on your machine.

This guide walks you through every step of installing Claude Code in 2026, from checking prerequisites to running your first AI-assisted coding session. Whether you are on macOS, Linux, or Windows, you will have Claude Code running in under five minutes.

What You Need (Prerequisites Checklist)

Before installing Claude Code, confirm you have the following:

Operating system

: macOS 13.0 (Ventura) or later, Ubuntu 20.04+ or Debian 10+, or Windows 10 (version 1809+) with WSL

RAM

: At least 4GB (8GB recommended for larger codebases)

Internet connection

: Claude Code connects to Anthropic's cloud API, so an active connection is required

Anthropic account

: A Claude Pro ($20/month), Claude Max ($100-200/month), Teams, Enterprise, or Console (API) account

Terminal

: Bash, Zsh, or PowerShell

Node.js 18+

 (only required for the npm installation method)

You do not need a GPU. All AI processing happens on Anthropic's servers. Your machine only needs to run the CLI client and send requests over the network.

Step 1: Install Node.js (If You Do Not Have It)

If you plan to use the npm installation method, you need Node.js 18 or higher. If you already have Node.js installed, check your version:

node --version


If the output shows 

v18.0.0

 or higher, skip to Step 2. If not, install or update Node.js using nvm (Node Version Manager), which is the recommended approach because it avoids permission issues and lets you switch between Node versions easily.

Install nvm on macOS or Linux:

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash


Close and reopen your terminal, then install Node.js:

nvm install 22
nvm use 22
node --version


You should see a version number starting with 

v22

 . Node.js 22 is the current LTS release and works perfectly with Claude Code.

Install Node.js on Windows (inside WSL):

First, ensure WSL is installed (see the Windows section below). Then open your WSL terminal and run the same nvm commands above.

Step 2: Install Claude Code

You have two options for installing Claude Code. The native installer is now the recommended method, but npm remains fully supported.

Option A: Native Installer (Recommended)

The native installer requires zero dependencies -- no Node.js, no npm. It auto-updates in the background and is the primary method Anthropic tests and supports.

macOS and Linux:

curl -fsSL https://claude.ai/install.sh | bash


Windows (PowerShell, as Administrator):

irm https://claude.ai/install.ps1 | iex


The installer downloads the Claude Code binary, places it in your PATH, and configures automatic updates. The entire process takes under a minute.

Option B: npm Install

If you prefer npm -- for example, to pin a specific version or because npm is standard in your workflow -- run:

npm install -g @anthropic-ai/claude-code


Important

: Do not use 

sudo

 with npm install. If you get permission errors, the correct fix is to use nvm (which installs Node.js in your home directory) rather than running npm as root.

Verify the Installation

Regardless of which method you chose, verify that Claude Code is installed:

claude --version


You should see a version number. You can also run the built-in diagnostic:

claude doctor


This command checks your environment and reports any configuration issues.

Step 3: Authenticate

Claude Code requires authentication before you can use it. Run:

claude


The first time you run this command, Claude Code opens your default web browser and asks you to sign in to your Anthropic account. Follow the prompts to authorize the CLI.

Authentication Options

Browser-based login (default):

 Best for personal machines. Claude Code opens a browser window, you sign in, and the CLI receives an authentication token automatically. This works with Claude Pro, Max, Teams, and Enterprise accounts.

API key (for CI/CD and automation):

 If you are running Claude Code in a headless environment or CI/CD pipeline, set your API key as an environment variable:

export ANTHROPIC_API_KEY=sk-ant-your-key-here


You can generate an API key from the 

Anthropic Console

https://console.anthropic.com/

. API usage is billed per token at Anthropic's published rates.

Subscription vs. API billing:

 With a Pro or Max subscription, your Claude Code usage is included in your monthly plan (subject to usage limits). With an API key from the Console, you pay per token. Choose based on your usage volume -- subscriptions are simpler for regular use, while API billing gives you more control for variable or automated workloads.

Step 4: Your First Project

Now that Claude Code is installed and authenticated, try it on a real project.

Navigate to any project directory:

cd ~/my-project


Start Claude Code:

claude


You are now in an interactive session. Claude Code has read your project structure and is ready to help. Try giving it a task:

> Explain the architecture of this project


Claude Code will scan your files, identify the tech stack, and give you a summary of how the project is organized.

Try something more hands-on:

> Add input validation to the user registration form


Claude Code will identify the relevant files, propose changes, and ask for your confirmation before modifying anything. You review each change in a diff view and accept or reject it.

For a one-off task without entering interactive mode, use the 

-p

 flag:

claude -p "Write unit tests for the auth module"


This runs the task, outputs the result, and exits -- useful for scripting and quick questions.

Step 5: Essential Configuration

Claude Code works out of the box with sensible defaults, but you can customize its behavior for your workflow.

Model Selection

Claude Code uses the latest Claude model by default. To specify a different model:

claude config set model claude-opus-4-6


Or for a single session:

claude --model claude-sonnet-4-20250514


Permissions

Claude Code asks for confirmation before performing potentially destructive actions like writing files or running shell commands. You can configure this behavior:

claude config set permissions.auto-accept-edits true


Project-Level Settings

Create a 

.claude/settings.json

 file in your project root to define team-shared configuration:

{
  "permissions": {
    "allow": ["read", "write", "shell"],
    "deny": ["shell:rm -rf *"]
  },
  "model": "claude-sonnet-4-20250514",
  "environment": {
    "NODE_ENV": "development"
  }
}


This file should be committed to version control so your entire team shares the same Claude Code behavior.

For personal overrides that should not be committed, use 

.claude/settings.local.json

 instead.

MCP Server Configuration

Claude Code supports Model Context Protocol (MCP) servers for extending its capabilities. Configure them in 

.mcp.json

 at your project root:

{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"]
    }
  }
}


Installing in Different Environments

macOS

The native installer is the simplest path on macOS. Both Apple Silicon (M1/M2/M3/M4) and Intel machines are supported:

curl -fsSL https://claude.ai/install.sh | bash


Alternatively, Claude Code is available via Homebrew:

brew install --cask claude-code


Linux

Works on Ubuntu 20.04+, Debian 10+, and most modern distributions:

curl -fsSL https://claude.ai/install.sh | bash


If you are on an older distribution, use the npm method with nvm to avoid system-level dependency issues.

Windows (WSL)

Claude Code on Windows requires either WSL or Git for Windows. WSL is the recommended approach:

Open PowerShell as Administrator and install WSL:

wsl --install


Restart your computer when prompted.

Open the WSL terminal (Ubuntu by default) and install Claude Code:

curl -fsSL https://claude.ai/install.sh | bash


Alternatively, you can use the native Windows installer directly in PowerShell:

irm https://claude.ai/install.ps1 | iex


Docker

For containerized environments, add Claude Code to your Dockerfile:

FROM node:22-alpine
RUN npm install -g @anthropic-ai/claude-code
ENV ANTHROPIC_API_KEY=your-key-here


For CI/CD pipelines, pass the API key at runtime rather than baking it into the image:

docker run -e ANTHROPIC_API_KEY=$ANTHROPIC_API_KEY my-claude-image claude -p "Run the test suite and fix any failures"


CI/CD Pipelines

Claude Code's headless mode ( 

-p

 flag) is designed for automation. Here is a GitHub Actions example:

- name: AI Code Review
  run: |
    npx @anthropic-ai/claude-code -p "Review the changes in this PR and suggest improvements" --output-format json
  env:
    ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}


The 

--output-format json

 flag returns structured output that downstream steps can parse.

Updating Claude Code

Native Installer

If you installed Claude Code with the native installer, updates happen automatically in the background. No action required. You can configure the update channel:

claude config set update-channel stable


To check your current version:

claude --version


npm

If you installed via npm, update manually:

npm update -g @anthropic-ai/claude-code


Or install a specific version:

npm install -g @anthropic-ai/claude-code@latest


IDE Integration

While Claude Code is a terminal-first tool, it integrates directly with popular IDEs for a more visual experience.

VS Code Extension

The VS Code extension provides a native graphical interface for Claude Code inside your editor. It includes a chat panel, checkpoint-based undo, file references with 

@

 -mentions, and the ability to run multiple conversations in parallel tabs.

To install, open VS Code and search for "Claude Code" in the Extensions panel, or run:

code --install-extension anthropic.claude-code


Once installed, you can open the Claude Code panel from the sidebar and interact with it just like the terminal version, but with the added benefit of seeing file diffs rendered in VS Code's native diff viewer.

JetBrains Plugin

For IntelliJ IDEA, PyCharm, WebStorm, GoLand, and other JetBrains IDEs, install the Claude Code plugin from the JetBrains Marketplace:

Open your JetBrains IDE

Go to 

Settings

 then 

Plugins

 then 

Marketplace

Search for "Claude Code"

Click 

Install

 and restart the IDE

The JetBrains plugin runs the Claude Code CLI inside your IDE's integrated terminal and opens proposed changes in the IDE's diff viewer. It is currently in beta but fully functional for daily use.

Troubleshooting

"command not found: claude"

The Claude Code binary is not in your PATH. If you used the native installer, try opening a new terminal window. If that does not work, run the install script again. For npm installations, ensure your global npm bin directory is in your PATH:

npm config get prefix


Add the 

bin

 subdirectory of that path to your shell's PATH variable.

"Node.js version too old"

Claude Code requires Node.js 18+. Check your version with 

node --version

 . If it is below 18, install a newer version using nvm:

nvm install 22
nvm use 22


npm Permission Errors (EACCES)

Never use 

sudo npm install -g

 . Instead, fix npm's default directory or use nvm, which installs everything in your home directory and avoids permission conflicts entirely:

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
nvm install 22
npm install -g @anthropic-ai/claude-code


Authentication Fails or Browser Does Not Open

If the browser-based login does not work (common on remote servers or WSL), you can authenticate with an API key instead:

export ANTHROPIC_API_KEY=sk-ant-your-key-here
claude


Generate your API key at 

console.anthropic.com

https://console.anthropic.com/

.

"Network Error" or Timeout During Installation

Your network or firewall may be blocking npm or the native installer. Try:

npm config set registry https://registry.npmjs.org/


If you are behind a corporate proxy, configure npm to use it:

npm config set proxy http://your-proxy:8080
npm config set https-proxy http://your-proxy:8080


Claude Code Runs Slowly

Claude Code itself is lightweight -- slowness usually means network latency to Anthropic's API. Check your internet connection. If you are on a VPN, try disconnecting. You can also check the API status at 

status.anthropic.com

https://status.anthropic.com/

.
