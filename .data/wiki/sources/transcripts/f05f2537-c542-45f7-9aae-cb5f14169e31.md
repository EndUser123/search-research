Traditional study methods are being augmented and in some cases, replaced by intelligent tools that cater to individual learning styles and needs. This project serves as a practical demonstration of how AI can be harnessed to process educational content efficiently. This AI Study Buddy is designed to:

📄 PDF Text Extraction Module

This module focuses on extracting text from PDF documents, enabling the tool to process and summarize textual content effectively. In this module, we use PyMuPDF to iterate through each page of the PDF to extract text.

import fitz  # PyMuPDF
def extract_text_from_pdf(uploaded_file):
    """
    Extracts and returns the full text from a PDF file using PyMuPDF.
    """
    text = ""
    with fitz.open(stream=uploaded_file.read(), filetype="pdf") as doc:
        for page in doc:
            text += page.get_text()
    return text


🎥 YouTube Transcript Retrieval Module

The YouTube Transcript Retrieval Module is designed to extract textual transcripts from YouTube videos, enabling subsequent processing and summarization. We utilize the 

youtube_transcript_api

 library, a lightweight and efficient Python package that allows for the retrieval of transcripts without the need for YouTube Data API keys or OAuth authentication.

In this module, we first extract the video ID from the provided YouTube URL and then retrieve the transcript using youtube_transcript_api library.

from youtube_transcript_api import YouTubeTranscriptApi
import re
def extract_video_id(youtube_url):
    """
    Extracts the video ID from a standard YouTube URL.
    """
    pattern = r"(?:v=|youtu\.be/)([a-zA-Z0-9_-]{11})"
    match = re.search(pattern, youtube_url)
    return match.group(1) if match else None
def get_transcript(youtube_url):
    """
    Fetches and returns the transcript as a string from the given YouTube video URL.
    """
    video_id = extract_video_id(youtube_url)
    if not video_id:
        raise ValueError("Invalid YouTube URL")
    transcript = YouTubeTranscriptApi.get_transcript(video_id)
    full_text = " ".join([entry['text'] for entry in transcript])
    return full_text


🧩 Chunking & RAG Module

Once we've successfully extracted text from a PDF or a YouTube transcript, the next challenge is enabling the AI to 

understand and respond meaningfully

 to user queries based on that content. Large language models, despite their prowess, are still limited by context window constraints. Moreover, retrieving the right information from long documents is non-trivial. This is where the concept of 

chunking and vector-based retrieval

 comes into play.

In this implementation, we break the text into chunks of roughly 400-500 words, each ideally containing complete sentences or paragraphs. This size strikes a balance: large enough to preserve context, but small enough to avoid exceeding the model's context window. The goal is to ensure each chunk remains coherent so it can be understood on its own when retrieved later.

Once chunking is complete, we move into the next critical phase: turning text into vectors. These are not arbitrary arrays of numbers but they are 

semantic representations

 of each chunk. Embeddings enable the AI to compare textual meaning rather than raw words. For instance, “What does ATP do?” and “Function of ATP in cells” might be worded differently, but their vector representations would be close in space if the embeddings are good.

Finally, when a user asks a question, we convert their query into an embedding using the same model and compare it to our indexed document chunks. The FAISS index returns the top-k closest chunks by semantic similarity. These chunks are then passed to the LLM along with the user's question to provide an accurate answer.

from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain.vectorstores import FAISS
from langchain.embeddings import HuggingFaceEmbeddings
from langchain.docstore.document import Document
# Use a small, performant embedding model
EMBED_MODEL_NAME = "sentence-transformers/all-MiniLM-L6-v2"
embedding_model = HuggingFaceEmbeddings(model_name=EMBED_MODEL_NAME)
def create_vector_store(text):
    """
    Splits text into chunks and creates a FAISS vector store with embeddings.
    """
    text_splitter = RecursiveCharacterTextSplitter(
        chunk_size=500,
        chunk_overlap=50
    )
    docs = [Document(page_content=chunk) for chunk in text_splitter.split_text(text)]
    vector_store = FAISS.from_documents(docs, embedding_model)
    return vector_store
def query_vector_store(vector_store, query, top_k=3):
    """
    Searches the FAISS store and returns top-k relevant documents for a query.
    """
    results = vector_store.similarity_search(query, k=top_k)
    return [doc.page_content for doc in results]


Text Summarization Module

To achieve effective summarization, we use Groq API, which offers access to high-performance language models like LLaMA 3 and Mistral. These models are optimized for speed and efficiency, making them well-suited for real-time summarization tasks.

import os
import requests
GROQ_API_KEY = os.getenv('GROQ_API_KEY') # Set this in your environment or .env file
GROQ_API_URL = "https://api.groq.com/openai/v1/chat/completions"
DEFAULT_MODEL = "mistral-saba-24b"  # or "llama3-70b-8192", etc.
HEADERS = {
    "Authorization": f"Bearer {GROQ_API_KEY}",
    "Content-Type": "application/json"
}
from groq import Groq
def generator(prompt, system_prompt="You are a helpful assistant.", model=DEFAULT_MODEL, temperature=0.7):
    client = Groq(
        # This is the default and can be omitted
        api_key=GROQ_API_KEY,
    )
    chat_completion = client.chat.completions.create(
        messages=[
            {
                "role": "system",
                "content": "you are a helpful assistant."
            },
            {
                "role": "user",
                "content": prompt
            }
        ],
        model= DEFAULT_MODEL
    )
    return chat_completion.choices[0].message.content
def summarize_text(text):
    """
    Generates a simplified explanation of the provided text using Mistral-7B.
    """
    prompt = (
        "You are a helpful AI tutor. Explain the following content in simple terms, "
        "like you're teaching a 10th-grade student.\n\n"
        f"Content: {text[:2000]}"
    )
    output = generator(prompt)
    return output.replace(prompt, "").strip()


Quiz Generation Module

If summarization is about building understanding, quiz generation is about testing it. With this module, we aim to automatically generate relevant, accurate, and engaging 

multiple-choice questions (MCQs)

 from the processed learning material.

from transformers import pipeline
# Use the same Mistral pipeline from llm_utils if needed, or redefine here
from llm_utils import generator
def generate_quiz(text, num_questions=5):
    """
    Generates quiz questions from the input text using the LLM.
    """
    prompt = (
        f"Create a quiz with {num_questions} multiple choice questions based on the following content.\n"
        "Each question should have 4 options and clearly mark the correct one.\n\n"
        f"Content: {text[:2000]}"
    )
    output = generator(prompt)
    return output.replace(prompt, "").strip()


User Interface Module

This file is the center that orchestrates the entire user experience. Rather than cramming all the logic into one place, this file serves as a clean interface layer that delegates work to specialized modules under the hood. When someone opens the app, they see a clean interface built using Streamlit. From here, they can either upload a PDF or paste a YouTube link. Depending on the input, the app extracts the relevant content and processes it by running the modules we built above.

The app is organized into three intuitive tabs. In the first tab, users can upload their study material and preview both the extracted content and the AI-generated summaries. The second tab allows them to generate multiple-choice quizzes and flashcards based on those summaries which is perfect for testing their understanding and reinforcing memory. The third tab offers a chatbot-like interface where users can ask any question about the material; the app intelligently searches the vector database for the most relevant information and uses a large language model to formulate a helpful, context-aware response.

import streamlit as st
from pdf_utils import extract_text_from_pdf
from llm_utils import summarize_text
from rag_utils import create_vector_store, query_vector_store
from quiz_utils import generate_quiz
from flashcards_utils import generate_flashcards
from youtube_utils import get_transcript
from text_utils import clean_text
st.set_page_config(page_title="AI Study Buddy", page_icon="🧠")
st.title("🧠 AI Study Buddy")
st.write("Upload a PDF or enter a YouTube link to get simplified explanations, flashcards, and quizzes.")
# Sidebar for inputs
source_type = st.sidebar.radio("Select Input Type", ["PDF Upload", "YouTube Link"]) # removed youtube link temporarily
pdf_text = ""
youtube_url = ""
vector_store = None
source_text = ""
if source_type == "PDF Upload":
    uploaded_pdf = st.sidebar.file_uploader("Upload a PDF file", type=["pdf"])
    if uploaded_pdf:
        with st.spinner("Extracting text from PDF..."):
            pdf_text = extract_text_from_pdf(uploaded_pdf)
            source_text = pdf_text
        st.subheader("Extracted Text Preview")
        st.text_area("First 1000 characters", pdf_text[:1000], height=200)
elif source_type == "YouTube Link":
    youtube_url = st.sidebar.text_input("Enter YouTube Video URL")
    if youtube_url:
        try:
            with st.spinner("Fetching and cleaning transcript..."):
                transcript = get_transcript(youtube_url)
                source_text = clean_text(transcript)
            st.subheader("Transcript Preview")
            st.text_area("First 1000 characters", source_text[:1000], height=200)
        except Exception as e:
            st.error(f"Failed to fetch transcript: {e}")
# Main action
st.sidebar.markdown("---")
action = st.sidebar.radio("What would you like to do?", ["Explain Simply", "Generate Flashcards", "Quiz Me"])
custom_query = ""
if action == "Explain Simply":
    custom_query = st.text_input("Ask a question or leave blank for general explanation", "Explain this content simply")
if st.sidebar.button("Run AI 🤖"):
    if source_text:
        with st.spinner("Creating vector store..."):
            vector_store = create_vector_store(source_text)
        with st.spinner("Processing with AI..."):
            if action == "Explain Simply":
                if vector_store:
                    relevant_chunks = query_vector_store(vector_store, custom_query)
                    combined_text = "\n\n".join(relevant_chunks)
                    summary = summarize_text(combined_text)
                    st.subheader("🧾 Simplified Explanation")
                    st.write(summary)
            elif action == "Generate Flashcards":
                if vector_store:
                    relevant_chunks = query_vector_store(vector_store, "Create flashcards from this content")
                    combined_text = "\n\n".join(relevant_chunks)
                    flashcards = generate_flashcards(combined_text)
                    st.subheader("🗂️ Flashcards")
                    st.text_area("Generated Flashcards", flashcards, height=400)
            elif action == "Quiz Me":
                if vector_store:
                    relevant_chunks = query_vector_store(vector_store, "Create a quiz from this content")
                    combined_text = "\n\n".join(relevant_chunks)
                    quiz = generate_quiz(combined_text)
                    st.subheader("📝 Quiz")
                    st.text_area("Generated Questions", quiz, height=400)
    else:
        st.error("Please upload a valid input before running the AI.")

🚀 Wrapping Up & What's Next

Building AI Study Buddy was an exercise in bringing the power of open-source AI into a real-world, practical learning tool. From parsing PDFs and YouTube transcripts to chunking and summarizing content, generating quizzes and flashcards, and answering questions with a RAG-powered chatbot. This project demonstrates just how far you can go with today's tools, even without relying on proprietary models.

One of the most immediate next steps would be to 

add session memory

 to the chatbot, so it can handle follow-up questions and maintain conversational context. Another useful addition could be allowing users to 

export their quizzes and flashcards

 to save them as PDFs for offline review. There's also exciting potential in supporting 

multimodal inputs

 — for example, extracting information from diagrams in PDFs, or letting users upload images for explanation. And finally, the backend architecture can be extended to support other open-source models or even local deployment for privacy-focused users.
