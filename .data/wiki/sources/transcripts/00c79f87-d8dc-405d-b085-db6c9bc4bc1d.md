Codex is getting a major update.

https://openai.com/index/codex-for-almost-everything/

 Already used by millions of developers, it is now expanding beyond coding to support a broader range of work. The focus remains clear: stronger developer workflows, better integrations, and less friction across projects.

Persistent Context and Intelligent Automations, Coming Soon

OpenAI is releasing a preview of memory. Codex will also support future work scheduling and more proactive help with ongoing projects. These personalization features, including memory and context-aware suggestions, are intended to improve productivity across multiple sessions and longer-term workflows.

Improved Developer Productivity

This update includes several additions aimed directly at developer use cases:

Full lifecycle coding support:

 Codex can now help with GitHub pull request comments, supports multiple terminal tabs, offers richer file previews including PDFs, spreadsheets, and presentations, and adds alpha support for SSH connections to remote development environments.

Browser-based workflows:

 An integrated browser lets you give precise instructions directly on web pages, which can make frontend development and game iteration faster and more intuitive.

Project summary pane:

 You can quickly review plans, sources, outputs, and artifacts in one place to stay organized.

More Integrations and Plugins

Codex now supports more than 90 new plugins and integrations for tools many teams already use, including Jira, GitLab Issues, Microsoft Suite, CI/CD pipelines, and databases. This makes Codex more useful as a central workspace across development and productivity workflows, while reducing unnecessary switching between tools.

Native macOS App Interaction

Starting on macOS, Codex can now interact directly with desktop applications. This opens up a new layer of automation for tasks that would otherwise need to be handled manually.

Built-in Image Generation for Multimodal Workflows

Codex now includes native image generation, making it easier to create and iterate on product mockups, concept visuals, UI prototypes, and game designs without leaving the workspace. This expands what you can do in one place and adds useful support for visual workflows.

Availability and Rollout

The updated Codex begins rolling out today for Codex desktop app users signed in with ChatGPT. Desktop app interaction, initially on macOS only, and browser integration will reach users in the EU and UK shortly after. Personalization features, including memory and proactive context-aware suggestions, will be available soon for Enterprise, Edu, and EU/UK users.

Codex is no longer just about writing code. This update moves it further toward being a practical tool for handling the broader workflow around development and day-to-day project work.

A coding assistant is only useful if it can survive normal iterative development. Right now, the limit model feels too restrictive for real work. It breaks momentum, discourages experimentation, and turns ordinary coding flow into quota management.

That makes all the “new Codex for almost everything” messaging hard to take seriously. If using the product normally burns through limits too fast, then it is not built for “almost everything.” It is built for small, cautious usage bursts.

OpenAI needs to fix the limit system first. Otherwise the product keeps improving on paper while becoming less usable in practice.
