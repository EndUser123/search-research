# Fix LTX 2.3 Detail Loss: 4K Image To Video ComfyUI Workflow (8GB VRAM) 🚀
The biggest issue we encountered when using 
the LTX image-to-video workflow was the  

loss of temporal consistency. As you saw in my 
previous video covering image-to-video generation,  

relying on just a single reference 
image means the model struggles to  

preserve the original details. Faces 
become completely unrecognizable,  

genders swap unexpectedly, and objects 
morph into entirely different things.

The solution to this is to limit the 
model's tendency to hallucinate by  

providing both first and last frame images. 
As you saw in the side-by-side comparisons,  

it completely changes the game.

In the previews, all the original details of the 
reference images—including facial identity and  

object permanence—were spot on when we guided the 
video generation with start and end frames. Now,  

you can finally create professional-looking 
videos. Well, to be perfectly honest,  

using a first and last frame doesn't fix the 
model's inherent issues with fast-paced action  

and sweeping cinematic camera controls. But 
at the very least, you can save your cloud  

credits for those advanced movements and use 
LTX 2.3 for the things it actually excels at.

This is a massive opportunity for us local users. 
You can easily kickstart your creative journey,  

generate an unlimited number of 
Facebook, Instagram, and TikTok reels,  

and maybe even get monetized since you 
aren't spending everything on credits.

Stick to close-ups or medium close-ups 
if you're hoping to use the model for  

professional workloads. Now, this actually isn't 
going to be a major roadblock if you're mainly  

going to stick with producing standard 
Facebook, Instagram, or TikTok reels.

Another bottleneck with the first-and-last-frame  

method is that it requires significantly 
more hardware resources than standard  

text-to-video or single-image generations, 
forcing 8GB VRAM users to stick with 720p.

It's not totally impossible to generate 1080p 
clips, but 1080p—especially when used for  

portrait aspect ratios—has definitely given me 
some issues. Take a look at this clip right here.

Another issue I noticed during testing 
is that the model struggles to maintain  

continuous action without breaking down 
and doing strange things when the clip  

is longer than 10 seconds, 
just like in this example.

Now, let's talk about another important detail. 
I usually go with the Euler Ancestral sampler,  

but sometimes the 'LCM' sampler yields better 
results. I generated this clip using Euler  

Ancestral, and as you can see, the people 
suddenly disappear just so the model can stay  

true to the last frame. However, switching 
to the 'LCM' sampler fixed the issue. Here,  

the people naturally walk out of the frame 
to bridge the gap between the first and the  

last image. Another thing you need to pay close 
attention to is that if you have a background  

where people are doing the exact same thing 
in both your first and last frames—like you  

see here—the background effectively becomes 
static. This happens even if you explicitly  

give instructions in the prompt to make them move, 
especially when using the Euler Ancestral sampler. 

Here, the LCM sampler smoothed this out a bit, 
but not entirely, so make sure the background  

extras in your last frame are doing noticeably 
different things compared to the first frame.

Blackwell architecture. If you're on an
