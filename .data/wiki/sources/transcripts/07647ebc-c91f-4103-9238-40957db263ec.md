The current way to handle this is by using the 

Layer::boxed

https://docs.rs/tracing-subscriber/0.3.18/tracing_subscriber/layer/trait.Layer.html#method.boxed

 method. The linked documentation explains the details, but in short you can call 

.boxed()

 on your layers which (from the docs):

Erases the type of this 

Layer

 , returning a 

Box

 ed 

dyn Layer

 trait object.

This can be used when a function returns a 

Layer

 which may be of one of several types, or when a 

Layer

 subscriber has a very long type signature.

Your original code would become:

Copylet tracing_layer = {
    if env::var("LOG_FORMAT").is_ok_and(|format| format == "json") {
        tracing_subscriber::fmt::layer().json().boxed()
    } else {
        tracing_subscriber::fmt::layer().boxed()
    }
};

tracing_subscriber::registry()
    .with(tracing_subscriber::EnvFilter::try_from_default_env()
        .unwrap_or_else(|_| "api_gateway=debug,axum=debug,tower_http=debug".into()))
    .with(tracing_layer)
    .init();

Box<dyn Layer<S>>

 impls 

Layer<S>

 , so:

Copy    let tracing_layer = {
        if env::var("LOG_FORMAT").is_ok_and(|format| format == "json") {
            Box::new(tracing_subscriber::fmt::layer().json()) as Box<dyn Layer<Registry>>
        } else {
            Box::new(tracing_subscriber::fmt::layer())
        }
    };

    tracing_subscriber::registry()
        .with(tracing_subscriber::EnvFilter::try_from_default_env()
            .unwrap_or_else(|_| "api_gateway=debug,axum=debug,tower_http=debug".into()))
