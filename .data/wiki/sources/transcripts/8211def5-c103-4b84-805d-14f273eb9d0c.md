# the only two claude frontend design skills worth your time
if you want to create websites with cloud code that don't suck then there's really only two UI skills you should be using The first one and you've probably heard of it before is Impeccable Impeccable is all about identifying AI slot patterns It defines like 40 plus of those sorts of patterns and then giving you suggestions to change them On top of that you can actually use Impeccable on a live preview of your website similar to Claw Design so you aren't just stuck inside the terminal The second skill and it also is open source is the taste skill Just like impeccable it's all about identifying these AI slot patterns and then doing something different The taste skill very recently got updated to version 2.0 and as you can see they made a ton of upgrades to how it works And the reason I suggest these two skills over some other ones is because they are not prescriptive They give you a ton of flexibility in terms of what you're trying to build So again you can get away from generic outputs
