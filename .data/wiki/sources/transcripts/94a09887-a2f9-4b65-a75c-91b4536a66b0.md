# Intelligence-Stream: Transcript + Subprocess Patterns
YouTube Transcript Extraction: Prioritize manual subtitles, fallback to auto-generated, then youtubei API. Use cookies.txt for bot-block avoidance. IP bans on cloud IPs require rotating residential proxies (Webshare). Fallback chain: yt-dlp manual → yt-dlp auto → youtubei get_transcript API → SDK.





Subprocess Timeout (Windows): The OS timeout command (Git Bash) is the reliable approach for Windows. CREATE_NEW_PROCESS_GROUP flag enables os.kill() on subprocess groups. Always use communicate() not .wait() with pipes. After TimeoutExpired, must call communicate() again to clean pipes.





Fallback Chain Pattern: try/except on CalledProcessError and TimeoutExpired. Layer: CLI (yt-dlp) → transcript API (youtube-transcript-api) → SDK (Gemini API direct).
