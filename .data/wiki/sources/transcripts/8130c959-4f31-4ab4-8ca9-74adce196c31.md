The proxy itself is just a TCP multiplexer — it binds to a port and routes requests to whichever provider

 

(anthropic/zai/minimax/gemini) based on the model ID in the incoming request. The config file defines those

 

model-to-provider mappings.

So the port is just a socket. The config is what determines routing behavior. Any config can run on any port — the port

 

just needs to be free (or you're willing to kill what's on it).

That's why the menu asks you to pick a port first, then a config. The port selection is purely about socket availability;

 

the config selection is about which model routing you want.
