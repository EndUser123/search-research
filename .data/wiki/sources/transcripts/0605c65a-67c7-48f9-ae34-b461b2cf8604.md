3. STRUCTURED DIAGNOSTIC PROTOCOL
List all hypotheses upfront
 (minimum 3)
For EACH hypothesis
: design disconfirming test → run test → mark RULED OUT/CONFIRMED
Only proceed
 when all but one ruled out OR one confirmed
Document
 the diagnostic path
