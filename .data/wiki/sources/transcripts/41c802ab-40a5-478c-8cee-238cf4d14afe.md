# uniprof — CPU profiling made simple for humans and AI agents
welcome back to GitHub awesome today's project is all about making performance profiling simple it's called Uniro and it helps humans and AI agents profile applications without code changes without dependencies and without a headache you can run it straight from the CLI or even plug it into your AI agent as an MCP server so your agent can find the real performance bottlenecks instead of just guessing out of the box UniROV supports multiple profiling backends like PY Spy Perf and Instruments automatically picking the right one for your platform and runtime it normalizes their outputs into a single format and even runs statistical analysis to highlight hotspots and the best part it comes with built-in flame graph visualization powered by Speed Scope so you can actually see what's slowing you down setup is penless too by default Unirov runs your code inside preconfigured Docker containers keeping your environment clean and isolated or if you prefer you can run in local mode if you already have the tools installed it works on Mac OS and Linux with partial WSL to support for Windows users and can profile everything from Python and Node.js to native ELF and Macco binaries so if you've ever struggled with profiling setups or want to give your AI agents the power to autooptimize code check out UniR link to the repo is in the description
