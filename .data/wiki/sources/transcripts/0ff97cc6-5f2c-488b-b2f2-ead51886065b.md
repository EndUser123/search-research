Vibe-Guardian

https://github.com/Camof1ow/vibe-guardian

License:

 MIT

What it does

A Claude Code skill that automatically scans AI-generated code for security vulnerabilities and quality issues 

before you commit

.

Most security scanners check your code after you've already pushed to GitHub. Even if you fix the vulnerability later, the original vulnerable code stays in your Git history forever. Vibe-Guardian catches issues before they reach your repository.

Code → [SCAN] → Fix → Commit → Push
        ↑
   Catch it here. Git history stays clean.


Features

🔴 

Critical Issues

: SQL Injection, NoSQL Injection, Command Injection, XSS (Reflected, Stored, DOM-based), Hardcoded Secrets, Auth Bypass, Path Traversal

🟡 

Warning Level

: Missing Input Validation, Poor Error Handling, Sensitive Logging, CORS Misconfiguration, Performance Issues

✅ Runs locally (no internet required, your code stays private)

✅ Supports JavaScript, TypeScript, Python, Java, Go

✅ 100% Free & Open Source (MIT License)

✅ Detailed reports with fix suggestions

Tech

Claude Code Skill · Markdown · TypeScript examples
