# Claude Code handoff shift #claudecode #handoff #aiworkflow
the longer you continue a claw code session the dumber it gets and sometimes compact is not enough to fix it compacting can still carry the shape of the previous conversation forward including messy debugging attempts or bad assumptions so what you actually want is a full handoff before you end a clawed code session tell it to create a handoff.md file have it include the goal the current state files it's working on what has changed what it's tried that failed and what to do next then run /clear or start a new cloud code session and tell it to read that handoff doc and continue from where it left off now instead of dragging that conversation forward you're giving a new agent a fresh start to solve the problem this is especially useful if you want to step away for a few hours or if Claude keeps trying the same broken solution over and over again follow for more AI news and tips
