There are no instructions to read or exfiltrate unrelated system files, scan for credentials, or post data to external endpoints.

✓

Install Mechanism

There is no automated install spec; the skill is instruction-and-script based and expects manual copy/enable. No downloads from arbitrary URLs or archive extraction occur. All executable helpers are local shell scripts and hook handlers included in the bundle.

✓

Credentials

The skill declares no required environment variables or credentials. The only runtime input referenced is CLAUDE_TOOL_OUTPUT (used by error-detector.sh) and the OpenClaw hook event/context. No secret-like env vars are requested.

✓

Persistence & Privilege

The skill does not set always:true and does not request persistent platform-level privileges. Its OpenClaw hook injects a virtual reminder file at agent bootstrap (expected behavior for a reminder hook). Scripts that scaffold files write to relative paths and include checks to avoid absolute paths/.. segments in the extract helper.

Assessment

This skill appears coherent and low-risk for its stated purpose, but follow these precautions before enabling hooks or running scripts: 1) Inspect the included scripts (activator.sh, error-detector.sh, extract-skill.sh) and hook handlers to ensure their behavior is acceptable in your environment. 2) If you enable the OpenClaw hook, know it will inject reminder content into session bootstrap files — this is expected but opt-in. 3) Make scripts executable only when you intend to use them (chmod +x) and run extract-skill.sh from a directory where creating a ./skills/ subfolder is safe. 4) The error detector reads CLAUDE_TOOL_OUTPUT (tool output provided by the agent) — ensure your agent runtime does not populate that variable with sensitive data you don't want re-logged. 5) If you have strict security controls, prefer manual use (create .learnings/ and copy templates) instead of enabling hooks globally.

Like a lobster shell, security has layers — review code before you run it.

Logging Format

Learning Entry

.learnings/LEARNINGS.md

 :

## [LRN-YYYYMMDD-XXX] category

**Logged**: ISO-8601 timestamp
**Priority**: low | medium | high | critical
**Status**: pending
**Area**: frontend | backend | infra | tests | docs | config

### Summary
One-line description of what was learned

### Details
Full context: what happened, what was wrong, what's correct

### Suggested Action
Specific fix or improvement to make

### Metadata
- Source: conversation | error | user_feedback
- Related Files: path/to/file.ext
- Tags: tag1, tag2
- See Also: LRN-20250110-001 (if related to existing entry)
- Pattern-Key: simplify.dead_code | harden.input_validation (optional, for recurring-pattern tracking)
- Recurrence-Count: 1 (optional)
- First-Seen: 2025-01-15 (optional)
- Last-Seen: 2025-01-15 (optional)

Hook Integration

Enable automatic reminders through agent hooks. This is 

opt-in

 - you must explicitly configure hooks.

Quick Setup (Claude Code / Codex)

Create 

.claude/settings.json

 in your project:

{
  "hooks": {
    "UserPromptSubmit": [{
      "matcher": "",
      "hooks": [{
        "type": "command",
        "command": "./skills/self-improvement/scripts/activator.sh"
      }]
    }]
  }
}


This injects a learning evaluation reminder after each prompt (~50-100 tokens overhead).

Full Setup (With Error Detection)

{
  "hooks": {
    "UserPromptSubmit": [{
      "matcher": "",
      "hooks": [{
        "type": "command",
        "command": "./skills/self-improvement/scripts/activator.sh"
      }]
    }],
    "PostToolUse": [{
      "matcher": "Bash",
      "hooks": [{
        "type": "command",
        "command": "./skills/self-improvement/scripts/error-detector.sh"
      }]
    }]
  }
}
