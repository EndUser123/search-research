Plugin: obey

GitHub:

 

https://github.com/Lexxes-Projects/obey

https://github.com/Lexxes-Projects/obey

Category:

 Plugins / Hooks / Productivity

What it does

Claude Code plugin that makes Claude actually follow user rules. Users say rules in natural language, obey stores them, injects them into every session, and actively blocks violations.

Features

/remember never push to main

 — saves rule, creates enforcement hook

3 scopes: global, stack-specific (Rust/Node/Python/Go/Java), project-local

17 hooks covering the entire Claude Code lifecycle

Hook-enforced rules actively block violations (exit 2)

Instruction rules remind at the right moment (before Write/Edit/Bash)

Stop hook: completion checklist before Claude can finish

Audit trail logging

Natural rule detection: says "remember" or "never" → auto-saves

Cross-platform: Linux, macOS, Windows

Zero dependencies beyond jq (auto-installed)

Install

/plugin marketplace add https://github.com/Lexxes-Projects/lexxes-plugins.git
/plugin install obey@lexxes-plugins


Why it matters

Every Claude Code user has this problem: you tell Claude a rule, it agrees, then breaks it 5 minutes later. obey fixes this with persistent storage + active enforcement via hooks.
