# DeepSeek Quietly Taught AI to Think in Pictures — Here's What Happened
what if the smartest AI in the world one that can write code pass bar exams and debug your entire code base simply cannot count the people in a photograph Not because it doesn't understand what counting is not because it can see the image but because of something deeper something nobody had a good name for until now A new paper from Deepseek just dropped and it identifies a fundamental flaw in how every modern multimodal AI reasons and then solves it Here is where we are today The last 2 years have produced an extraordinary generation of multimodal large language models GPT 5.4 Claude Sony 4.6 Gemini 3 Flash Quen 3 Gemma 4 These models can look at an image and hold a conversation about it They can read charts describe scenes answer questions about what they see The secret weapon powering the best of these is called chain of thought reasoning Instead of just blurting out an answer the model thinks out loud It reasons step by step checks its own logic and arrives at a more reliable conclusion Chain of thought made AI dramatically more capable overnight But here is the thing almost nobody is talking about Chain of thought is entirely linguistic Every single step of that reasoning happens in words The model never actually points at the image while it thinks It describes it names it refers And that turns out to be a much bigger problem than anyone expected Researchers have been aware of one version of this problem for a while They call it the perception gap If an image is low resolution or if the detail you care about is tiny the model simply cannot see it well enough to reason about it To fix crop the image into tiles Zoom in Use more pixels Models like Deepseek's earlier work and OpenAI's GPT4 tackle this head-on with dynamic highresolution patching And it works The models see better But this paper makes a bold argument Fixing perception was never enough because even when a model sees perfectly it can still completely collapse when the task requires precise spatial reasoning Think about counting every person in a packed crowd photo or navigating a maze or following a tangled line to its end point The model sees every pixel but when it tries to reason in language the person on the left the one in the red jacket near the wall it loses track References drift Objects get confused with each other The answer falls apart The paper calls this the reference gap And it is not a perception problem It is a language problem Natural language is fundamentally too ambiguous to serve as a precise pointer inside a continuous visual space When you ask a model to reason about dense spatial layouts using only words you're asking it to navigate with a map drawn in fog So here is deep answer Instead of asking the model to describe what it sees while it reasons teach it to point The framework is called thinking with visual primitives The core idea is surprisingly elegant Two basic constructs from computer vision bounding boxes and points are elevated from outputs to units of thought They are interled directly into the model's chain of thought right alongside the words So instead of the model thinking there is a bear climbing a tree and two bears on the ground it thinks there is a bear and simultaneously draws a box around it at pixel coordinates Then another bear another box Then it counts from the boxes not from words from coordinates The paper draws a beautiful analogy to human cognition When you navigate a complex maze or count objects in a dense scene you don't do it purely in your head You point you gesture you track with your finger That physical grounding reduces cognitive load and keeps you accurate These researchers are giving the model the same tool a finger a spatial anchor something to hold onto They call bounding boxes and points visual primitives the minimal units of spatial thought Now let us talk about how they built this and why the architecture choice is almost as impressive as the idea itself The model is built on DeepSeek V4 flash a mixture of experts architecture with 284 billion total parameters but only 13 billion active during inference That already makes it dramatically more efficient than its parameter count suggests But the visual token efficiency is where things get genuinely wild When you feed an 800 by 800 image into most Frontier models they use somewhere between 660 and 1100 visual tokens to represent it This model it uses approximately 90 entries in the KV cache That is a 756 times compression ratio from raw pixels to final cache entries It achieves this through a two-stage compression First a 3x3 spatial merge in the vision transformer which collapses nine adjacent patch tokens into one Then a compressed spares attention mechanism in the language model compresses again by a factor of four The result is a model that operates with a fraction of the visual memory while maintaining the same cognitive depth Less tokens less compute same reasoning quality That is the bet they are making Training a model to think with visual primitives is not trivial They designed a four- stage pipeline First pre-training where the model learns the basic grammar of visual primitives They scraped nearly 98,000 box grounding data sources from the web ran them through a two-step quality filter and ended up with over 40 million highquality annotated samples The model learns to output coordinates as naturally as it outputs word Next specialized supervised fine-tuning separately for thinking with grounding using bounding boxes and thinking with pointing using coordinate sequences Keeping these two separate avoids conflicts when training data is limited Then reinforcement learning with custom reward models that evaluate format quality and accuracy for counting tasks The reward uses smooth exponential decay near correct answers are only lightly penalized which provides a much richer learning signal than binary right or wrong Finally the two specialists are merged through unified rejection fine-tuning then consolidated through on policy distillation where the merged student model learns directly from both expert teachers Now for the part everyone actually wants to know How does it perform Deepseek evaluated across 11 benchmarks public and in-house spanning counting spatial reasoning and topological reasoning and the results are striking on Pixmo count and object counting benchmark 89.2% exact match that beats Gemini 3 flashes 88.2% GPT 5.4's 76.6% and clothe Sony 4.6's sixes 68.7% on fine grain counting 88.7% the highest of all models tested on spatial reasoning benchmarks it matches or exceeds every model across most categories on the MI bench hallucination test 85.3% top score but the most dramatic result is in topological reasoning on maze navigation all frontier models cluster between 48 and 51% accuracy this model scores 56.9% On path tracing competitors score between 24 and 46% This model scores 56.7% Those are not marginal improvements Those are a different class of capability achieved with a model running on 90 KV cache entries per image Why does this matter beyond benchmark numbers Because this paper is making a philosophical argument not just an engineering one The conventional wisdom in multimodal AI has been see more reason better more pixels more resolution more visual tokens This paper says no The bottleneck is not perception it is reference You can give a model perfect vision and it will still lose track of what it is talking about The moment it has to reason about space The fix is not more pixels It is giving the model a way to anchor its thoughts to physical coordinates That reframing has enormous implications It suggests that the path to true system 2 multimodal reasoning requires AI to develop something analogous to deactic pointers The ability to gesture while thinking to hold something in visual space while the reasoning continues around it This is a paper worth reading slowly
