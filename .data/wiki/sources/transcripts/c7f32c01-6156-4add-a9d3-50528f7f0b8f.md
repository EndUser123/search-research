Abstract Base Classes

Abstract Base Classes (ABCs) in Python allow you to define 

interfaces

 that subclasses must implement. They help enforce contracts, enable 

polymorphism

https://www.lowleveldesignmastery.com/oops-refresher/03-polymorphism/

, and make your code more maintainable and self-documenting.

What Are ABCs?

Abstract Base Classes are 

classes

https://www.lowleveldesignmastery.com/oops-refresher/00-classes-and-objects/

 that cannot be instantiated directly. They define abstract methods that must be implemented by subclasses. ABCs help ensure that 

classes

https://www.lowleveldesignmastery.com/oops-refresher/00-classes-and-objects/

 follow a specific interface or contract.
