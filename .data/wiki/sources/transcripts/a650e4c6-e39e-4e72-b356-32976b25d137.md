Here is chatgpt extract of that page, so it stays here as a copy:

Summary:

In driver version 536.40, NVIDIA introduced a new method to enable applications to use shared memory when GPU memory is exhausted, preventing crashes by allowing applications to run at lower speeds. However, Stable Diffusion, which often requires close to 6 GB of GPU memory, may invoke this mechanism on 6 GB GPUs, resulting in reduced application speed. Driver version 546.01 and above introduced a setting to disable the shared memory fallback, providing stable performance at the risk of potential crashes if GPU memory requirements are exceeded.

Instructions to Disable Shared Memory Fallback for Stable Diffusion:

Run Stable Diffusion and note the path of the running python.exe process.
Open NVIDIA Control Panel.
In the 3D Settings section, click on Manage 3D settings.
Navigate to the Program Settings tab and click Add to customize programs.
Browse and select the Python executable file from Step 1.
Click on CUDA - Sysmem Fallback Policy and set the value to Prefer No Sysmem Fallback.
Click Apply to confirm.
Re-launch Stable Diffusion for the changes to take effect.
