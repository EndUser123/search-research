## Patterns detected across sessions

### Pattern 1: "Design for what fires, not what theoretically could" (3 concepts, 1 session)
- [[couple-triggers-to-events-that-actually-fire]] — features coupled to commands the operator never invokes are dead code
- [[forgetting-not-rejecting-distinguish-non-use-from-disapproval]] — operator forgetting ≠ operator rejecting
- [[passive-monitoring-over-active-probing]] — passive monitoring wins over active probing because active probing causes harm

**Meta-pattern:** this fleet consistently over-designs proactive mechanisms (active probes, lint-coupled features, session-start health checks) that either cause harm or never fire. The recurring correction is: couple to what actually happens, use reminders for forgotten maintenance, and let failures surface naturally rather than probing for them.

### Pattern 2: "Inference without verification" (recurring across sessions)
- [[inference-in-code-blind-spot]] — writing guessed constants into code without running the verification tool
- [[plausible-narratives-substitute-for-verification]] — fabricating explanations for failures instead of running diagnostics
- [[verify-before-write-hook-design]] — the structural fix (hook to enforce verification)

**Meta-pattern:** the agent defaults to inference when verification is available but costs more effort. This has appeared 5+ times across sessions (yt-is fetch failures, cc-council stub propagation, Perplexity quota guessing, session-end fatigue claims, ChatGPT ensemble diagnosis). The structural fix that works is: make verification mandatory (hook) rather than advisory (prose rule).

### Pattern 3: "Knowledge system evolving from collection to stress-testing" (this session's arc)
- TTS research → Perplexity quota → meta-analysis → tool-failure lifecycle → epistemic knowledge system
- 4 independent LLMs (Grok, DeepSeek, Claude, Gemini/Perplexity) converged on confidence decay + epistemic debt
- The wiki is transitioning from a static archive to a self-aware knowledge system with debt tracking

**Meta-pattern:** each major session extends the knowledge system's self-awareness. The trajectory: passive archive → gap detection → proactive suggestions → epistemic debt tracking → (future) self-motivating re-research.

The system doesn't just track what it knows — it tracks how confident it is and what needs re-checking. This is the structural implementation of "designing-harnesses-that-make-good-behavior-the-path-of-least-resistance" applied to knowledge quality.
