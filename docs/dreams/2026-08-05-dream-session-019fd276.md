### Candidate 1: retry-with-fallback model pattern for ship skills

- **Proposed path:** wiki/concepts/retry-with-fallback-model-pattern.md
- **provenance:** dream-proposal
- **Promotion path:** corpus-frequency (≥2 instances)
- **Pattern:** when a workflow agent fails on its primary model, retry once with a different model from the pool before logging a warning and continuing. The retry must use a different model (not the same one — same blind spots), and the workflow must not block on a single agent failure. This applies to any multi-agent pipeline where one agent's failure shouldn't halt the whole run.
