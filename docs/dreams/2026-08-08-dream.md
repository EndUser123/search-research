### Candidate 2: Pipeline phase-gate state machines must reset on re-entry, not inherit blocked state

- **Proposed path:** wiki/concepts/pipeline-phase-gate-reset-on-reentry.md
- **provenance:** dream-proposal
- **Promotion path:** corpus-frequency (≥2 instances)
- **Pattern:** when a pipeline (ship-py) is re-run after a prior blocked attempt, the state file retains `phase: blocked` from the prior run.
