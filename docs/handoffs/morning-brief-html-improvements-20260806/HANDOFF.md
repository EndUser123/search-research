## Synthesized suggestions (consensus + unique contributions)

### Consensus (all 3 models agreed)

1. **Add a table-of-contents / jump navigation bar** — the page is ~2000 lines with 7+ sections. Sticky anchor nav with pure CSS (`position: sticky; top: 0`).

2. **YouTube watch plan should come before inventory statistics** — the 5-video coverage shortlist (actionable recommendation) currently appears after the KPIs and bar charts (inventory). Invert the order.

3. **Use compact rows, not boxy cards, for 125+ video items** — current `.watch-item` card is too heavy for 125 repetitions. Grid-template: `40px 1fr 60px 30px` (rank / title / duration / priority).

4. **Accessibility needs explicit work** — proper heading hierarchy, `aria-label` on sections, visible focus states, don't rely on color alone for urgency, meaningful link text.

### High-value structural (ChatGPT-led)

5. **Merge "Start Here" and "Security" into one action card** — the same Scotiabank alert appears in both sections. Use a single `<section id="action" class="section--critical">` with a `<dl>` fact-list.

6. **Remove `<base target="_blank">`** — global side effect. Put `target="_blank" rel="noopener noreferrer"` on individual external links instead.

7. **Show generation timestamp and data freshness** — a daily brief needs a visible "Generated: August 6, 2026 6:00 AM" marker.

### Design refinements

8. **Mixed typography** — keep Georgia for `<h1>`, switch body/dashboard text to sans-serif for scanning.
9. **Three prominence levels** — `section--critical` (alert), `section--primary` (watch plan), `section--secondary` (newsletters).
10. **Print styling** — `@media print` rules + a "print expanded" generator option with all `<details open>`.

### Code quality

11. **Component-based CSS** — `.panel`, `.kpi-card`, `.badge`, `.bar-row`, `.accordion`, `.list-row` instead of page-region styles.
12. **KPI grid with `auto-fit`** — `repeat(auto-fit, minmax(150px, 1fr))` instead of hardcoded `repeat(4, ...)`.
13. **Generator-side HTML escaping** — email titles and URLs are untrusted inputs even when produced locally.
