## Intent Summary
v1 budget coordination adds char-count budgets to 3 conditional hooks (reasoning_mode_selector, cognitive_enhancers, testing_strategy_router) to prevent context overflow on long prompt + injection chains. A central `unified_detection` hook initializes `remaining_budget=20000`; conditional modules decrement it; a trace log records the end state. The design is tiered (safety modules skip budget entirely) and fail-open (missing budget → unlimited).

## Logical Gaps & Inconsistencies

1.1. [HIGH] **NameError when module in SAFETY_MODULES**: `budget` is assigned at line 72 inside `if _mod_name not in SAFETY_MODULES:` but consumed at line 158 after the if-block exits. When a module IS in SAFETY_MODULES, budget is never assigned → NameError. Affects reasoning_mode_selector.py (lines 72, 158), cognitive_enhancers.py (lines 438, 480), and testing_strategy_router.py (lines 99, 114). Fix: initialize `budget = context.data.get("remaining_budget", 20000)` before the safety check, then guard with `if _mod_name not in SAFETY_MODULES and budget < min_chars:`. (source: adversarial-compliance/COMP-001, adversarial-quality/QUAL-001)

1.2. [HIGH] **reasoning_mode_selector early return doesn't decrement budget**: When budget guard fires (lines 74-76), function returns empty without decrementing remaining_budget. When short-prompt guard fires (line 86), also returns empty without decrementing. cognitive_enhancers correctly decrements before its early return; reasoning_mode_selector does not. Creates inconsistent skip-cost behavior. Fix: add `context.data["remaining_budget"] = budget` before each early return. (source: adversarial-logic/LOGIC-001, adversarial-logic/LOGIC-002)

1.3. [HIGH] **cognitive_enhancers short-circuit path also doesn't decrement**: The `_is_actionable_prompt` false path at line 447 returns empty without budget decrement. Only the successful injection path at line 480 decrements. If a prompt is actionable but later found to have no selected enhancers, budget is unchanged despite analysis work being done. (source: adversarial-logic/LOGIC-003)

## Hidden Assumptions & Fragile Dependencies

2.1. [MEDIUM] **direct_answer_hint is computed but never consumed**: `unified_detection` sets `context.data["direct_answer_hint"]` (line 642) but none of the 5 reviewed files read it. If it was intended to gate behavior (e.g., boost budget for diagnostic questions), that logic is absent. Dead data that may confuse future maintainers. Verify consumer exists or remove. (source: adversarial-compliance/COMP-004, adversarial-testing/TEST-004)

2.2. [MEDIUM] **Hard cap 20000 chars is unverified against maximum injection size**: If all 3 conditional modules inject at max, combined injection could approach 1000+ chars. With 10+ cognitive enhancers selected, the combined length could reach several thousand. No verification that 20k cap is sufficient for all cases or that it is ever actually exhausted. If exhaustion is the goal, this needs validation. If it's just a safety limit, the value is arbitrary. (source: Phase 2 meta-critique)

2.3. [LOW] **Work.md line references don't match actual code**: Section 4 claims "Budget decrement before return" for reasoning_mode_selector but the code doesn't do this. Documentation was written before implementation was finalized. (source: adversarial-logic/LOGIC-006)

## Missing Obvious Actions / Best Practices

Unit tests use mocked contexts and don't catch integration-level drift. (source: adversarial-testing/TEST-001)

3.5. [MEDIUM] **Verify or remove direct_answer_hint consumer**: Either wire it into budget decisions (e.g., direct-answer prompts get higher initial budget) or remove it as dead code. (source: adversarial-testing/TEST-004)

## Risks and Edge Cases

4.1. [HIGH] **Latent time bomb if module added to SAFETY_MODULES**: If any of the 3 budget-aware modules are added to SAFETY_MODULES in the future, they will crash with NameError. The guard pattern makes this easy to trigger accidentally. The `budget` variable must be initialized outside the safety check regardless of intended design. (source: adversarial-compliance/COMP-001)

4.2. [MEDIUM] **Budget drift when reasoning contract already applied**: `reasoning_mode_selector` line 102 shortens `system_context` when `contract_active` is True, but the budget decrement at line 158 uses the full `system_context + user_message` length. If the contract was already active, the actual injection is shorter than the budget deduction — budget appears smaller than reality. (source: Phase 2 meta-critique)

4.3. [MEDIUM] **cognitive_enhancers resolution conflict affects injection length**: `resolve_conflict()` may reduce the enhancer list. Budget decrement uses `len(injection)` after selection, which is correct. But if `_build_injection` returns an empty string (shouldn't happen), decrement is zero and budget appears inflated. (source: adversarial-logic/LOGIC-005)
