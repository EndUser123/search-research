# RSN Formatter Reference Guide

**File**: `P:\.claude\hooks\__lib\rsn_formatter.py`
**Priority**: P0 (shared infrastructure)
**Consumers**: `/critique`, `/gto`, `/uci`, `/skill-ship`

---

## Overview

RSNFormatter produces dynamic section critique output with lazy section creation, severity ordering, and sequential numbering.

---

## Domain → Section Routing

### Custom Section Definitions (highest priority)

Pass `section_definitions: dict[str, tuple[str, str]]` to the constructor:

```python
formatter = RSNFormatter(section_definitions={
    "spec_compliance": ("Specification Compliance Issues", "spec_compliance"),
    "code_quality": ("Code Quality Issues", "code_quality"),
})
```

### Default Routing (when no custom definition matches)

| Domain keywords | Section |
|----------------|---------|
| `security`, `inv`, `invariant`, `logic`, `api` | Logical Gaps & Inconsistencies (`logical_gaps`) |
| `performance`, `concurrency`, `reliability` | Hidden Assumptions & Fragile Dependencies (`hidden_assumptions`) |
| `test`, `testing`, `coverage`, `quality`, `maintainability` | Missing Obvious Actions / Best Practices (`missing_actions`) |
| `risk`, `edge_case` | Risks and Edge Cases (`risks`) |
| `docs`, `documentation` | Concrete Recommendations (`recommendations`) |
| *(anything else)* | Severity fallback (see below) |

### Severity Fallback (no domain match)

| Severity | Section |
|----------|---------|
| CRITICAL, HIGH | Logical Gaps & Inconsistencies (`logical_gaps`) |
| MEDIUM | Hidden Assumptions & Fragile Dependencies (`hidden_assumptions`) |
| LOW | Open Questions / Unknowns (`open_questions`) |

## Finding ID Generation

Finding IDs are generated by callers (e.g., `_generate_finding_id` in `skill-ship/lib/formatter.py`). The format is `PREFIX-HASH` where:

- `PREFIX`: Uppercase first 8 characters of the check name
- `HASH`: MD5 hex digest (first 4 chars) of the full check name

Example: `context_size_check` → `SHIP-CONTEXT_-a3f2`

**Collision risk**: ~1/65536 for same-prefix names. The Stop hook quality gate (`StopHook_rsn_display_gate.py`) detects duplicates.

---

## Empty-Section Behavior

Sections are created **lazily** — only when findings exist for them. This means:

- If no findings have `domain="security"`, the `logical_gaps` section is never created
- Numbering is dense (1., 2., 3.) even if earlier sections were skipped
- An RSNResult with no findings produces only the header + `0 — Do ALL Recommended Next Steps`

## Output Formats

### `render_text()` / `render_markdown()`

Plain text with sequential numbering:
```
Recommended Next Steps

1. Logical Gaps & Inconsistencies
   1a. [CRITICAL] Fix YAML unsafe_load (path:12)
   1b. [HIGH][blast: 3, rev: 1.25] Add regex bypass protection (path:45)

0 — Do ALL Recommended Next Steps
```

### `render_toon()`

Machine-parseable TOON format:
```
{RSN}
  severity_totals: CRITICAL=1 HIGH=1 MEDIUM=0 LOW=0
  [logical_gaps]
    (SHIP-001) CRITICAL @security
      message: Fix YAML unsafe_load
      ref: path:12
      action: Manual
      effort: 5
      blast: 3
      rev: 1.25
      conf: H
  [/logical_gaps]
{/RSN}
```

### `validate()`

Programmatic validation returning a list of quality issues:
- Duplicate finding IDs
- Empty finding messages
- Section overflow (>20 findings per section)

## Custom Section Definitions Pattern

When overriding routing for a skill, define all domains the skill uses:

```python
MY_SECTIONS = {
    "spec_compliance": ("Specification Compliance Issues", "spec_compliance"),
    "context_size": ("Context Size Issues", "context_size"),
    "integration": ("Integration Issues", "integration"),
    "evaluation": ("Evaluation Issues", "evaluation"),
    "optimization": ("Optimization Issues", "optimization"),
    "distribution": ("Distribution Issues", "distribution"),
}

formatter = RSNFormatter(section_definitions=MY_SECTIONS)
```

## Common Pitfalls

1. **Unknown domain + CRITICAL severity** → routes to `logical_gaps`. If you intended `missing_actions`, explicitly set `domain="quality"`.

2. **`"quality"` domain** → routes to `missing_actions` (not `logical_gaps`). Use `domain="logic"` for CRITICAL-quality issues.

3. **`"test"` domain** → routes to `missing_actions`. This is intentional — test coverage gaps are "missing obvious actions."

4. **Empty `RSNResult`** → `render_text()` produces only the header. This is correct behavior ("nothing to do"), not an error.

5. **TOON `ref:` field** → Only emitted when `file_ref` is non-empty. Always check field presence, not just value.

## Stop Hook Quality Gate

`StopHook_rsn_display_gate.py` validates RSN output in responses:

- **Duplicate finding IDs**: Detected in both TOON and text format
- **Empty messages**: Detected in TOON format
- **Section overflow**: Warns when >20 findings per section (cognitive load risk)

The gate runs on every Stop event when `RSN_DISPLAY_GATE_ENABLED=true` (default).
