**Problem:** TOCTOU issues rated inconsistently (HIGH vs LOW).

- HIGH: TOCTOU affects data correctness (e.g., stale handoff presented as fresh)

**Improvement:** When specialists recommend structural changes, they should provide concrete code examples, not just descriptions.
