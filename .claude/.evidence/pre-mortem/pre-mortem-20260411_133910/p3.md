handoff_session_id = data.get("session_id")

### 3.2. [MEDIUM] Code duplication in file discovery pattern

**Location:** P:\.claude\skills\recap\__init__.py:1448-1461, 1575-1587

**Problem:** Three functions use identical glob+sort pattern:
- `_load_from_direct_transcript` (lines 1448-1461)
- `_get_current_session_id` (lines 1575-1587)

Both iterate `.glob("*.jsonl")`, filter with `_is_transcript_file()`, sort by mtime descending, and take the first result.

**Impact:** Future changes require updates in multiple places. Violates DRY principle.

**Recommendation:** Extract shared helper:
```python
def _get_most_recent_transcript(transcript_dir: Path) -> Path | None:
    """Get the most recent transcript file from a directory."""
    jsonl_files: list[tuple[float, Path]] = []
    for jsonl_file in transcript_dir.glob("*.jsonl"):
        if _is_transcript_file(jsonl_file):
            try:
                mtime = jsonl_file.stat().st_mtime
                jsonl_files.append((mtime, jsonl_file))
            except OSError:
                continue
    if not jsonl_files:
        return None
    jsonl_files.sort(key=lambda x: x[0], reverse=True)
    return jsonl_files[0][1]
```
