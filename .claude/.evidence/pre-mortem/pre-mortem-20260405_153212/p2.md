1. **COMP-002 ASCII apostrophe finding is wrong** — adversarial-compliance claims `doesn'?t` only matches curly apostrophe (U+2019), not ASCII. Verdict: INCORRECT. The regex `doesn'?t` in a Python raw string means: `doesn` + optional ASCII apostrophe (`'`) + `t`. So "doesn't" (ASCII) IS matched by `doesn'?t`, and "doesn't" (curly) IS matched by `doesn\u2019t`. Both forms are covered. The finding should be DOWNGRADED to LOW or CLOSED.
