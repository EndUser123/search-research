## Intent Summary
Fix the PreCompact hook's `prior_transcript_path=N/A` bug: at compaction time, `load_raw_handoff()` was returning S_NEW's own handoff (newest by mtime) instead of S_OLD's, causing all handoff chains to break at depth=1. The fix adds `exclude_session_id` parameter to skip S_NEW's handoff when scanning for S_OLD.

## Logical Gaps & Inconsistencies

1.1. [HIGH] `handoff_files.py:374` — Falsy empty-string check on `sid` — The condition `if sid and sid != exclude_session_id:` treats empty string as falsy. If a handoff file has `source_session_id = ""` (edge case; PreCompact always provides a valid UUID), the exclude loop would skip it incorrectly. Fix: change to `if sid is not None and sid != exclude_session_id:`. Note: this is defense-in-depth; the empty-string case cannot occur through PreCompact's normal code path where `session_id` is always a valid UUID. (source: adversarial-logic, file:374)
