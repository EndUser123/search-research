## Intent Summary
This work implements a two-phase subagent delegation policy for Claude Code: a UserPromptSubmit hook (`delegation_prospector`) surfaces delegation opportunity advisories before task execution, and a Stop hook (`Stop_subagent_opportunity`) surfaces missed-opportunity advisories after task completion without Agent tool usage. A CLI analysis script (`tune_subagent_gate.py`) provides telemetry-based threshold tuning.

**QA-002 Verification Criteria:** 50-79% = Warning — Significant issues in 2+ domains, address HIGH items first.

The system has one CRITICAL (dead code — hook never runs) and one HIGH (path traversal) issue alongside multiple MEDIUM issues. The delegation policy cannot function as designed until the dead code is resolved.

## Logical Gaps & Inconsistencies
1.1. [CRITICAL] delegation_prospector.py is dead code — `@register_hook` decorator at line 93 self-registers into the HOOKS dict, but `registry.py:_load_hooks()` never imports the module. The hook name does not appear in `core_hook_modules` and no `_try_import_hook` call references it. Result: hook code exists but never executes. (source: adversarial-compliance, UserPromptSubmit_modules/delegation_prospector.py:93, registry.py:607-661)
1.2. [HIGH] Path traversal in `_load_session_opportunities()` and `_save_session_opportunities()` — `terminal_id` and `session_id` are interpolated directly into file paths without sanitization. A malicious input could inject `../` to escape `_LOG_DIR`. The `_LOG_DIR` containment is the only constraint. (source: adversarial-security, Stop_subagent_opportunity.py:37,49)

## Hidden Assumptions & Fragile Dependencies
2.1. [MEDIUM] Prompt content is written to plaintext `.jsonl` logs without sensitive data redaction. API keys, bearer tokens, or passwords appearing in user prompts are written to `delegation_prospector.jsonl` unredacted. (source: adversarial-security, delegation_prospector.py:85)
2.2. [MEDIUM] Silent `OSError` suppression means all telemetry events are dropped without warning when disk is full, permission denied, or directory missing. No fallback path, no warning emission, no retry. (source: adversarial-io-validation, delegation_prospector.py:89, Stop_subagent_opportunity.py:71)
2.3. [MEDIUM] `_OPPORTUNITY_THRESHOLD = 3` is an arbitrary constant with no empirical calibration. No specialist verified this threshold against actual usage patterns. (source: adversarial-io-validation meta-note)

## Risks and Edge Cases

## Concrete Recommendations
5.1. [CRITICAL] Add `"delegation_prospector"` to `core_hook_modules` in `registry.py` (after line 660) to actually wire the hook into the dispatch chain.
5.2. [HIGH] Sanitize `terminal_id` and `session_id` before use in file paths: `re.sub(r"[^a-zA-Z0-9_.-]", "", v)` or equivalent. (source: adversarial-security)
5.3. [MEDIUM] Add sensitive data redaction before logging prompts. Strip patterns matching API keys, bearer tokens, and credential formats. (source: adversarial-security)
5.4. [MEDIUM] Replace `except OSError: pass` with warning emission in `_log_delegation_event()` and `_log_opportunity_event()`. At minimum, emit a warning so failures are observable. (source: adversarial-io-validation)
5.5. [MEDIUM] Add `if not isinstance(tool_events, list): return early_value` guard in `_count_file_operations()`, `_agent_was_used()`, and `_get_touched_files()`. (source: adversarial-security)
5.6. [LOW] Add `_LOG_DIR.mkdir(parents=True, exist_ok=True)` to `_save_session_opportunities()` before the `open()` call. (source: adversarial-compliance)
