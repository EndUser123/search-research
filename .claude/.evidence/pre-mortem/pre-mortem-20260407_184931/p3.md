## Intent Summary

This work implements a UserPromptSubmit hook that detects design/implementation intent in user prompts and injects cognitive guardrails to prevent two systemic LLM failures: (1) discovery failure - proposing new implementations without searching for existing ones, and (2) instance-class confusion - solving symptoms without checking broader problem classes. The hook uses three regex-based detection patterns (action verbs + objects, planning framing, slash commands), environment variable gating, and FRAMEGUARD pattern compliance with priority 2.0.
