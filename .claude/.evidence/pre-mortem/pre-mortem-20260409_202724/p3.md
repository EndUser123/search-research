1.2. [MEDIUM] TTL comparison uses `>` instead of `>=` — entries at exactly TTL age remain valid for ~1 additional second (cache.py:107, cache.py:71)

1.3. [MEDIUM] Multiple TTL cleanup threads spawned for same terminal_id — each QueryCache() instance with shared terminal_id starts its own daemon thread, all redundantly sweeping the same cache every 60s (cache.py:55-63)

## Concrete Recommendations

5.2. [MEDIUM] Add overall timeout wrapper to asyncio.gather — `await asyncio.wait_for(asyncio.gather(*search_tasks, return_exceptions=True), timeout=backend_timeout * 1.5)` (router_async.py:291)

5.3. [MEDIUM] Change TTL comparison from `>` to `>=` for precise expiration semantics (cache.py:107, cache.py:71)

5.4. [MEDIUM] Use class-level flag to ensure only one cleanup thread per terminal_id instead of one per QueryCache instance (cache.py:55)

5.5. [LOW] Consider caching HyDE results under both enhanced and original query keys — trading memory for better hit rate (router_async.py:309-313)
