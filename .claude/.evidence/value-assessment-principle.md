# Value Assessment Principle

**When**: Evaluating whether guidance adds value to a workflow (new prompt, skill addition, pattern).

**How**: Identify the UNIQUE contribution — what this framing provides that existing skills don't.

**Redundancy check**: If a skill already covers ~70%+ of the use case with equivalent rigor, the marginal value is low.

**Applied example**: `/rca` skill is comprehensive (9-step investigation, evidence tiers, hypothesis scoring) but lacked explicit restatement step and stale-vs-real failure distinction — those were the unique elements worth preserving.

**Anti-pattern**: Greenfield proposals without a search pass. Extending existing solutions when they cover ~70%+ is preferred.
