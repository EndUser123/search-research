## Intent Summary

The GTO batch detection enhancement adds three sequential strategies to `_detect_batch_groups()` for grouping gaps before RSN output: Strategy 1 batches gaps at the same file:line with 70% effort multiplier, Strategy 2 groups `# type: ignore` gaps by root cause keyword with 50% effort, and Strategy 3 passes individual gaps through. The `format_rsn_from_gaps()` bridge function passes results to `RSNFormatter`. The code is in production use but has critical bugs causing wrong severity assignment, crashes on malformed input, and silent data loss.

## Logical Gaps & Inconsistencies

1.1. [BLOCKER] **Severity case mismatch — all batches report LOW on every run** (source: adversarial-testing/TEST-001, next_steps_formatter.py:388-390, 445-447)
   `severity_order = {"CRITICAL": 0, "HIGH": 1, "MEDIUM": 2, "LOW": 3}` but `Gap` dataclass produces lowercase values. `min()` always falls through to default 99 → every batched finding gets LOW severity regardless of actual contents. Affects every batch on every run with valid input.

1.2. [BLOCKER] **AttributeError when message is None/non-string** (source: adversarial-io-validation/IO-001, next_steps_formatter.py:428-429)
   `kw in msg.lower()` called without string type guard. Malformed gap with `message=None` causes `AttributeError: 'NoneType' object has no attribute 'lower'`.

1.3. [BLOCKER] **TypeError when message values are unhashable** (source: adversarial-io-validation/IO-002, next_steps_formatter.py:393)
   `dict.fromkeys(g.get("message", "") for g in batch_gaps)` — generator expression with unhashable message values (list, dict) causes `TypeError: unhashable type`.

1.4. [HIGH] **Location key collision — same-file gaps not batched together** (source: adversarial-quality/QUAL-001, next_steps_formatter.py:369-374)
   `fp = gap.get('file_path') or ''` normalizes `None` to `''` but the key is built as `(fp, ln)`. Two gaps at same file but one with `file_path=''` and one with `file_path=None` produce different keys `('', None)` vs `(None, None)` — they will NOT be batched together.

1.5. [HIGH] **Strategy 2 reason split loses attribute name context** (source: adversarial-quality/QUAL-002, next_steps_formatter.py:433)
   `reason = msg[reason_start:].split('.')[0][:40]` truncates at first dot. For `# type: ignore[attr-defined] — cannot find attribute "foo"`, splits into `['# type: ignore[attr-defined]', ' — cannot find attribute "foo"']` → reason = `# type: ignore[attr-defined]`. Distinct attribute names conflated into one batch.

1.6. [HIGH] **Schema validation gap — malformed output silently passes through** (source: adversarial-meta-critique/p2)
   `_detect_batch_groups()` produces a specific output schema (id, severity, message, file_ref, action_type, effort_minutes, domain, is_batch, batch_count, gap_ids) but no schema validation exists before passing to `RSNFormatter`. Malformed output silently propagates.

1.7. [HIGH] **Duplicate severity_order dict defined in two loops** (source: adversarial-meta-critique/p2, next_steps_formatter.py:388, 445)
   Identical `severity_order` dict defined inside both Strategy 1 and Strategy 2 loops. Maintenance hazard — future changes to one copy are easy to miss in the other. Also recreated on every batch group (minor performance).

1.8. [MEDIUM] **Double-truncation causes batch ID collisions** (source: adversarial-logic/LOGIC-001, next_steps_formatter.py:432-434)
   `reason[:20]` truncation of an already-truncated `reason[:40]` means distinct `# type: ignore` errors with different attribute names but identical 20-char prefixes produce identical `BATCH-IGNORE-{prefix}` IDs and merge incorrectly.

1.9. [MEDIUM] **Strategy 3 severity not normalized — mixed-case causes KeyError** (source: adversarial-quality/QUAL-003, next_steps_formatter.py:482)
   Strategy 3 uses `gap.get("severity", "LOW")` without `.upper()`, while Strategy 1/2 normalize via `severity_order` lookup. Mixed-case severity values pass through unchanged, risking `KeyError` in downstream `RSNFormatter.sort_by_severity()`.

1.10. [MEDIUM] **Partial location overlap silently drops gaps** (source: adversarial-testing/TEST-004, next_steps_formatter.py:379-380)
   `if any(i in used_indices for i in indices): continue` skips entire location group when ANY index was previously used. Indices `[0,1,2]` where index `0` was already used → indices `1` and `2` are silently dropped, not batched, not even emitted individually.

1.11. [LOW] **Windows drive letter colon creates ambiguous batch IDs** (source: adversarial-quality/QUAL-004, next_steps_formatter.py:407)
   `f'BATCH-LOC-{file_path}:{line_number}'` with `file_path='C:\repo\file.py'` produces `BATCH-LOC-C:\repo\file.py:10` — the colon after C is indistinguishable from the line number separator.

## Hidden Assumptions & Fragile Dependencies

2.1. [BLOCKER] **No error containment in format_rsn_from_gaps()** (source: adversarial-meta-critique/p2, next_steps_formatter.py:497-528)
   `format_rsn_from_gaps()` calls `_detect_batch_groups()` with no try/except. Any exception (IO-001, IO-002, or logic errors) propagates to RSN rendering. RSN generation crashes entirely on malformed input instead of degrading gracefully.

2.2. [HIGH] **Strategy 1/2 priority is undocumented — correctness unverified** (source: adversarial-logic, open_question; adversarial-meta-critique/p2)
   `used_indices` makes strategies mutually exclusive. Gap matching both Strategy 1 (location) and Strategy 2 (reason) criteria is claimed entirely by Strategy 1. No specialist verified whether location-based batching should actually have priority over reason-based batching for overlaps.

2.3. [HIGH] **Effort multipliers 0.7 and 0.5 have no empirical basis** (source: adversarial-io-validation/IO-003, next_steps_formatter.py:402, 450)
   Both multipliers are arbitrary thresholds with no justification, calibration data, or upper-bound validation. Values can exceed reasonable effort if input contains large numbers of gaps.

2.4. [MEDIUM] **sys.path mutation at import time — multi-terminal TOCTOU hazard** (source: adversarial-io-validation/IO-004, next_steps_formatter.py:312-322)
   `sys.path.insert(0, _claude_dir)` happens at module import time. In multi-terminal environments, the import ordering is non-deterministic. LOW severity because the try/except fallback is well-established and the mutation is one-time at import.

2.5. [MEDIUM] **Domain hardcoded for Strategy 1/2 batches, ignoring gap type** (source: adversarial-logic/LOGIC-002, next_steps_formatter.py:413, 460)
   Strategy 1 always uses `domain="code_quality"`, Strategy 2 always uses `domain="import"` regardless of the original gap type. Batched findings route to different RSN sections than equivalent non-batched findings.

2.6. [LOW] **find('# type: ignore') returning -1 produces msg[-1:] as grouping key** (source: adversarial-io-validation/IO-005, next_steps_formatter.py:428-434)
   If `# type: ignore` not found, `reason_start=-1` and `msg[-1:]` uses the last character as the grouping key — wrong behavior silently accepted.

2.7. [LOW] **GapFinding missing effort_estimate_minutes field** (source: adversarial-testing/TEST-006, gap_finder_subagent.py:33-47)
   `GapFinding.to_dict()` omits `effort_estimate_minutes`. When `_detect_batch_groups()` calls `gap.get("effort_estimate_minutes", 5)`, it always gets the default of 5 regardless of actual effort.

## Missing Obvious Actions / Best Practices

3.1. [HIGH] **Zero test coverage for batch detection logic** (source: adversarial-testing/TEST-002, next_steps_formatter.py:1-66; gap_finder_subagent.py)
   `_detect_batch_groups()` and `format_rsn_from_gaps()` have zero tests. All 3 strategies, severity aggregation, effort multipliers, and edge cases (None line_number, partial overlap, mixed-case severity) are completely untested. TEST-001 is currently undetected precisely because no tests exist.

3.2. [HIGH] **Normalize severity to uppercase in all 3 strategies** (source: adversarial-testing/TEST-001, next_steps_formatter.py:389, 446, 482)
   Add `.upper()` to severity values before lookup: `severities = [g.get("severity", "LOW").upper() for g in batch_gaps]`. Also apply to Strategy 3 pass-through at line 482.

3.3. [HIGH] **Add type guard before .lower() call** (source: adversarial-io-validation/IO-001, next_steps_formatter.py:428)
   Add `if not isinstance(msg, str): continue` before `kw in msg.lower()`.

3.4. [HIGH] **Sanitize message values before dict.fromkeys()** (source: adversarial-io-validation/IO-002, next_steps_formatter.py:393)
   Convert messages to strings or repr for hashability: `str_msgs = [str(m) if isinstance(m, str) else repr(m) for m in msgs]`.

3.5. [HIGH] **Normalize file_path to '' for both None and empty string** (source: adversarial-quality/QUAL-001, next_steps_formatter.py:369-374)
   Explicit coalescing: `fp = gap.get('file_path'); fp = fp if fp is not None else ''` — ensures both `None` and `''` produce the same location key.

3.6. [MEDIUM] **Use '|' separator in batch IDs instead of ':'** (source: adversarial-quality/QUAL-004, next_steps_formatter.py:407)
   Change `f'BATCH-LOC-{file_path}:{line_number}'` to `f'BATCH-LOC-{file_path}|{line_number}'` to avoid Windows drive letter ambiguity.

3.7. [MEDIUM] **Guard against -1 from find()** (source: adversarial-io-validation/IO-005, next_steps_formatter.py:428)
   Add `if reason_start == -1: continue` before using `reason_start` to extract the reason.

3.8. [MEDIUM] **Emit unused indices as individual findings instead of skipping** (source: adversarial-testing/TEST-004, next_steps_formatter.py:379-380)
   Instead of skipping entire location group on partial overlap, emit unused indices individually: `unused = [i for i in indices if i not in used_indices]; for i in unused: results.append(build_individual(i))`.

3.9. [MEDIUM] **Derive domain from matched keyword or original gap type** (source: adversarial-logic/LOGIC-002, next_steps_formatter.py:460)
   Instead of hardcoding `domain="import"`, map keywords to domains: `'no attribute'/'cannot find' → "code_quality"`, `'missing'/'import' → "import"`.

3.10. [MEDIUM] **Add effort upper-bound validation with documented justification** (source: adversarial-io-validation/IO-003, next_steps_formatter.py:402, 450)
   Cap multipliers and add constants with justification comments: `EFFORT_STRATEGY1_MULTIPLIER = 0.7  # Batched location gaps share fix effort` and `EFFORT_STRATEGY2_MULTIPLIER = 0.5  # Reason-based grouping reduces per-gap effort`.

3.11. [LOW] **Make severity_order a module-level constant** (source: adversarial-meta-critique/p2, next_steps_formatter.py:388, 445)
   Define `SEVERITY_ORDER = {"CRITICAL": 0, "HIGH": 1, "MEDIUM": 2, "LOW": 3}` at module level, reuse in both loops instead of duplicating the dict.

3.12. [LOW] **Add try/except around _detect_batch_groups() call** (source: adversarial-meta-critique/p2, next_steps_formatter.py:497-528)
   Wrap the call to `_detect_batch_groups()` in `format_rsn_from_gaps()` with try/except to prevent unhandled exceptions from crashing RSN rendering.

   Change `f'BATCH-LOC-{file_path}:{line_number}'` to `f'BATCH-LOC-{file_path}|{line_number if line_number else "NOLINE"}'`.

## Risks and Edge Cases

4.1. [MEDIUM] **Strategy 1/2 mutual exclusivity may conflate overlapping cases** (source: adversarial-logic, open_question)
   `used_indices` prevents a gap from appearing in both strategies. For a gap at `(file=X, line=Y)` with message containing `# type: ignore missing import`, Strategy 1 claims it exclusively — even though Strategy 2's reason grouping might be more appropriate.

4.2. [LOW] **50% effort multiplier may mislead on actual effort** (source: adversarial-io-validation/IO-003)
   Batched gaps claim 50% of actual effort. If the batched gaps each require separate investigation, the reduced estimate gives a false picture of total work.

4.3. [LOW] **Domain routing inconsistency between batched and non-batched findings** (source: adversarial-testing/TEST-005, next_steps_formatter.py:413, 460, 476-477)
   Batched findings route to `code_quality` or `import` sections. Non-batched findings route via `GTO_TYPE_TO_RSN_DOMAIN` mapping. Same gap could appear in different sections depending on whether it was batched.
