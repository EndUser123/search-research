# Critique: README-preview.html

## Intent Summary

This HTML file is a styled preview of the gitready README, generated by the /gitready skill. It includes a day-night theme toggle with CSS custom properties for light/dark modes, localStorage persistence, and Google Fonts. The goal is to let users preview how their README will look in browser with proper styling and theme switching.

## Hidden Assumptions & Fragile Dependencies

2.1. [MEDIUM] localStorage assumed always available — private browsing throws SecurityError (source: adversarial-quality, file:118, 121)
No try/catch around localStorage.setItem and getItem. Will break in strict privacy modes.

2.2. [MEDIUM] Toggle uses emoji icons but CSS variable `--toggle-fg` cannot control emoji color (source: meta-critique)
Emoji render in their own color regardless of CSS. The `--toggle-fg` variable is defined but ineffective for its stated purpose.

2.3. [MEDIUM] `transition: all` on toggle button animates unintended properties (source: meta-critique, file:69)
`transition: all 0.2s ease` will animate every animatable property, not just theme-relevant ones. Inconsistent with explicit property transitions elsewhere.

2.4. [LOW] Google Fonts CDN is a single point of failure (source: meta-critique, file:8)
No fallback fonts if CDN is unreachable. Corporate networks and privacy tools may block it.

## Missing Obvious Actions / Best Practices

3.1. [MEDIUM] `prefers-reduced-motion` not supported (source: adversarial-quality, file:51, 69, 96)
Transitions run at 0.2s regardless of user preference. Causes vestibular discomfort for sensitive users.

3.2. [MEDIUM] Missing `:focus-visible` styles for keyboard navigation (source: adversarial-quality, file:54-75)
Toggle button and links have no visible focus indicator for keyboard-only users.

3.3. [MEDIUM] Inline styles bypass CSS variable system (source: adversarial-quality, file:129-130)
Hardcoded `color:#e8e0f0` in header. If gradient changes, subtitle becomes unreadable without updating inline style.

3.4. [LOW] Tables lack `scope` attributes for screen readers (source: adversarial-quality, file:155-159)
`<th>` elements without `scope="col"` may be announced incorrectly by screen readers.

## Risks and Edge Cases

4.1. [MEDIUM] Flash of light theme (FOUC) possible on page load (source: meta-critique)
The IIFE that restores saved theme runs after HTML parses but before paint. Users with dark theme saved will briefly see light theme.

4.2. [LOW] Emoji toggle icons render inconsistently across platforms (source: adversarial-quality, file:108)
HTML entities `&#9788;` and `&#9790;` display differently on Windows, macOS, and mobile. No SVG fallback.

4.3. [LOW] Broken slide links all point to same empty URL (source: adversarial-critic, file:589-592)
Three separate links have identical empty targets. User confusion when none work.

## Concrete Recommendations

5.1. [HIGH] Remove line 205 internal developer note: "Runtime should match the exported NotebookLM asset..."

5.2. [HIGH] Add system theme detection before localStorage check in the IIFE (file:120-126):
```javascript
const saved = localStorage.getItem('theme');
if (!saved) {
  const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
  document.documentElement.setAttribute('data-theme', prefersDark ? 'dark' : 'light');
  document.getElementById('theme-icon').innerHTML = prefersDark ? '&#9790;' : '&#9788;';
} else {
  document.documentElement.setAttribute('data-theme', saved);
  document.getElementById('theme-icon').innerHTML = saved === 'dark' ? '&#9790;' : '&#9788;';
}
```

5.3. [HIGH] Replace placeholder URLs with actual GitHub repository URLs or remove links if content not yet published

5.4. [MEDIUM] Change "all automated" to "automated when GitHub CLI is installed, with manual fallback otherwise" (file:241)

5.5. [MEDIUM] Wrap localStorage access in try/catch for private browsing compatibility (file:118, 121)

5.6. [MEDIUM] Add `prefers-reduced-motion` media query:
```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

5.7. [MEDIUM] Add `:focus-visible` styles for keyboard accessibility:
```css
.theme-toggle:focus-visible, a:focus-visible {
  outline: 2px solid var(--link-color);
  outline-offset: 2px;
}
```

5.8. [MEDIUM] Replace inline styles with CSS variables or classes for header elements (file:129-130)

5.9. [MEDIUM] Replace `transition: all` with explicit properties on toggle button (file:69)

5.10. [MEDIUM] Add `scope="col"` to all table headers for accessibility

5.11. [LOW] Consider replacing emoji toggle icons with inline SVG for consistent cross-platform rendering, or accept emoji color cannot be CSS-controlled
