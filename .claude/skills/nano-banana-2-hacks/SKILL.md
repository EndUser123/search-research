# Nano Banana 2 Hacks

Advanced prompting techniques and professional workflows for Nano Banana 2 AI image generation.

## Core Philosophy

The real power of Nano Banana 2 isn't just in the 4K resolution or 14 reference images - it's in understanding exactly how to structure your prompts for specific use cases. These techniques are production-ready and used by Fortune 500 companies and solo creators.

## Essential Features

### Web Search Integration
Enable the web search checkbox for time-sensitive requests:
- **Latest models**: Get actual 2026 design trends, not 2024 training data
- **Current products**: Real smartphone aesthetics, not outdated references
- **Trending styles**: Up-to-date visual references from the internet

### Reference Image Style Cloning
Upload reference images to clone exact visual styles:
1. Upload reference image with desired style
2. Upload target image to transform
3. Prompt: "Transform the [target] into the exact style of the [reference]"

## Workflow Tips

1. **Start Simple**: Test prompts with basic concepts before complex scenes
2. **Use References**: Upload style references for exact visual matching
3. **Enable Web Search**: For current products, trends, or time-sensitive content
4. **Iterate**: Use previous outputs as inputs for continuation
5. **Be Specific**: Include camera angles, lighting, materials in prompts
6. **Test Angles**: Explore bird's eye, Dutch angle, extreme low angle for cinematic variety
