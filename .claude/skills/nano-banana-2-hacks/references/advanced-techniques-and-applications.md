# Nano Banana 2 Advanced Techniques & Professional Applications

Advanced workflows and industry-specific application guides.

## Sequential Story Generation

For long-form narratives:
1. Generate initial comic page or scene
2. Upload completed page
3. Prompt continuation: "Continue this story for N more panels"
4. AI analyzes story state and generates logical progression

## Material & Texture Library

Build material references for consistent results:
- Melted chocolate on marble
- Brushed metal surfaces
- Fabric textures (denim, silk, wool)
- Wood grains (oak, mahogany, pine)

## Lighting Setup Library

Create reference lighting setups:
- Three-point lighting diagrams
- Rembrandt lighting
- Cinematic film noir setups
- Natural outdoor lighting conditions
