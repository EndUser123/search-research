# Phase Resources

## Purpose
This directory contains phase workflow definitions (p0.md through p6.md) that describe procedural steps for each phase of the p-skill consolidation framework.

## Usage
These files are referenced by the `/p` skill's Step 4 dispatch logic. Each phase file defines:
- Entry/exit criteria
- Validation stages
- Integration points
- Handoff protocols

## Ownership
These are **resource files**, not standalone skills. They belong to the consolidated `/p` skill and should not be invoked directly.

## Migration
Previously part of individual phase skills (/p0, /p1, etc.), now consolidated under unified `/p` command structure.
