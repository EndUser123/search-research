# p-Skill Scripts

## Purpose
Supporting utilities for validation, certification, and security enforcement across the p-skill framework.

## Migration Source
Scripts migrated from decommissioned phase skills:
- **From /p3**: Stage validation scripts
- **From /p5**: Archlint package and enforcement
- **From /p6**: Certification and security tools

## Key Scripts
- `stage_*`: Validation stage execution
- `archlint/`: Architecture linting package
- `certify`: Phase certification tooling
- `security/`: Security validation utilities

## Usage
Called indirectly by `/p` skill during phase execution. Not intended for direct invocation.
