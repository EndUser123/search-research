Subagent Usage Decision Tree

## ALWAYS Use Subagents (95% of cases)

- Any task requiring more than 2-3 minutes of focused work
- Code analysis, review, or quality assessment
- Syntax error detection and comprehensive codebase validation
- Research, documentation, or knowledge synthesis
- Complex problem-solving or multi-step operations
- Domain-specific work (security, performance, architecture, etc.)
- Quality-critical operations where specialist expertise matters
- Multi-component coordination or system integration work
- File exploration, codebase analysis, or pattern recognition
- Testing strategy or implementation
- Performance optimization or bottleneck analysis
- Security validation or vulnerability assessment
- Architecture decisions or design patterns
- Data analysis or complex data processing
- Error diagnosis or troubleshooting
- Planning or strategic task breakdown
- Learning or knowledge acquisition tasks

## Consider Direct Execution (5% of cases)

- Trivial one-liner responses or simple factual answers
- Basic file read operations when you know the exact path
- Simple status reports or immediate observations
- Emergency responses requiring immediate action
- Very low-risk, low-complexity operations where subagent overhead exceeds benefit
