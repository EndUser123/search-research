# Q2 - QuickCollectors

## Purpose

Run Stage 1 quick checks in parallel and return merged raw results.

## Workflow

Launch three parallel subtasks:
1. Subtask A: session activity + conversation scope signals
2. Subtask B: git branch/status/diff verification
3. Subtask C: mechanical checks + artifact/plan checks
4. **[From /investigate]** Evidence gathering subtask:
   - CHS search for feature discussions
   - Git log for relevant commits (when added/removed)
   - TSK folder search for plan documents
   - Alternative location search (glob/find)

Merge all outputs into `scan_state.raw_checks`.

## Rules

- Keep checks lightweight; no deep DUF/problem analysis in this phase.
- Do not silently drop failed subtasks.
- Mark any failed subtask as degraded for Q3.

## Decomposed from /investigate

Evidence gathering methodology now integrated into Q2 quick collectors:
- Prevents claiming something "doesn't exist" without searching
- Prevents claiming something "was never implemented" without git history
- Provides current state evidence for issue normalization
