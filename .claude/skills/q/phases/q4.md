# Q4 - Strategic Path

## Purpose

Render strategic output for clean or strategic-forced runs.

## Workflow

1. Use frozen `scan_state.mode` from Q3.
2. Generate up to 7 strategic priorities based on session context and scope.
3. Include low-severity debt as optional future items.
4. Produce action menu and next-step options.

## Rules

- Do not emit problem-oriented fix lists in this phase.
- Do not re-run collectors or recompute mode.
- Hand off final summary to Q6.
