# Q5 - Mixed/Problem/Deep Renderer

## Purpose

Render mixed/problem outputs and run deeper analysis when requested.

## Workflow

1. Use frozen `scan_state.mode` from Q3.
2. Mixed mode (1-6): show prioritized fixes plus forward steps.
3. Problem mode (7+): show full prioritized fix plan.
4. **[From /ddd]** If problem mode or `--deep` flag: run Due Diligence checklist:
   - Technical Implementation (code quality, security)
   - Testing & Validation (coverage, edge cases)
   - Business & Requirements (scope, docs)
   - Deployment & Operations (environment, monitoring)
   - Risk Assessment (technical debt, constitutional compliance)
5. If `--deep` or critical/high findings beyond DDD:
   - run deeper analysis routines from inside `/q` path
   - keep user control and escalation notice semantics

## Rules

- Respect `--fast` unless critical risk requires escalation.
- Keep deep runs bounded unless user explicitly requests exhaustive depth.
- Do not recompute scope or mode in this phase.
