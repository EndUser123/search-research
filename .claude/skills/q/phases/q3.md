# Q3 - IssueNormalizer + ModePlanner

## Purpose

Normalize findings and compute one frozen mode decision.

## Workflow

1. Convert raw checks into normalized issues:
```json
{"id":"Q-001","severity":"warn|high|critical","category":"scope|git|syntax|artifact|context","source":"subtask_a|subtask_b|subtask_c","actionable":true,"message":"..."}
```
2. **[From /library-first]** Add existing-solution issues:
   - Check for duplicate implementations (code reinvention)
   - Check for standard library alternatives
   - Check for codebase pattern reuse opportunities
   - Flag "why new instead of reuse?" without justification
3. Deduplicate overlapping issues.
4. Count issues and compute mode once:
   - `0` => `strategic`
   - `1-6` => `mixed`
   - `7+` => `problem`
5. Freeze `scan_state.mode` and `scan_state.counts` for downstream phases.

## Rules

- Mode must be computed exactly once per `/q` run.
- Degraded scan issues count toward thresholds.
- Output is consumed by Q4 or Q5.

## Decomposed from /library-first

Existing solution detection now integrated into Q3 issue normalization:
- Prevents code reinvention
- Flags standard library opportunities
- Promotes pattern reuse over new implementations
- Creates actionable issues for "use existing instead of create new"
