# Q6 - ContextSink

## Purpose

Persist `/q` context for downstream strategic workflows.

## Workflow

1. Validate `WT_SESSION` exists and is non-empty.
2. Write context exactly once using final scan summary.
3. Confirm write success and report handoff status.

## Rules

- If `WT_SESSION` is missing, HALT with remediation.
- If context write fails, HALT and do not report successful completion.
- Do not mutate issue counts or mode in this phase.
