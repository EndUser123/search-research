# Examples

Collection of runnable examples demonstrating rca features.

## Basic Usage

```bash
python basic_usage.py
```

Shows how to perform basic root cause analysis with evidence collection.

## Advanced Configuration

```bash
python advanced_config.py
```

Demonstrates custom confidence thresholds, evidence tiers, and hypothesis scoring.

## Real-World Integration

```bash
python real_world.py
```

End-to-end debugging session for a realistic production issue.
