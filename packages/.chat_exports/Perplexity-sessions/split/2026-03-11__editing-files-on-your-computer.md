can you edit files on my computer?

## Assistant



No, I can't directly edit files on your local computer. I operate in an isolated cloud sandbox environment — my file operations are limited to a workspace within that sandbox.

Here's what I can and can't do:

## What I can do
- Create, edit, and share files within my cloud workspace that you can then download
- Use a cloud browser to interact with websites
- Connect to services you authorize (Gmail, Slack, GitHub, etc.)

## What would let me touch your local files
- **Your local Comet browser** — if you have the Perplexity Comet browser installed locally, I can perform browser-based tasks using your local sessions. But that's browser automation, not direct file system access.

## For your workflow specifically
Since you're working with Claude Code on Windows 11, if you need AI-assisted file editing on your local machine, Claude Code itself is the right tool for that — it has direct file system access in your terminal. I'm better suited for research, generating files for you to download, or interacting with web services and connected apps.

Is there something specific you're trying to accomplish? I might be able to help a different way.
