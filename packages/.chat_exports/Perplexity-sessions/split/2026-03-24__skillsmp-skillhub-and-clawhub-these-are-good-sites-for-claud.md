## Human

SkillsMP, SkillHub, and ClawHub, these are good sites for claude skills.

Are there good sites for plugins?

## Assistant

Yes, there are several good sites and directories for Claude Code plugins, analogous to SkillsMP, SkillHub, and ClawHub for skills. These focus on plugin marketplaces, GitHub collections, and directories, with claude.com/plugins as the official hub.[1][2]

## Official Source
Claude Code's official marketplace at claude.com/plugins offers verified plugins like GitHub integration, auto-installed via `/plugin install <name>@claude-plugins-official`. It's maintained by Anthropic; submit via claude.ai/settings/plugins/submit.[2]

## Key Directories
- claudemarketplaces.com: Curates 95+ GitHub plugin marketplaces (e.g., ruvnet/claude-flow), searchable with install commands like `/plugin marketplace add owner/repo`.[3][4]
- claude-plugins.dev/skills: Plugin explorer alongside skills.[5]
- buildwithclaude.com: 400+ extensions including plugins, agents, skills.[6]

## GitHub Curations
Repositories like quemsah/awesome-claude-plugins (top 100 by adoption), ComposioHQ/awesome-claude-plugins (25-30 production-ready), and claude-plugins-official (Anthropic-managed) rank by stars/forks; add via `/plugin marketplace add owner/repo`.[7][8][2]

Install from these by adding the marketplace first, then browsing/installing individually—no direct "plug-and-play" like some skills sites, per Claude docs. Quality varies (community-driven); prioritize official/high-star repos. For your Claude Code workflows, test in a worktree: `/plugin marketplace add claude-plugins-official` then `/plugin`.[1][2]
