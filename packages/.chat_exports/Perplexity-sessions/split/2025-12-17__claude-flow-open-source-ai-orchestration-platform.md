## Assistant

Claude-Flow is an open-source AI orchestration platform designed for Claude AI models, enabling multi-agent workflows and swarm intelligence.[2]

## Core Features
It supports hive-mind agent swarms, persistent memory across sessions, and integration with over 100 MCP (Model Context Protocol) tools for tasks like research, coding, testing, and deployment.  Users deploy agents via simple CLI commands like `npx claude-flow hive-mind spawn`, specifying agent count, strategies (e.g., parallel), and memory namespaces for isolated projects.  The platform excels in VS Code, offers zero-configuration setup, and scales for enterprise use with security and monitoring.[1][3][6][2]

## Key Use Cases
- **Development Acceleration**: Spawns teams of agents for parallel task execution, such as building full apps (e.g., e-commerce with React/Node.js).[6]
- **Recursive Self-Improvement**: Agents can enhance Claude-Flow itself through modular, autonomous coordination.[3]
- **Workflow Automation**: Combines with Claude Code for natural language-driven planning, debugging, and deployment.[5]

## Installation and Start
Run `npx claude-flow` for instant setup, requiring Node.js and Anthropic API access.  GitHub repo at github.com/ruvnet/claude-flow provides v2.7 docs and examples.  Tutorials on YouTube cover hive-mind demos and comparisons to tools like Devin.[7][8][2][3][5]
