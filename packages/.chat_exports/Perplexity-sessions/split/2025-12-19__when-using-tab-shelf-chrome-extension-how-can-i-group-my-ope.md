## Human

when using tab shelf chrome extension, how can I group my open tabs in the browser

## Assistant

You group tabs in Tab Shelf either by using its automatic rules or by manually creating Chrome tab groups from within the side panel.[1]

## Manual grouping from Tab Shelf

Once the side panel is open and Tab Shelf is visible, you can use normal Chrome tab grouping actions directly on the items in the Shelf.[1]

- Right‑click a tab entry in Tab Shelf and choose **“Add tab to new group”** (or the equivalent Chrome “Add to new group”) to create a new tab group.  
- Drag a tab entry onto an existing colored group in Tab Shelf to add it to that group, just like in the regular tab strip.[1]

## Group all tabs from a site

Tab Shelf adds a shortcut for grouping all tabs from the same domain in one shot.[1]

- Right‑click one of the tabs for that site in the Tab Shelf list.  
- Choose the option that says something like “Group all tabs from this site” to automatically collect and group every open tab with that domain.[1]

## Automatic grouping rules

For persistent organization, you can define rules so new tabs are grouped as soon as you open them.[1]

- Open Tab Shelf’s settings (gear icon in the side panel) and go to the rules or grouping section.  
- Create rules that match a domain or URL pattern (for example, `github.com`) and assign them to a specific group name and color; future tabs that match are grouped automatically.[1]

## Using grouping across windows

Tab Shelf can apply those grouping rules across multiple windows where the extension is active.[1]

- In settings, make sure the option to “Run grouping rules on all windows” is enabled so tabs in every open Chrome window follow the same grouping rules.  
- With this enabled, any window that has Tab Shelf open will auto‑group matching tabs according to your defined rules.[1]
