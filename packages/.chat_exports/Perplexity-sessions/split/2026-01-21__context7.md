## Assistant

Context7 is a service (and MCP server) that gives LLM-based coding assistants access to up‑to‑date, version‑specific documentation and code snippets for libraries, frameworks, and APIs.[1][2][4]

## What Context7 Does

- Provides **clean**, versioned documentation and real code examples pulled directly from official docs and source repositories for many libraries and frameworks.[2][4][5]
- Delivers concise, filtered snippets (plus short explanations) so assistants can generate code that actually compiles instead of hallucinating outdated or non‑existent APIs.[4][5][2]

## How It Works

- Indexes and parses documentation sites and repos, extracts code examples, enriches them with metadata, embeds them for semantic search, then re‑ranks and caches results for low‑latency lookup.[4]
- When queried for a given library and topic, returns a small set of highly relevant snippets and docs, often scoped to a specific version (e.g., particular Next.js or @upstash/redis version).[5][2][4]

## Integration With Coding Assistants

- Exposed as an MCP server that tools like Claude Code, Cursor, Windsurf, VS Code extensions, or local LLM setups can call to fetch documentation on demand during a coding session.[7][8][2][5]
- Typical flow: resolve a library ID, then request docs/snippets for a topic (e.g., “JWT auth in Next.js 15”) and inject those results into the model’s context so subsequent generations use that ground truth.[3][2][7]

## Why It’s Useful

- Reduces wrong or stale code completions for fast‑moving frameworks (Next.js, Cloudflare, Upstash, etc.) by always consulting latest docs instead of the model’s static training data.[6][5][4]
- Especially valuable for niche libraries or fresh APIs that models were never trained on, and for large projects where keeping mental track of all library versions is error‑prone.[8][5][4]
