## Human

in excire foto, what should I pick to continue the analysis, without starting over?

## Assistant

Pick **Renew analysis**.

In Excire Foto that continues the catalog analysis for a folder or project using existing results, whereas **Complete analysis** or starting a new project would redo analysis from scratch.[1]
