## Human

sometimes perplexity says it has files for me, but I don't see where to download them.

## Assistant

Perplexity displays generated files (like CSVs, charts, code outputs) in the "Assets" section below the relevant query response in Perplexity Labs or tool executions.[1][2]

## Downloading Files
Look for the **Assets** panel at the bottom of the conversation thread where files were mentioned—download buttons appear there for direct access.[2]
If using the web version, right-click file previews in sources or citations for "Save as" options (not available on mobile/desktop apps).[3]
Pro/Max users can also export assets like DOCX/PDF/XLSX to Google Drive if connected.[4][1]

## Troubleshooting Visibility
Scroll down in the thread or expand the response fully, as Assets may be collapsed.[2]
Check you're on web.perplexity.ai (not app) for full download features; refresh if files were just generated.[3]
If still missing, verify your subscription (Pro+ required for some assets) via Settings > Billing.[5]
