## Human

How can I get perplexity to save it's work as a file I can download?

## Assistant

**Perplexity saves and allows downloading of generated work primarily through Perplexity Labs' Assets tab and thread export options.**[1][2]

## Perplexity Labs
Access Labs via the mode selector in the input bar (available to Pro subscribers on web, Mac, and mobile apps). Generated files like documents, spreadsheets, charts, images, HTML/CSS/JavaScript assets, and code organize automatically in the **Assets tab**. View and download them directly from there to save your project's outputs.[2][1]

## Thread Exports
Open any thread from your Library (at perplexity.ai/library), then use the **Export button** to download the conversation and answer as PDF, Markdown, or DOCX. This captures AI-generated responses without attachments unless specified. For uploaded files or images (web version only), right-click in the sources view and select "Save image as" or use the print option for PDFs.[3][4]

## Additional Options
Recent updates enable building and downloading assets like slides, sheets, and docs across all input modes, not just Labs. Enterprise admins control file download permissions, but Pro users like you have unlimited access. Threads and files remain private unless shared.[5][6]
