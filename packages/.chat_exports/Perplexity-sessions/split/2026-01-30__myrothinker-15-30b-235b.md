## Assistant

MiroThinker 1.5 is an open‑source **research** agent built by MiroMind AI, released in January 2026 as a deep web‑research and code‑execution system.[1][2][3][4]

### What “1.5 – 30B & 235B” means

- MiroThinker 1.5 comes in two main model sizes: a 30B‑parameter MoE variant and a larger 235B‑parameter MoE variant, both derived from Qwen3 mixture‑of‑experts bases.[5][6][7]
- In the MoE setup, only a subset of experts is active per token (e.g., ~3B active parameters for the 30B, ~22B active for the 235B), giving high performance at lower effective compute cost.[6][5]

### Capabilities

- Acts as a full research agent: plans multi‑step tasks, searches the web, reads and summarizes pages, runs Python code in a sandbox, and synthesizes long reports.[2][8][9][10]
- Designed for long‑horizon, tool‑heavy workflows: up to 400 tool calls per task, with a 256k‑token context window for multi‑document and long‑session work.[11][9][12][1]
- Benchmarks show strong performance on agent tasks like GAIA, HLE, and Browse‑type evaluations, often matching or beating larger/proprietary agents on tool‑use‑centric tests.[9][12][4][2]

### How you might use it locally

- You clone the open‑source repo (MIT‑style licensed models) and configure keys for search (Serper), web scraping (Jina), and a code‑execution sandbox (e2b) along with a summary LLM if desired.[8][2][9]
- The 30B variant is intended to be feasible on a strong single GPU or multi‑GPU rig, while the 235B is more for heavy setups or hosted deployments, trading more VRAM and latency for stronger reasoning and robustness.[7][4][5][6]
