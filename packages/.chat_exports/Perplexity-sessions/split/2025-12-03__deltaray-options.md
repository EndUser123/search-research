## Assistant

**Deltaray offers tools and platforms for options trading research, backtesting, and execution, including retail and institutional solutions.**[1][3]

## Retail Solutions
These tools target individual traders for strategy development and live trading. MesoSim provides low-code options strategy backtesting with 25 free runs upon signup, while MesoLive connects strategies to brokerage accounts like Interactive Brokers for real-time execution. The Strategy Library shares community-created strategies with documentation, such as Rhino (a broken-wing butterfly variant) and Boxcar trades.[3][5][1]

## Institutional Solutions
FundPro delivers enterprise features for hedge funds, including MesoSim API for scaled backtesting, MesoLive API for automation, and Merlin for strategy optimization via machine learning. Additional components like MesoMiner use genetic algorithms for trade discovery, Q-API supports quantitative analysis, and Quantify enables SQL-based analytics. These integrate AI workflows and support custom data.[10][1][3]

## Key Features
- GitHub repositories with public strategies (e.g., NetZero, Volatility Hedged Theta) and APIs like Q-API.[5]
- Lua-based DSL in MesoSim for dynamic simulations with Greeks and rules.[6]
- Educational resources on vertical spreads, 0-DTE trades, and seasonality via partnerships like Quantpedia.[6]
