## Human

Agent Skills now available in Antigravity

## Assistant

Agent Skills in **Antigravity** are a new feature (v1.14.2, Jan 13, 2026) that lets you customize what your agent can do and how it behaves, on top of the existing agent and tab model system.[1]

## What changed in 1.14.2

- Agent Skills are now exposed as a first‑class customization surface for agents in Antigravity, aimed at “enhanced customizability.”[1]
- The underlying tab model architecture was updated, which likely affects how agents reason over and coordinate across editor tabs and browser-like contexts.[1]
- New conversation settings let you disable conversation history and knowledge, which is important if you want stricter isolation/privacy or test agents without long‑term context.[1]

## Why Agent Skills matter

- Skills give you a structured way to define capabilities and behaviors for agents instead of relying only on global settings or ad‑hoc prompts.[1]
- Combined with secure mode (added in 1.11.17) and knowledge management from the original launch, this moves Antigravity further toward an agent‑first development environment with controllable autonomy and tools.[1]

## Related recent features

- Support for Gemini 3 Flash plus native audio and long‑conversation performance improvements arrived in 1.12.4, which these skills can presumably leverage as underlying models/capabilities.[1]
- Secure Mode, introduced in 1.11.17, enforces constraints to prevent autonomous targeted exploits and require human review, which pairs naturally with finely scoped skills.[1]

If you want, the next step is to open the Antigravity docs for Agent Skills and walk through how to define a skill set that mirrors your current Claude Code hooks/skills setup.
