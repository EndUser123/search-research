## Assistant

Invidious is an open-source alternative front-end to YouTube designed for privacy and ad-free viewing.[1][3]

## Key Features
It offers lightweight playback without tracking, JavaScript requirements, or ads, plus subscription management independent of Google accounts. Users enjoy customizable homepages, audio-only mode, and support for importing/exporting data from YouTube or apps like NewPipe. A developer API enables integration, and it's available via public instances or self-hosting with Docker.[3][4]

## Technical Details
Invidious scrapes YouTube's site rather than using official APIs to minimize data shared with Google, though IP addresses remain visible. The project, hosted on GitHub under AGPL-3.0, faced a 2023 takedown notice from YouTube but continues operating. Self-hosters often pair it with VPNs or tools like SponsorBlock for enhanced control.[4][6][3]

## Usage Options
Access public instances listed on invidious.io for immediate use, or deploy your own for full privacy via GitHub instructions. Mobile apps like Clipious sync with instances, making it popular for de-Googling workflows. Note potential updates needed due to YouTube changes.[6][1][3]
