## Human

i have mp4 videos that I'd like to cut parts out of, easily, quickly.  What are the best free tools that are easy to use on windows 11?

## Assistant

The best free, easy-to-use tools for cutting MP4 videos quickly on Windows 11 are **LosslessCut** (top recommendation), **Clipchamp** (built-in), and **Avidemux** (simple open-source). Here's what makes each stand out:

### Top Free Video Cutters for Windows 11

| Tool | Key Advantage | Lossless? | Ease of Use | Download Source |
|------|---------------|-----------|-------------|-----------------|
| **LosslessCut** | Fastest, truly lossless cutting with keyframe precision [1][2] | ✅ Yes (no re-encoding) | ⭐ Very easy - drag timeline handles | GitHub: `mifi/lossless-cut/releases` [1][3] |
| **Clipchamp** | Built into Windows 11, no download needed [4][5] | ❌ Re-encodes | ⭐ Very easy - drag handles on clip | Microsoft Store / Windows 11 built-in [6] |
| **Avidemux** | Simple open-source, cuts sequences quickly [1][7] | ✅ Yes (JSOPE mode) | ⭐ Easy - set start/end points | avidemux.org [1][8] |
| **VIDCUTTER** | Based on mpv player, interrupt-free cutting [4] | ✅ Yes | ⭐ Easy | via Python/pip [4] |
| **Shutter Encoder** | GUI for FFmpeg, "Cut without re-encoding" [1] | ✅ Yes | ⭐ Moderate | shutterencoder.com [1] |

### Why LosslessCut is Best for Your Needs

LosslessCut is specifically designed for **extremely fast, lossless operations** on video files:[2]

- **No re-encoding** = cuts complete in seconds instead of minutes[1]
- Set "copy" for video/audio format, drag start/end handles, use keyframes only[1]
- 100% free forever, cross-platform FFmpeg GUI[2][1]
- Direct Windows download: `LosslessCut-win-x64.7z` from GitHub[1]

### Quick Start Option (Already Installed)

If you want to cut videos **right now without downloading**, use **Clipchamp** which comes built into Windows 11:
- Open Clipchamp → click your clip → drag handles on either side to trim[6]
- Limitation: tops out at 1080p and re-encodes[4]

For your goal of cutting MP4 parts **easily and quickly**, I'd recommend starting with **LosslessCut** for the best speed/quality combination, or using **Clipchamp** if you want zero setup.
