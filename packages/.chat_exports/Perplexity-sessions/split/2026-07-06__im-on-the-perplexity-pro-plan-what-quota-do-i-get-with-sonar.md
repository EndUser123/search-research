## Assistant

You switch between basic (standard) search and Pro Search from the UI when starting or continuing a thread.[1][2]

### How to start a Pro Search

1. Open Perplexity and log in to your Pro account.[3]
2. Start a **new thread** (new question).  
3. In the composer at the bottom, **enable Pro Search** by clicking the **“Pro” button** or toggle on the bottom-right of the input box before you send the query.[2][1]
4. Ask your question and send; that query (and the thread that follows) will use Pro Search and consume Pro search quota.[1][2]

### How to do a basic / standard search

1. In the same composer, **leave the Pro toggle off** (don’t click the Pro button).[4][1]
2. Type your question and send; this runs a **standard/basic search**, which is the default mode.[4][1]
3. You’ll get a faster, lighter answer that usually pulls from 1–2 sources, and it does **not** consume Pro search credits.[1][4]

### How to tell which you’re using

- Pro Search: You’ll see a **Pro** label/toggle active on the thread and more detailed multi-section answers with a lot of citations and sometimes tools like code/file analysis.[4][1]
- Standard/basic: No Pro label; answers are shorter, with fewer sources and no advanced Pro-only tools.[1][4]
