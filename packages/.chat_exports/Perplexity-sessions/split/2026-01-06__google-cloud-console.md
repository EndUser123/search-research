## Assistant

The Google Cloud Console is the web-based dashboard used to manage all Google Cloud Platform (GCP) resources, including projects, billing, compute, storage, networking, and IAM.[2][3]

## How to open it

- Go to `https://console.cloud.google.com/` in your browser and sign in with a Google account that has access to a GCP project.[1][3]
- Once signed in, select or create a project from the project selector at the top bar to start managing resources.[3][6]

## What you can do there

- Manage infrastructure: create and administer Compute Engine VMs, Cloud Run services, Kubernetes clusters, and App Engine apps from a unified **interface**.[2]
- Work with data and storage: create buckets, upload/download objects, manage permissions, and monitor usage for Cloud Storage, BigQuery, and databases.[3][2]

## Key features

- Centralized overview: customizable dashboards for resources, health, costs, and activity, plus integrated Cloud Shell for running `gcloud` without local setup.[2][3]
- Access control and security: configure IAM roles, service accounts, and per-resource permissions directly from the console to control who can access what.[3][2]

## Mobile access

- There is an official Google Cloud mobile app that lets you monitor billing, status, incidents, and SSH into VMs, plus access Cloud Shell from Android or iOS.[7]
