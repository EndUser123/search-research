## Human

when I add a chat session to a space as a file, how long will it stay there?

## Assistant

When you add a chat session to a Perplexity AI Space as a file (via the "add to space as a file" option), it is treated as a file upload to the Space and retained indefinitely until you manually delete it.[1]

This applies across account types, including Pro and Enterprise, distinguishing it from thread-attached files (deleted after 7 days).[2][3][4]

Official policy confirms: "Files uploaded to ... Spaces are retained until deleted." No automatic expiration noted for non-Enterprise users.[4][1]

## Human

What's the difference between adding a session as a chat or adding it as a file to the space?

## Assistant

**Adding as Chat vs. File**

Adding a chat session to a Perplexity Space as a "chat" appends it as an interactive thread within the Space, preserving the full conversation history, responses, and context for ongoing reference or continuation. This keeps it structured like a native chat, accessible for follow-ups or collaboration while tied to the Space's custom instructions and files.[3][5]

**Key Distinctions**

| Aspect | As Chat | As File |
|--------|---------|---------|
| Format | Interactive thread with Q&A flow | Static file export (e.g., text/PDF snapshot) [6] |
| Retention | Indefinite, like other Space content [prior context] | Indefinite until deleted [7] |
| Usage | Directly query/continue in Space context [5] | Upload/reference as knowledge base file [2] |
| Behavior | AI treats as live history; supports threading | AI analyzes as document; no native interactivity [8] |

Choose "chat" to maintain conversational continuity; use "file" for archival or standalone analysis. No automatic deletion for either in Pro/Enterprise plans.[prior context][5]

## Human

Is there a way in the history of the sessions to filter only on sessions that are not in a space?

## Assistant

**No Direct Filter Available**

Perplexity AI's History page (https://www.perplexity.ai/library) lists all your threads, including those added to Spaces, but lacks a built-in filter for "not in Spaces" or excluding Space-linked sessions.[1]

**Available Filters**

- **Search bar**: Keyword search across all threads.[1]
- **Type**: By Search Mode (Pro, Research, Create files/apps).[1]
- **Sorting**: Newest/Oldest.[1]
- **Other toggles**: Hide Comet browser threads; no Space-specific option.[1]

Threads remain in History even after adding to a Space—you can check the three-dots menu on individual threads to see if "Added to [Space]" appears. For non-Space sessions, manually scan or use search bar with project keywords; feature requests exist in community but unconfirmed in UI as of April 2026.[2]
