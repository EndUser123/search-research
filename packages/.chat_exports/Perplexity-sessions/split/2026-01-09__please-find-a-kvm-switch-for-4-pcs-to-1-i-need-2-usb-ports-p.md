## Assistant

Yes, exactly! You've got it right.[1]

**The single USB 3.0 cable to each PC carries ALL the USB device signals** - keyboard, mouse, and any other USB devices you have plugged into the KVM's 4 front USB ports. That's how KVM switches work - they multiplex all the USB device data through one USB connection to each PC.[2][1]

**The setup per PC:**
- 1× HDMI cable (for video from PC to KVM to monitor)
- 1× USB 3.0 cable (carries keyboard + mouse + printer + any other USB device data between PC and KVM)

**Your devices plug into the KVM:**
- Keyboard → into one of the 4 USB 3.0 ports on the KVM
- Mouse → into another USB 3.0 port on the KVM  
- Printer/USB drive/etc → into the remaining 2 USB ports on the KVM
- Monitor → HDMI from KVM to monitor

That single USB 3.0 connection to each PC is a **USB hub connection** that carries all 4 USB devices' data streams. USB 3.0 has plenty of bandwidth to handle keyboard, mouse, printer, and more simultaneously through one cable.[2]

So yes, you can absolutely use both keyboard and mouse - they both go through that single USB cable to the PC via the KVM's internal USB hub.
