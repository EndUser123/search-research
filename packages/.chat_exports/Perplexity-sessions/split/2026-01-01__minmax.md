## Assistant

Minimax is a decision-making algorithm used in artificial intelligence, particularly for two-player zero-sum games like chess or tic-tac-toe. It minimizes the possible loss for a worst-case scenario by recursively evaluating positions, assuming the opponent plays optimally.

## Core Concept
The algorithm builds a game tree where maximizing players choose moves to maximize their score, while minimizing players select moves to minimize the opponent's score. At each level, the value propagates up: max nodes take the maximum child value, min nodes take the minimum.[5]

## Algorithm Steps
- Start at the root node (current board state).
- Recursively generate child nodes for all possible moves.
- Evaluate leaf nodes with a heuristic function (e.g., material advantage in chess).
- Backpropagate: max(\(child_1, child_2, \dots\)) for max player; min for min player.[5]

## Example in Tic-Tac-Toe
For a position where X can force a win, the minimax value is +1 (win for max player X); O aims for -1. Alpha-beta pruning optimizes by skipping irrelevant branches.[5]

## Applications
Common in game AI, optimization problems, and decision theory under uncertainty.[5]
