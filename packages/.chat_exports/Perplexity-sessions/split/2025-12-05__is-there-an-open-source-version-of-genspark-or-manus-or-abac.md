## Human

Is there an open source version of genspark or manus or abaccus?

## Assistant

**Yes, open-source alternatives exist for Genspark AI and Manus AI—such as OpenManus, Suna, Kortix, Lemon AI, and Skywork.ai—but no direct open-source version was found for Abaccus (likely referring to Abacus.AI's Deep Agent), though Abacus.AI contributes open-source models and tools.**[1][2][3][4][5][6]

## Key Open-Source Alternatives
These projects replicate agentic features like task execution, web browsing, and multi-agent systems for both Genspark and Manus.

- **OpenManus**: A modular framework using Docker, Python, and JavaScript to mimic Manus AI's autonomous task handling (e.g., travel planning, data analysis); available on GitHub with CLI, API, and web UI support.[7][8][9]
- **Suna (by Kortix)**: Fully local, self-hostable agent for website creation, research, and automation; rivals both tools and runs without subscription costs.[2][10]
- **Lemon AI**: Full-stack agentic framework with code interpreter sandbox; positions as local alternative supporting complex workflows.[5]
- **Kortix**: Customizable, self-hosted option for Genspark-like browser automation and API integrations.[4]
- **Skywork.ai**: Multi-agent content OS for documents, slides, and podcasts; serves as broader Genspark/Manus replacement.[3]

## Abacus.AI Context
Abacus.AI's Deep Agent focuses on RAG chatbots and code review but operates as a proprietary platform; they release open-source LLMs like Dracarys fine-tunes for coding instead.[11][12][6]
