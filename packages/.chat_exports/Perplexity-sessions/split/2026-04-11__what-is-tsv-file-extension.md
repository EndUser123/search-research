## Human

what is tsv file extension?

## Assistant

**TSV** stands for **Tab-Separated Values**, a plain-text file format (.tsv extension) for storing tabular data where fields in each record (row) are separated by **tab characters** (ASCII 9), and records are separated by newlines.[1][2][3]

1. **Structure**: Similar to **CSV** (comma-separated values), but uses tabs as delimiters, making it ideal for data with commas in fields; first line often serves as headers.[2][4]

2. **Use Cases**: Common for data exchange between tools like spreadsheets (**Excel**, **Google Sheets**), databases, and scripts; lightweight and widely supported.[5][3][1]

3. **Opening/Editing**: Load in text editors (e.g., Notepad), spreadsheets (import as tab-delimited), or code (e.g., Python's `pandas.read_csv(sep='\t')`).[1][5]

## Key Takeaways
- **TSV** = tab-delimited tabular text files; no uncertainty—standard format per authoritative sources.[3][2]
- **Next Step**: To create one, enter data in **Excel** > **Save As** > **Tab Delimited Text**.[1]
