## Human

is there an openclaw plugin for claude code?

## Assistant

Yes, there is an OpenClaw plugin specifically designed for Claude Code.[1][2]

## Plugin Overview
This open-source plugin, available on GitHub at alizarion/openclaw-claude-code-plugin, enables orchestration of Claude Code sessions through chat platforms like Telegram or Discord.  It supports launching multiple concurrent sessions, multi-turn interactions, foreground/background modes, session resuming, and intelligent notifications for completions or budget alerts.[2][1]

## Key Features
- Multi-agent workspaces with custom notification settings.
- Configurable autonomy levels, from fully hands-off to human-in-the-loop.
- Built using Claude Code itself, wrapping the official Claude Agent SDK.[1]

## Installation and Usage
Install via npm (e.g., from the referenced package), then integrate with OpenClaw for programmatic session management.  A demo is available on YouTube, and it's released under the MIT license as of February 2026.[3][2][1]
