## Assistant

**Error 0x80073712 indicates corruption in the Windows component store, often blocking updates or feature changes on Windows 11.**  This matches the screenshot showing "The component store has been corrupted" during a Windows Features operation.[1][2]

## Primary Fix
Run these tools in an elevated Command Prompt (right-click Start > Terminal (Admin) or cmd as admin) to repair the image and files.

- `DISM /Online /Cleanup-Image /RestoreHealth` (fetches clean files from Windows Update; may take 10-30 minutes).[2][1]
- Then `sfc /scannow` to fix system files.[1][2]
- Restart and retry the operation.

If DISM needs a source and internet fails, use a Windows ISO mounted as a drive (e.g., /Source:W:\sources\sxs /LimitAccess).[2]

## Additional Steps
**Disk Cleanup:** Search for "Disk Cleanup," select "Clean up system files," check "Windows Update Cleanup," and run it to remove corrupted update files.[1]

**Reset Update Components:** Stop services then rename folders:
```
net stop wuauserv
net stop cryptSvc
net stop bits
net stop msiserver
ren C:\Windows\SoftwareDistribution SoftwareDistribution.old
ren C:\Windows\System32\catroot2 Catroot2.old
net start wuauserv
net start cryptSvc
net start bits
net start msiserver
```
Restart afterward.[1]

## Repair Install
If issues persist, go to Settings > System > Recovery > "Fix problems using Windows Update" > Reinstall now. This keeps files/apps while refreshing Windows (10-35 minutes).[2]

Run Windows Update Troubleshooter first (Settings > System > Troubleshoot > Other troubleshooters) and scan for malware.  These steps resolve most cases without data loss.[2][1]
