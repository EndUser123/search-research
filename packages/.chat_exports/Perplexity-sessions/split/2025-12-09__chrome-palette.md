## Assistant

**Chrome Palette** is a Chrome browser extension that provides a command palette interface, similar to those in VSCode or Sublime Text, for quickly accessing internal Chrome commands without memorizing hotkeys or using the mouse.[1][6]

## Key Features
- Fuzzy search across commands, sub-commands (like tabs, bookmarks, history), and extensions, with results sorted by usage frequency.
- Supports dark mode, displays standard shortcuts, and includes actions like new tab/window, close/reload tabs, mute tabs, split screen, and settings navigation.
- Open-source (MIT license on GitHub), privacy-focused with no server uploads or telemetry; built with SolidJS for fast performance (38KB compressed, ~99ms startup).[6][1]

## Installation
Install from the Chrome Web Store or load unpacked from the GitHub repo (dbuezas/chrome-palette). Set a custom shortcut like Cmd+Shift+P via Chrome's extensions shortcuts page.[1][6]
